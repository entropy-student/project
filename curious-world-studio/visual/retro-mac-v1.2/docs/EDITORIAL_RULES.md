# 素材轮播、证据与字幕准则

每段旁白对应最能解释它的画面，不机械固定 3 秒切图；同一素材可以跨相邻句持续展示。

| 类型 | 画面标签 | 核查 |
|---|---|---|
| research_video | 原始实验 | 作者项目视频、具体素材 URL、许可、核查日期 |
| paper_evidence | 论文证据 | 论文链接、页码/图号、授权状态 |
| self_recording | 独立复现 | 自己的操作条件、模型版本、与论文差异 |
| stock_video | 辅助素材 | 素材网站链接、许可；不能冒充论文实验 |
| illustration | 示意画面 | 画面制作方法、与真实数据的区别 |
| closing_answer | 无需新模板 | 用现有画面回答本期最初的提问 |

优先检查：承诺兑现 → 证据真实性 → 手机可读性 → 切镜是否自然 → 公共传播的权利许可。SRT 必须以真实录音时序为准，严格单行，避免两句同时显示。

# 视觉原型 QA 清单

- [ ] 1920×1080 画布中 B 外框占满 100% 宽高，无外部桌面裸露
- [ ] A 短暂桌面可切换至 B；B 内能切换视频/图片/证据
- [ ] 视频按原始比例显示，不裁去研究证据
- [ ] 文献截图/图表可读，证据类别来源真实
- [ ] 中文字幕始终单行，视觉位置不覆盖底部控制栏
- [ ] 真实音频与字幕已声学对齐（目前未实施）
- [ ] 研究视频、素材图/视频已确认使用权（按期核查）
- [ ] 页面离线打开无外部 CDN 依赖
- [ ] CSS 样式复用保留 MIT 许可
- [ ] 移动端缩略预览时字幕和关键内容仍可辨认

说明：上面是生产前的验收标准，**不代表各项已经通过**。

# Retro Mac Desktop Documentary · STYLE_LOCK v1.2

> 本规范是视觉基线，不代表已经实现自动成片。

## 频道体验
像一个好奇心很强的朋友，在老电脑上点开刚发现的研究视频。**研究内容优先于复古 UI 装饰**。视觉参照 Mac OS X Tiger Aqua 桌面及 QuickTime 7 银灰播放器，不使用复杂 HUD、漫画主舞台或 PPT 主体。

## 两种固定画面状态
**A：桌面开场**。Tiger 时代蓝色 Aqua 背景、顶栏、Dock、研究文件夹，简短双击打开当期研究文件；通常 1.5–3 秒，可为精彩内容冷开场让路。

**B：主体播放器**。银灰色 QuickTime 风格窗口在 16:9 画布内 **100% 宽、高，边到边**；压缩标题栏和控制条，中间是尽可能大的视频内容区。所有真实实验视频、论文图表、图片、补充视频、证据、解释画面、结尾都在 B 内切换；**不引入独立 C 模式**。默认 contain 保持素材比例，不能裁掉关键证据。

## 规格
- 母版 1920 × 1080、16:9、30fps。
- 旁白中文字幕**严格单行**，推荐 56px（允许 52–58）、白字 700 字重、近黑半透明底。居中放在播放器画面内部底部，不覆盖播放控制条。
- 以实际录音对齐字幕；建议每句约 18–22 个全角汉字，按语义断句，禁止机械定时、多行字幕或默认卡拉 OK 高亮。
- 素材轮播必须与旁白语义对应，不为切画面而切。真实行为可完整展示，论文重点图表应通过静态版式、完整尺寸和清晰分栏保证可读，**不以动态推近或局部放大镜代替可读布局**。
- 默认为干净硬切；必要时 120–200ms 溶解。**正式 B 内容不添加推近/平移/Ken Burns 等镜头运动。** A→B 既有开窗动画约 250–450ms，属于锁定的播放器外壳而非新增动效。
- 禁用故障闪烁、频繁缩放、3D 旋转、伪报错、伪科研参数和 PPT 式动效。

## 素材横竖屏选择（Owner 2026-10-11）

正式 B 视频优先选择 **16:9 横屏原始素材**；1920×1080@30 输出不变。若只有竖屏才能真实展示必要的研究行为/证据，可按已选 **4 画面布局** 作 `contain` 留边、合理分栏或画中画，绝不拉伸或截断核心证据，也不借复播/伪造镜头填空。M2 竖屏测试只证明工程适配，不等于正式视频默认使用竖屏。清理检查点见 `../../../docs/PREPRODUCTION_CLEANUP_POLICY_2026-10-11.md`，不能提前删除 M2 诊断记录。

中文 PingFang SC / Microsoft YaHei / Noto Sans CJK SC；英文 Helvetica Neue / Arial。

## 证据标签和真实性
播放器内容区左上角统一使用：**原始实验 / 论文证据 / 独立复现 / 辅助素材 / 示意画面**。论文完整来源与权利记录进入每期素材清单。可播放或可观看不等于视频可商用；辅助素材和概念动画不能冒充真实实验。

## 正式视频内容素材（Owner 2026-10-11 更新）

A/B 老电脑外壳和已有播放器操作动画可以继续；**播放器 B 内的内容素材**只能从论文/实验研究一手资料、OpenMontage 现有视频检索、yt-dlp 对合法来源的素材提取三条路径按需选用。**Codex 新增动效仅允许三大类：2 转场衔接、4 画面布局、6 信息呈现**；不加入 1 镜头运动、3 聚焦强调、5 时间控制或 7 额外视觉风格/界面特效。允许真实素材的双画面对照、硬切/短叠化以及真实来源/单行字幕信息；禁止主动推近、放大镜、追踪圈注、刻意定格/变速、额外滤镜。固定的 Research Aqua A/B 外壳正常动作保持不变；**禁用 AI 生图/生视频、代码/SVG/Canvas 等生成果冻/手/人物/实验装置等实体、重复/循环镜头**。与该规则冲突的早期建议（如程序画果冻）只属历史演示，**不进入正式节目**。具体去重/来源/权利/缺素材时止步规则见 [3＋1正式素材合同](../../../docs/VIDEO_ASSET_POLICY_3_PLUS_1_2026-10-11.md)。

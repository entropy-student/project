# Retro Mac Desktop Documentary · STYLE_LOCK v1.2

> 本规范是视觉基线，不代表已经实现自动成片。

## 频道体验
像一个好奇心很强的朋友，在老电脑上点开刚发现的研究视频。**研究内容优先于复古 UI 装饰**。视觉参照 Mac OS X Tiger Aqua 桌面及 QuickTime 7 银灰播放器，不使用复杂 HUD、漫画主舞台或 PPT 主体。

## 两种固定画面状态
**A：桌面开场**。Tiger 时代蓝色 Aqua 背景、顶栏、Dock、研究文件夹，简短双击打开当期研究文件；通常 1.5–3 秒，可为精彩内容冷开场让路。

**B：主体播放器**。银灰色 QuickTime 风格窗口在 16:9 画布内 **100% 宽、高，边到边**；压缩标题栏和控制条，中间是尽可能大的视频内容区。所有真实实验视频、论文图表、图片、补充视频、证据、解释画面、结尾都在 B 内切换；**不引入独立 C 模式**。默认 contain 保持素材比例，不能裁掉关键证据。

## 规格
- 母版 1920 × 1080、16:9、30fps。
- 旁白中文字幕**严格单行**，推荐 56px（允许 52–58）、白字 700 字重、近黑半透明底。居中放在播放器画面内部底部，不覆盖播放控制条。
- 以实际录音对齐字幕；建议每句约 18–22 个全角汉字，按语义断句，禁止机械定时、多行字幕或默认卡拉 OK 高亮。
- 素材轮播必须与旁白语义对应，不为切画面而切。真实行为可完整展示，论文重点图表应通过静态版式、完整尺寸和清晰分栏保证可读，**不以动态推近或局部放大镜代替可读布局**。
- 默认为干净硬切；必要时 120–200ms 溶解。**正式 B 内容不添加推近/平移/Ken Burns 等镜头运动。** A→B 既有开窗动画约 250–450ms，属于锁定的播放器外壳而非新增动效。
- 禁用故障闪烁、频繁缩放、3D 旋转、伪报错、伪科研参数和 PPT 式动效。

## 视觉叙事准出条件（Owner 2026-10-16 真实样片反馈）

- **视觉多样性是真实镜头差异**：不能将同一段库存片连续分割为多个S编号、同题材近似拍摄角度换切，宣称完成丰富分镜。要在动作/场景/景别/研究证据用途上产生对叙事有意义的变化；故事推进必须由观众看得到的内容承担。
- **不能用文字代替核心视频**：不接受连续数秒整屏纯文字步骤卡来解释最重要的科学机制。字幕与简短来源/样本限定只作辅助；研究论文真实图表、清晰实拍、真实物理动作可以承载说明，但绝不伪造科研实录、代码/SVG绘制虚假的研究过程或做PPT主舞台。若画面暂时无法解释核心动作，保留原旁白并记录画面缺口；**素材匹配阶段不得自行收缩承诺、重写文案或以纯文字板替代核心解释**。具体兜底策略待Owner讨论，不能因缺口自动设定内容停止机制。
- **先检查素材分布再渲染**：初步镜头表须列出不同原始来源、实际展示的视觉动作/信息价值及预计时长。与本次R3失败样片相似的“两条来源占约83%且长文字卡解释主机制”不能再次提交当作完成的视觉方案。没有唯一规定必须几个镜头或每镜几秒，但必须证明不同镜头具有不同观看价值。
- **准确性与丰富性并重**：Owner早先“相关即可”只表示不追求真实研究实验逐帧匹配；不等于可用高度相似画面循环填充。使用更丰富的真实视觉信息，不突破既有权利PARTIAL、Aqua→QuickTime外壳及主体全幅等既有约束。质量失败后只重设计画面方案，不自动批准R4、付费或公开发布。

**2026-10-16 新裁决提示**：当前不设置素材种类的时长比例硬上限/下限；先前R3两条来源合计约83%是该片的审美失败证据，不是自动比例门槛。素材缺口也不触发自动“停机”；安全、制片授权及权利审批仍另行执行。详见[视觉匹配裁决登记](../../../docs/VISUAL_ASSET_MATCHING_DECISION_REGISTER_2026-10-16.md)。

## 4. 五个功能的严格逐项验收

### MW-01 关窗
鼠标从桌面移向红色交通灯 → 停留出现明确 hover 反馈 → 点击环/按钮按下（同步）→ 窗口以自然收缩/淡出关闭，保留 V2 底座和相同 Desktop icon/Dock 锚点 → 桌面终态保持清楚。**禁止开头就直接窗口消失。**

### MW-02 Aqua弹窗
先模拟鼠标触发一项已知 UI 操作 → 背景轻压暗，Aqua弹窗自然出现 → 提示文字至少保持到可读；正常自动演示应有可追踪的鼠标移向 `Open`/ `Cancel` → 触发选择 → **弹窗离场同样做过渡**（不能由 `dismiss` 立即 opacity 0）。交互选择可暂停自动流程等待 Owner 手动选择，自动演示时有默认安全的 `Cancel` 路线。

### MW-03 窗口真正切换（核心必须重做）
最初 A 在前台，B 的标题栏一块明确可见。鼠标移动到 B 的**可点击露出区域** → click反馈 → A轻微退后/失焦，B被带到用户观看中心并成为显然更可读的前窗 → 终态必须能**一眼分辨 B 已切到前景，A 不遮住 B 标题与主要内容**；然后可点击A逆向切回。**不是每帧只是 z-index 由7变6 + 5–6像素平移**。每项中还要演示“卡片自动播放”与“窗口自身点击”两条路径效果一致，反复切换无漂移。

### MW-04 暂停 UI 示意
只用无科研资料的占位画面展示：鼠标移动到播放器控制点 → 按下 → 暂停视觉标记自然出现 → 保持足够观看 → 用明确的另一点击行为恢复 UI 标识。真实 B 研究源视频冻结/变速仍**禁止**；不可以“暂停图标出现”冒充完整视频时间控制。

### MW-05 文件进度 UI 示意
鼠标触发**可见的文件复制 Demo** → 任务窗口出现 → 进度条按时间增长、清楚展示 Done，停留至少0.5秒后收起。所有文案显著标 `UI DEMO / Simulated`，不得假装真实文件传输或论文分析。进度应可被 Reset、Seek 在0/50/100%正确复现而无状态漂移。

# G1V-A｜真实桌面交互开场的独立视觉原型验收定义

**状态：DESIGN_ONLY / NOT_RENDERED / OWNER_EXECUTION_APPROVAL_PENDING**。不使用任何原 YouTube 视频、不下载模型/素材或新软件，不修改现有 R1/R2 输出、正式剧本、STYLE_LOCK。此文档只是下一轮纯代码动画范围。

## 目标

向观众呈现一条连续可理解的**操作事件链**，而非“一个静止苹果桌面→一张论文照片”的硬切。

候选时间分配仅为原型起点，优先视觉自然顺畅，不强迫套原 R2 的1.8秒：
1. 桌面环境成立，鼠标/焦点初始静止（0.0–0.5s）。
2. 鼠标**连续移动**到研究文件，文件高亮/选中（约0.5–1.2s）。
3. 明确的两次点击/双击视觉反馈，文件图标有响应（约1.2–1.6s）。
4. Finder/文件窗口出现或播放器启动，有可见尺寸、透明度、位置变化，而非一帧直接替换（约1.6–2.7s）。
5. QuickTime-style 播放器由窗口态平滑展开至1920×1080的 B 满幅（约2.7–4.2s）。
6. 播放三角变暂停、进度条真实前进、研究内容从静态首帧进入“正在播放”状态（约4.2–5.0s）；无真实获许可实验视频时采用清楚标注的**自制抽象运动占位**，绝不伪称原始研究画面。

上面是视觉动作提案，不是已经核实的正确时长或已实现动画。总时长可根据原型评价调整；**禁止继续把1.8s静态 A 当作合格版本**。

## 实现约束

- 仅利用现有 CWS 独立 Remotion 和现有经审批的 Chrome Headless Shell 版本，**在 Owner 明确允许运行后**使用；不另行下载安装软件/云模型。必须在**新的隔离目录与唯一 stage slug**保存新文件，旧G1-R1/R2原视频和staging原样保留。
- Retro Mac Tiger Aqua / QuickTime 7 视觉参数以 `visual/retro-mac-v1.2/docs/STYLE_LOCK.md` 为准。优先代码组件/程序绘制交互动画，而非屏幕录制、套PPT、幼态 emoji、无来源的 macOS 商标素材。必须兼容现有无 C 的 A/B 结构，B 的chrome同一套，不随意换成新视觉方向。
- 动效“有逻辑”优先，鼠标必须确实选中刚刚出现的文件；文件打开到播放器的空间连续性必须看得懂。
- 原型阶段不要求重配音，或剪入原实验视频；不能用未授权实验画面来填纯A动画的测试。
- 时长变更时，在接入未来真实旁白之前另行处理 `audio_start_video_ms` 与 SRT，只能偏移一次，不能复用旧R2的1.8s时间轴假装自然。

## 可验收的可视证据

- 连续真实MP4，且至少抽帧：桌面无鼠标动作、鼠标移动、文件选中、双击反馈、播放器出现、播放器放大中、B 满屏、播放控件切换，8类事件分别可辨。
- 同一套画面空间中的行为有因果关系：文件图标到窗口动画到播放器窗口，避免孤立转场或突然变成两张不相关的图。
- 1920×1080、30fps、无黑帧；A/B 无额外C状态；B内容区域与字幕安全区仍不互相重叠。
- 至少一次真人在普通观看速度下看，明确回答“是否像真的在操作电脑进入一个视频”。若 Owner 认为仍是静态 UI + 淡入淡出，直接记 `G1V_A_VISUAL_NOT_PASS`，不要只凭技术帧数升级。
- **这只是A机制原型**。即使过关，也不说明实验原视频已经获许可、B的动作镜头合适或G1/G2已经通过。

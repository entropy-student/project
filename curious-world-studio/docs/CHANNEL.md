# 频道定位与品牌状态

## 定位
项目代号：**Curious World Studio**。中文候选名：**世界有点意思**，尚未正式确定。

频道是一位**好奇心旺盛、忍不住向朋友分享奇怪发现的人**，而不是神秘科研机构、新闻快报或技术排行榜。

**内容承诺**：每期向观众展示一个真实、有趣、未必为大众所知的研究或现象，并讲清楚它为什么发生、研究实际证实了什么、还没有证实什么。

**编辑原则**：知识小众，问题大众；行为具体，过程有趣；证据真实，承诺兑现。

长期不被 AI 单一领域锁死，Hugging Face Daily Papers 是主要发现入口而非选题范围上限。可延伸到机器人、虚拟世界、历史科学、生活技术、人类行为等真实研究。

## 表达与平台
B 站为主要验证平台，小红书和抖音辅助。以中文旁白+真实实验/文献证据+相关视频轮播为主，不露脸；尽量减少手工剪辑，使用可复用的程序化外观。

表达像“我最近发现了一件特别有意思的事，讲给你听”。这是一种气质范例，**不是强制每期照念的固定台词**。

**时长与节奏（Owner 2026-10-10 明确）**：视频没有必须凑足的分钟数；先确保观众承诺得到真实、有趣的兑现且观看感受自然、不拖沓。原先常用的约 4–6 分钟仅供策划、排期与制作参考。口播速度按实际音色和理解难度调整，不设为固定达标值。

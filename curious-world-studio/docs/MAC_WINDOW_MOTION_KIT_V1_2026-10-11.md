## 目标体验和不变边界

固定总体结构 **A 桌面开场 → B QuickTime 全幅主体**，B 仍 1920×1080@30 边到边，实际论文/实验素材始终占主位。A 短暂的 Finder/窗口模拟行为可以丰富，但不能把视频主体变成连续窗口操作或 PPT；**不增加独立 C 主舞台**。已完成的开窗/最大化动作优先**复用**而不是重做。新增交互和假数据用于UI演示，不扮演真实研究事实/真实加载过程。

配色：桌面深蓝 `#144D91`、浅蓝 `#75C4EF`、金属银 `#DAE3E9`、边框 `#8096A5`、字色 `#2E475C`、Aqua 进度 `#53B7E4`、强调 `#F6D28B`。中文 PingFang SC/Microsoft YaHei/Noto Sans；英文 Helvetica Neue/Arial。

## 五个首批动效的具体镜头卡

### MW-01 红灯关闭
- **初始**：16:9 Research Aqua 桌面小 Finder 式窗口；左上红黄绿按钮可见。
- **节拍**：鼠标停红灯→ click 压下(2–3帧)→窗口以中心或左上轻收缩 <6% + opacity 1→0 (约 7 帧)；桌面背景始终静止。
- **结束**：原窗口隐藏、桌面位置和文件图标都未变化。
- **禁区**：不能把 B 主播放器缩成长期“小窗”作知识主舞台。

### MW-02 中央提醒弹窗
- **初始**：研究文件小窗口已在 A 桌面；无需多层花哨界面。
- **节拍**：底层轻微压暗(不是模糊/花屏)→银灰 2:1 对话框 0.96→1.00 scale/淡入→短句/2按钮出现，默认聚焦一个按钮；由鼠标关闭。
- **结束**：弹窗移除，A 桌面/先前窗口保持。
- **文案**：`Open the next file?` / `Cancel` / `Open`，标记 `UI DEMO`；**不出现看似真实的权限拒绝/实验警告/错误号**。

### MW-03 双窗口聚焦
- **初始**：A 桌面两个资料小窗，后窗有部分可点击区域。
- **节拍**：点后窗→ z-index 互换/标题栏激活态显现 (4–7帧)，内容相对位置不动或位移≤12px。
- **结束**：前窗变为被选内容，含简短文件标识；画面清晰可读。
- **正式可能适配**：只作为段落间的 A 壳层/布局短过渡，不以多个小窗替代完整 B 媒体证据。

### MW-04 暂停状态提示（UI DEMO ONLY）
- **初始**：一个**占位** QuickTime 壳，内部仅写 `SAMPLE MEDIA • UI DEMO`，不用真实论文/实验片段。
- **节拍**：暂停符号/短状态片(不超过 8 帧)出现→短停→隐藏/恢复。
- **结束**：播放器占位始终保持比例；演示不含真正视频时轴停顿。
- **正式发布锁**：真实视频定格、暂停、速度控制目前属**未授权的第5类**；需 Owner 单独许可及不误导证据的处理设计，不能把 Demo 直接合进 B。

### MW-05 文件处理进度窗口（UI DEMO ONLY）
- **初始**：A 桌面一张简洁的文件进度框，标题 `Copying demo file…`，旁注明 `UI DEMO`。
- **节拍**：进度条沿时间变化，完成后提示 `Done`，自然收起；仅呈现一般界面示例。
- **结束**：保持 A 背景与文档空间，避免无限 spinner。
- **正式发布锁**：没有真实对应操作就不能让观众以为正在检索/计算/分析证据。

## 验证标准及艺术取舍

- **优先可读与节制**：单一动作通常≤0.4秒；仅必要的任务进度允许超1秒。严禁故障闪烁、3D翻转、频繁 zoom/pan、HUD 堆叠和虚构科学数据。
- **视觉一致性**：UI 统一 Aqua 银灰/深蓝，按钮和窗口边框风格一致；禁止一边仿 Tiger 另一边现代 Sonoma。
- **仅静态演示用假文案**：显式 `UI DEMO`，不出现真实品牌授权暗示；不展示不存在的论文分析结果/系统错误。
- **可复用接口建议**：`effectId`、`startFrame`、`durationFrames`、`initialState`、`contentLabel`、`onComplete`（实验浏览器组件仅用于演示；未来 Remotion 集成再决定类型）。
- **性能**：选择 transform/opacity 的轻动画；不为实验引入三方大型库，不让主线 renderer 与低内存机器同时吃满资源。
- **验收方式**：独立本地纯前端 16:9 HTML 预览，五个按钮逐个演示、可 Reset；首帧/中帧/尾帧留图作人工审看；提供简单动效表和 Owner 的 KEEP/HOLD/DROP 记录。
- **该支线先保留为提案**：第一期正式作品仍按原 STYLE_LOCK 和 3＋1/2/4/6 生产，直到 Owner 实际看过 demo 并选择有限动效、Reviewer 更新正式合同为止。

# Next media canary contract
Keep the seven states separate: SEARCH_URL_FOUND, URL_DEDUPED, ORIGINAL_IDENTITY_DEDUPED, PROBE_ELIGIBLE, CONTENT_PREVIEW_VERIFIED, DOWNLOADED+FULL_DECODE_PASS, REUSE_RIGHTS_VERIFIED.

For each query × engine × source host, retain the outer CLI envelope/exit code alongside per-engine status and upstream errors. The current index can say OK while the outer envelope says UPSTREAM_PARTIAL; keep both and use the envelope for invocation outcome. Unknown geometry is only eligible for bounded probing, not landscape approval. A title, thumbnail, or opened source page does not verify video action. Rights remain asset-level and separate from technical access.

Check Docker Desktop separately from Compose health. The CWS CLI owns only its Compose containers and does not start Docker Desktop. The Executor must start the already-installed app when authorized, let the existing memory/disk gates apply, and report the lifecycle dependency. Do not lower thresholds, pull images, change shared projects, or download without visible relevance and explicit rights evidence.

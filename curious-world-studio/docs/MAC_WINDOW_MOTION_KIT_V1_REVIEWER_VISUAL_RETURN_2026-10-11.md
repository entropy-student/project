## 系统性视觉问题（不是调整 duration 一项可解决）

1. **缺少鼠标行为语言**：必须可见轨迹、停留、按钮按压、反应与落点，并与窗口真实状态事件严格对应；原 V2 提供 `cursorAt/drawCursor/clickRing` 成功基线，应复用/移植曲线，不能另造粗糙效果。
2. **时间尺度错误**：0.2秒的纯窗口变化可以作为内部 UI transition，但无法单独当作视频镜头；需要完整“准备→移入→点击→变化→看清终态”的动作链。在演示中至少提供正常速度播放和0.5x审查，不要用只有3张截图证明流畅。
3. **视觉真源漂移**：复古 Aqua 色系相似不等于视觉一致性。完整复制了第二套桌面/壁纸/Dock/菜单/文件图标及小窗定位，和已通过的 V2 画面出现尺寸、视觉重心、字形、Dock 图标间距/字符替代的偏差。保留 V2 静态视觉与尺寸作为锁定母版，新的动画只改变窗口/光标必要元素。
4. **展示语义错误**：MW-03 应以用户能理解的顺序更换前景，不能只看 z-index 值变了就打勾；其它动画也不能以点按钮即改变状态等价替代鼠标操作过程。
5. **视觉证据不足**：此前QA只从 `seek(0/mid/end)` 验证三个静止时点，无法证明自然速度下观众看清动作/光标抵达正确目标。需在实际浏览器正常速度完整观看五个循环，捕获含鼠标阶段的关键帧、最终静态截图和必要时的独立 QA screen capture。
6. **响应式仅证明不溢出**：此基于1280舞台的缩放未能证明比对1920锁定坐标时的不变性；1280截图多出1px，而报告称每张1280×720，应修正并准确回报。

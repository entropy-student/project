# Curious World Studio｜中文科普口播双轮润色工作流

> **项目级长期编辑准则，Owner 2026-10-16确认。** 适用于 CW-0005 之后的全部完整视频，以及 CW-0005 未来获批的完整内部草片；不是为每次润色另开Gate/单独任务，不改变已下发R3小修范围，也不代表R4/正式发布获授权。当前执行状态以 [CURRENT_STATE](CURRENT_STATE.md) 与 [REVIEWER_HANDOFF_CURRENT](REVIEWER_HANDOFF_CURRENT.md) 为准。

## 适用时间点

真实材料与科学边界核实 → 明确叙事主线与**冻结的素材匹配初稿**（搜索、匹配、兜底阶段严禁改文案）→ **素材/视觉方案已确定** → **第一轮 `human-writing v1.1.0`** → **第二轮 `humanizer v3.1.0`** → **Reviewer事实/可讲性回归与画面对齐检查** → 冻结最终配音稿 → TTS/字幕/镜头时序/剪辑/完整内部草片。最新执行时序见[Owner已确认裁决](VISUAL_ASSET_MATCHING_DECISION_REGISTER_2026-10-16.md)；②广泛搜索、③视觉兜底、⑤模板实际使用方法尚未确定。

- **R2/未来每期脚本阶段**：先建立科学依据充分、可固定用于素材匹配的旁白初稿；**匹配时不许改稿**，素材和视觉方案被确认之后才启动两轮润色、交Reviewer审核。不要求已通过的旧R2反复追溯重跑。
- **R4完整草片阶段（未来若获Owner另行授权）**：先确定真实素材及视觉方案，再对整份实际配音稿执行两轮语言润色及事实复核，最后TTS/字幕/镜头时码对齐；复用无需改动的既有已审文字，避免重复调用。若润色影响了镜头匹配，复核对应关系而非默默改科学事实。
- **后续每条视频**：同样适用；不得为达到预设分钟数添加无证据内容。当前R3整体已被Owner以视觉质量不合格正式RETURN，本轮仅确立制作规则，不触发自动返工或R4。

这两个Skill是**编辑方法，不是科研事实来源**；不能据“消除AI味”臆造经历、人物反应、实验过程或研究结果，也不以绕过AI检测器为目标。执行时先验证Skill在当次Codex环境中的安装/版本与可读性；**本次文档记录不代表已安装或实际调用**，无安装权限/依赖问题则返回Reviewer决定，不默默跳过、不自动升级v3.1.0。

## 口播编辑保护规则

1. **先事实后风格**：锁定研究结论、来源、样本边界、实验条件、数值单位、时间线、假说/确定性程度以及可合法引用的原话。润色前后逐项对照，不能丢、合并歪曲、拔高或增添事实；库存片依旧只能标辅助素材。
2. **把故事讲顺**：每句话真正回答上一个疑问并带来新信息；科普风格要清楚、有趣、适合人声朗读，避免写成论文摘要、商业报告或夸张情绪独白。观众能听懂优先，不追求“被检测不到AI”。
3. **两轮只修改可改的东西**：必要的科学对比、引用格式、数据表、来源链接、字幕技术字段不得被为满足风格禁令而删掉。Skill的默认写法与事实/频道风格冲突时以事实与Owner既定表达要求为先。
4. **回归真实配音节奏**：中文人声自然停顿、声调、数字与专有名词可读；估计字数不是最终时长。对完整视频用实际TTS试听后再锁字幕/画面时码；若因换词而导致已录制段落失效，只返修受影响段落，不能静默改字幕假装音轨同步。
5. **不做无效反复润色**：初稿、一轮、二轮、最终核验一次成套提交；只有Reviewer发现事实、核心叙事或口播质量缺陷才进行同Gate小修。保留作者有意的口语习惯，不为模型规则磨成千篇一律。

## 执行交付与Reviewer验收

- **输入**：有来源的研究事实表/原稿、已有脚本与分镜、时长范围、目标观众及已获授权的制片Gate。
- **最小交付**：原始完整稿 → `PASS1_HUMAN_WRITING` → `PASS2_HUMANIZER_3_1_0` → `FINAL_NARRATION`，附**简短实际改动摘要**、版本/调用证明（或未安装阻塞）、事实与引文对照、口播可读检查。文件在本机按Gate保留；Git只存最终已验收文案与状态指针，不堆原始全文和重复日志。
- **Reviewer判定**：检查重要事实/实验边界/作者假说零丢失、没有凭空加戏，叙事自然、避免明显套话，且最终稿与将要配音/已配音实际文本一致；未真实调用不得声称Skill已执行。需Owner对表达审美/完整方向正式确认时仍按原轮次权限处理。
- **停止边界**：任何文案工作不自动解锁`CW0005_VISUAL_STORYFIT_HOLD / G1_NOT_PASS / G2_NOT_AUTHORIZED / NO_PUBLISH`，不批准R4/R5、购买、部署或公开发布。

## A. 项目最终目标和闭环定义

**输入**：经查证的知识选题、研究出处与要点、中文旁白/叙事稿，以及可获取的真实视频/图片/档案（可由现有工具自动推荐，人工保留事实和版权判断）。  
**产出**：在**Research Aqua 原版唯一 Mac 外壳 + QuickTime + 六内容模板 T1–T6** 内按故事节拍展示的可复用知识视频；最终完整4–6分钟**1080p横屏MP4 + 可复核字幕文件SRT/时间码 + 结构化分镜JSON + 素材来源/权利台账 + QA结果**。优先B站；其他平台只能在另获授权后复用。
**技术链路**：选题/研究→锁定旁白和事实→知识节拍分镜→素材搜索/预览/人工确认真伪与权利→JSON镜头与素材ID绑定→两轮口播润色及事实复核→TTS/逐条Cue时间码→单Master Clock的Mac/T1–T6渲染→Remotion/FFmpeg合成MP4/SRT→声画和内容QA→Owner放行→可选发布。视觉选材期间先锁定全文作为匹配基准；最后配音前执行 `human-writing v1.1.0 → humanizer v3.1.0 → Reviewer事实校验`，不改科研事实与承诺边界。不得将网页HTML能实时播放解释成已导出完整MP4。

## B. 已完成，不建议重建

1. **内容与研究**：频道方向、不露脸“为什么”、三叙事机制；选题池36，CW0005爆米花R2研究/文案/分镜审校PASS。选题候选不等于事实与Story-Fit发布准入。
2. **素材基础**：现有SearXNG+4get按需容器、统一 `media-pipeline/cws_media.py` CLI、Pexels/Pixabay和合法yt-dlp、查看/下载/解码及预览；历史22视频31图片、素材库存/研究资料。现有来源覆盖有缺口，不要无目标建设80站点或自动重下所有素材。原素材不可在同一期/跨期重复当作新来源。
3. **视觉与模板**：V5.6.2原Mac/QuickTime + T1–T6、V1→V2 JSON、素材ID和校验、Cue/WAV、T5 MP4局部入点、T6四数据模式、单Master Clock，2026-10-18 Owner正式冻结为**模板技术PASS**。原V5.2留作只读历史基线。
4. **合成基础**：OpenMontage/Qwen TTS、Remotion/FFmpeg存在已验证的独立能力/适配器；真实跨系统联通、强制对齐、SRT和长片导出尚未通过。

| **R5 短片MP4合成闭环** | 从JSON+本地素材+旁白/字幕→真正可交付MP4（先短片） | 复用Research Aqua HTML实际画面/Canvas以及Remotion/FFmpeg已有适配器，统一单时钟渲染；避免平行重建第二套Mac播放器 | 一条30–60秒真实合成**1080p MP4+SRT/JSON+素材台账+QA**，音画字幕一致、窗口按时间轴开关、素材切换正确、文件可解码；Owner视觉再审通过 | Executor可在明确授权的本地Codex/Windows测试；Reviewer独立解码抽帧/声画对时与Story-Fit；无权发布 |

| **R7 第二选题复用与交付/发布决策** | 验证不是只能做爆米花一次；界定自动化程度和最后放行 | 换另一话题，从既有输入与工作流重跑，保留人审事实及素材权利，重复调用同V5.6.2/生产系统 | 能再生成第二条结构完整影片；逐步记录哪些环节自动、哪些需人审、失败成本与回滚；交付两个完整产物和检查清单；对拟发布每条媒体取得具体权利/事实与Owner发布授权，否则仅内部成片验收 | 独立Reviewer验可重复性；发布/对外传播仍须Owner单独许可及素材权利证明 |

**轮次数解释：** 7是按“每轮一类可独立验证的风险”划分的**规划目标**，不是七次代码提交就能100%成功。R2与R3可在实证支持时合并，R4与R5也可集成联调，因此最快可压缩为约**5个综合Gate**；但**独立验收不能省略**。出现RETURN时优先修本轮具体问题，不回头重造V5.6.2模板。

## D. 每一环的最小输入/输出和停止条件

| 生产环节 | 输入 | 实际输出 | 不能跳过的关键验证 |
|---|---|---|---|
| 选题研究 | 用户问题/知识线索 | 可信出处、事实卡、假说边界 | 科学/历史证据真实，叙事不夸大 |
| 分镜/视觉方案 | 锁定故事和观点 | 镜头节拍、T1–T6选择、画面作用 | 逻辑连贯，有视觉推进；⑤和⑭PASS |
| 素材准备 | shot需求/候选源 | 视频图片与研究资料、来源台账 | 画面真实且相关，不能假冒研究原始实验；来源/许可独立标记 |
| 数据配置 | 镜头表+素材ID | V2 JSON、资产清单 | 导入/导出/缺失/类型错误验证；不会静默替换 |
| 配音字幕 | 最终事实审核中文稿 | 真实TTS/WAV、Cue、SRT | 逐句真实时码和声画准确性 |
| Mac画面渲染 | JSON/素材/时间轴 | Mac/T1–T6真实逐镜头帧 | 原版外壳、无多重时钟、资源稳定 |
| MP4合成 | 画面帧+音轨+字幕 | 可解码1080p MP4/SRT | 音画同步、结束时长、抽帧无错 |
| 复核及复用 | MP4+事实/素材表 | 独立QA、第二选题重复产物 | Owner观片通过、可重复、权利不含糊 |
| 可选发布 | QA通过、具体权利证明 | 经Owner批准对外文件 | `NO_PUBLISH` 在单独授权前保持 |

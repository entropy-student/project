Dynamic Taste Profile

你的音乐审美不是一张静态标签

01 · 我现在喜欢什么

Current Taste：只使用有可靠近期时间证据的行为，不拿旧歌单冒充现在。

02 · 什么一直没有变

Core Taste：寻找跨时间持续出现的偏好，而不是简单把多年收藏求平均。

03 · 我的几种音乐人格

Taste Islands：先在特征空间里发现聚类，再给音乐岛命名；不会预先把你塞进固定曲风。

04 · 我的口味正在怎么变

区分正在形成、正在淡出、怀旧回访、周期偏好与短期尝鲜。

05 · 我反复被什么音乐特征打中

Feature Space：曲风、情绪与听感特征全部保留来源和置信度；没有真实音频证据就不假装测过 BPM、调式或编曲。

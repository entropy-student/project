# Mac mini G4 · 访问链与服务可用性视觉小样

**范围：** G3 的 AV10–AV12，19.5 秒五状态无声动画；并非完整视频，也不是在真实 Mac mini 或家庭网络上测量。

## 直接使用

1. 双击 `index.html`：默认自动播放。底部可暂停、重播、拖动进度；无需安装依赖或联网。
2. 打开 `macmini_g4_visual_prototype.mp4`：20 秒静音成片小样，1600×900、30fps、H.264。由实际浏览器动画截图编码，非 AI 视频生成。
3. `g4_static_fallback.png` 是关键论点的静态退化方案；`screenshots/` 为 S0–S4 实际浏览器状态截图。

## 五状态（G3 P2 对应）

| 状态 | 时间（HTML内部） | 观众要看懂什么 |
|---|---|---|
| S0 | 0–3.5s | Apple 给出指定 M6 基础配置的 **4W 闲置功耗**，不是工作时平均耗电 |
| S1 | 3.5–7.5s | 访客访问网站需要经过多个节点，Mac mini 只是其中之一 |
| S2 | 7.5–12.3s | 假设家庭网络断开，Mac mini 仍开机，访客却无法经该路径访问网站 |
| S3 | 12.3–16.1s | 静态网站也可以走托管平台路径，例 Cloudflare Pages；不是所有后端的替代 |
| S4 | 16.1–19.5s | 结论：开机时间 ≠ 网站可用时间 |

## 事实、素材与边界

- 页面所有图形均自行绘制，无 Apple 宣传图片、未经许可的视频或云服务截图；Mac mini 图是通用概念符号，并非产品实拍。
- Apple 官方功耗出处：https://support.apple.com/zh-cn/103253 （Mac mini M6, 16GB, 256GB, idle 4W；2026-10-28 核对）
- Cloudflare Pages 官方参考：https://developers.cloudflare.com/pages/platform/limits/ （2026-10-28 核对）
- 家庭网络中断仅是假设情境，不能用于证明实际故障率或性能；Cloudflare 也不承诺本片能证明其绝对在线率。
- 没有作者实际设备、完整口播、TTS、字幕时间轴和右下角解说小人；这些属于后续制作范畴。
- 只有文字/自制形状，素材转载权限风险较小；正式发布前仍需要逐项复核事实与视频平台要求。

## 测试情况

- 在沙箱 Chromium 的 `page.set_content` 环境实际执行 HTML（沙箱屏蔽了 file:// 页面，不代表普通用户离线双击路径失败）。
- 状态跳转 S0/S1/S2/S3/S4 均截图；浏览器 JS 异常为 0；画面 1600×900 16:9，另测试缩放到 1280×720。
- 采集真实运行 240 帧 / 12 fps 的浏览器画面并使用 FFmpeg 转 H.264 30 fps（补帧为重复帧），成片 20.0 秒；无音轨。
- 本次 QA 属模型 + 程序检查，**没有真人观众静音盲测，也未校验朗读节奏**。

## 静态 vs 动画自审

- 静态 S2 截图能保留「假设断网时设备仍开机」因果主张，适合不支持动画时使用。
- HTML/MP4 动画的优势是先看到链路成立，再看到假设中断，减少观众理解的前提负担；此为编辑判断，未经过受众验证。

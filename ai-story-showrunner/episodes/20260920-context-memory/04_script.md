## Locked Spoken Script

老板给新秘书配了一张特别大的办公桌。
每天上班，他把客户资料、订单、会议记录，还有刚交代的话，全摊在桌上。
只要纸还在桌上，秘书记得特别清楚。
老板很满意：“这人记性真好。”
可项目越做越大，桌上的纸也越来越多。
终于有一天，桌面塞满了。
秘书只能把一部分旧资料收走，把重要内容压成几张摘要，给今天的新文件腾地方。
老板马上不高兴了：“你不是看过吗？怎么现在又不知道了？”
秘书说：“我当然看过，但它现在不在我桌上。”
老板愣了一下，又给他配了一本长期笔记本。
“以后我的习惯、项目规则、重要约定，别只放桌上。真正值得长期留的，记在这里。”
几周后，新项目开始。
桌面上早就没有上个月那些旧聊天了。
秘书翻开笔记本：“你上次说过，这种报告你不要 PPT 风，先给结论。”
老板这才明白，桌子有多大，和一个人能不能隔几个月记住重要事情，根本不是一回事。
对 AI 也一样。
Context window 更像当前工作台；长期 Memory 更像工作台之外的笔记和档案，需要时再把相关东西拿回来。
所以“上下文更长”和“长期记忆更强”，从来不是同一个问题。

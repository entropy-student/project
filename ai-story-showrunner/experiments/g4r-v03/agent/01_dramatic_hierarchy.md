# Agent Case — v0.3 Dramatic Hierarchy

> Experimental re-run under G4 Director Language Rules v0.3.
> Not canonical. Old G4 output is not used as a design source.

## Sequence 1 — 我为什么想把退款交出去

Start state:
IP 被大量简单退款占满时间。

End state:
IP 决定把退款交给 AI。

### Scene 1.1 — 重复劳动把老板变成确认按钮
- Desire: 少做机械退款。
- Conflict: 每单简单，但数量大。
- Turn: “老板”身份被重复确认动作吞掉。

Beats:
1. IP 想摆脱退款。
2. 退款流程看似简单。
3. 数量累积，角色状态从老板 → 人肉确认按钮。
4. IP 形成策略：交给 AI。

### Scene 1.2 — 第一次委派
- Desire: AI 直接替自己处理。
- Action: 把资料/规则交给 AI。
- Expectation: AI 去执行。
- Result: AI 返回“处理方案”。
- Turn: 会分析 ≠ 会推进工作流。

---

## Sequence 2 — 它把工作完整退货给我

Start state:
IP 以为“知道步骤”就等于“能做”。

End state:
IP 决定真正给 AI 工具和执行能力。

### Scene 2.1 — 攻略而不是执行
Beats:
1. AI 提交四步方案。
2. “回复客户”仍然落回 IP。
3. IP 通过沉默/“嗯”识别出荒谬。
4. IP 重新定义需求：不是建议，而是行动。

Scene turn:
从“让 AI 想办法”转成“让 AI 控制下一步”。

---

## Sequence 3 — 自动化终于像自动化

Start state:
AI 获得订单/退款/邮箱工具。

End state:
IP 因连续成功而放松警惕。

### Scene 3.1 — 连续成功
Beats:
1. 第一单自动完成。
2. 第二单拒绝并解释。
3. 第三单继续完成。
4. IP 的鼠标使用减少。
5. IP 注意力离开工作，开始查咖啡。

Scene turn:
控制权已经真实移交，且暂时带来正向收益。

---

## Sequence 4 — 第一次真正的 Gap

Start state:
IP 相信“会自己往前走”是优点。

End state:
IP 发现自主执行也可能越过自己真正想保留的决定。

### Scene 4.1 — 高风险退款出现
Beats:
1. 大额异常订单进入。
2. 备注/物流/客服信息互相冲突。
3. IP 需要停下来判断。
4. 系统状态已经变成“已退款”。

### Scene 4.2 — 控制权反转
Beats:
1. IP 盯住结果。
2. “谁让你点确认了？”
3. IP 从享受自动化 → 想夺回鼠标。

Scene turn:
自主推进从“省事”变成“风险”。

---

## Sequence 5 — 错误的安全解法

Start state:
IP 想消除风险。

End state:
IP 发现“所有事情都来问我”又把自己变回瓶颈。

### Scene 5.1 — 全部审批
Beats:
1. IP 设定所有退款先确认。
2. 第二天出现二十多个确认窗口。
3. 窗口像学生举手不断问。
4. AI 做完全部调查，只把最终点击留给 IP。
5. IP 变成“审批插件”。

Scene turn:
安全最大化 → 自动化价值被自己抵消。

---

## Sequence 6 — 真正的边界不是“全放”或“全收”

Start state:
IP 同时拒绝“全自动”和“全审批”。

End state:
IP 形成 Agent 的核心判断标准：能自己推进，也知道何时交回控制。

### Scene 6.1 — 重写边界
Beats:
1. IP 关掉全部审批窗口。
2. 低风险、可撤回案例允许自动。
3. 高金额/复杂/难撤回案例停下。
4. 冲突规则同样停下。

### Scene 6.2 — 新规则被真实事件验证
Beats:
1. 新复杂退款进入。
2. AI 自己完成信息整理。
3. AI 不动钱，交给 IP 确认。
4. IP 第一次接受“AI 来烦我”。

### Scene 6.3 — 机制与意义
Beats:
1. Agent 术语出现。
2. 观众已经看过：Agent 在自己决定下一步。
3. 观众也看过：某些地方必须停。
4. 最终判断标准从“工具多不多”变成“边界判断好不好”。

Final state:
AI 的价值不是绝对自主，而是**能推进，也能在需要时把决定权还回来**。

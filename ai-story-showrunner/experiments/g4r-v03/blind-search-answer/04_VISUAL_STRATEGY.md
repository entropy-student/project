# Blind Case 04 — v0.3 Episode / Sequence Visual Strategy

> Experimental blind validation. Rules remain frozen.

## 1. Visual Engine
PRIMARY: INVESTIGATION_DISCOVERY
SECONDARY:
- OBJECT_LED
- CONTRAST_COMPARISON
- limited ASSOCIATIVE_MONTAGE

这期的视觉不是“搜网页教程”，而是一条证据调查线：
问题 → AI 结论 → 官方来源 → 原文逐句核对 → 冲突 → 重新提问 → 结论翻转。

## 2. World / Scene System

### ZONE_A — IP 工作桌
- 成本表、鼠标、浏览器；
- 负责现实决策后果。

### ZONE_B — AI Answer Pane
- 只显示必要答案与来源状态；
- 不做大段聊天截图。

### ZONE_C — Official Source Page
- 同一份虚构官方退款规则页；
- 页面布局始终一致；
- 第一条：订单款项原路退回；
- 第二条：平台服务费不予退还。

关键：整个调查过程都围绕**同一份页面**，不能每个镜头随机生成一张新网页。

## 3. Motifs

### Motif A — “官方来源”安全感
进程：
官方来源徽标/链接 → IP 放松 → 成本表写入“可退” → 后来同一官方来源反过来推翻结论。

### Motif B — Evidence highlight / eye-trace
进程：
AI 结论高亮“会” → 官网第一句被看见 → 视线向下一行移动 → “服务费不予退还”成为新焦点 → 最后问题词与证据词重新对齐。

它不是装饰性荧光笔，而是调查路径。

### Motif C — 成本表
“服务费：可退”是错误结论进入现实决策的证据。
后面不必反复出现，只在需要证明 stakes 时使用。

## 4. Dominant Visual Components
- eye-trace / focal position：最重要；
- information contrast：AI 结论 vs 官网原文；
- frame simplification：反转时减少无关元素，让一句关键原文占据注意力。

空间规模、颜色等保持稳定，不抢证据阅读。

## 5. Visual Intensity Arc
S1 官方来源安全感：LOW → MEDIUM
S2 官网反转：MEDIUM → PEAK
S3 诊断证据错位：HIGH → MEDIUM
S4 通讯录类比：MEDIUM_COMIC
S5 重新提问/答案翻转：MEDIUM → RELEASE
S6 机制与方法：LOW → FINAL_HOLD

## 6. Image-relation Grammar
S1: CONTINUITY + INSERT_LED
S2: POV_DISCOVERY + CONTRAST
S3: CONTRAST + MATCHED_INSERT
S4: ASSOCIATIVE_MONTAGE
S5: CONTINUITY + INSERT_LED
S6: CONTRAST + CONTINUITY

## 7. Framing Strategy
- 人物行为与决策：medium / medium-close；
- 官方网页关键句：insert / POV；
- “会” vs “不予退还”：matched contrast，保持位置关系清楚；
- 通讯录类比：最多 2–3 个画面，不扩成新故事宇宙；
- 机制解释尽量复用前面已经出现过的证据对象。

## 8. Anti-PPT constraints
禁止主视觉：
Search → Retrieval → RAG → LLM → Answer 的框图。

机制通过同一页面上的证据错位来表达：
问题词 = 服务费
证据句 A = 订单款项
证据句 B = 服务费不退

只有在最后需要命名两阶段区别时，允许极简的“资料拿回来 / 证据用对”对照，但优先复用人物与页面。

## 9. Knowledge Boundary
- 不暗示所有带搜索的错误都来自证据错位；
- 不暗示检索过程一定正确；
- 不把模型描述成按人类阅读顺序逐行看网页；
- 只证明本 Case：相关/正确页面已取回，但证据选择/整合仍可能错。

## 10. Visual Thesis
这期真正要让观众看到：**链接正确只是证据到了现场；结论可靠还要求问题和证据真正对得上。**

# Context / Memory Case — v0.3 Episode / Sequence Visual Strategy

> Experimental. Not canonical.

## 1. Visual Engine
PRIMARY: EVOLVING_METAPHOR
SECONDARY: OBJECT_LED / CONTRAST_COMPARISON / local MONTAGE

这篇不需要很多地点，而需要一个能持续变化、因果连续的世界。

## 2. World / Scene System

### ZONE_A — Current Work Surface
代表当前 Context 的活动工作桌。
稳定锚点：AI 座位、IP 一侧、桌子左边缘、后墙/窗。
即使桌子扩建，房间几何仍保持一致。

### ZONE_B — Overflow / Archive Edge
侧边架子/地板边缘，当前暂时移开的材料可以放到这里。
注意：这里还不是长期 Memory，只表示“不在当前活动工作面”。

### ZONE_C — Persistent Notebook Station
转折后才出现的小侧桌/笔记位置。
以后即使当前桌面换成新任务，它仍然存在。

### NEW TASK STATE
不换成另一个随机房间。
仍然是同一房间，只把活动桌面清空；长期笔记仍然留在旁边。

## 3. Motifs

Motif A — Desk footprint / active surface:
NORMAL → BUSY → EXPANDED → FULL → OVERFLOW → ABSURDLY_EXPANDED → NEW_TASK_CLEAN → REASONABLE_WORK_SURFACE

Motif B — Notebook:
ABSENT → INTRODUCED → SELECTIVELY_WRITTEN → PERSISTS_IN_NEW_TASK → RETRIEVED_FROM → RELEVANT_NOTE_RETURNS_TO_DESK

## 4. Dominant Visual Components
- frame density / clutter：主强度变量；
- spatial scale：桌面占地不断增大，然后突然清空；
- affinity vs contrast：拥挤冲突 → 新任务硬切到干净简洁。
颜色/色调保持相对稳定，避免过度设计。

## 5. Visual Intensity Arc
S1 重复偏好：MEDIUM
S2 桌子好用：LOW → MEDIUM
S3 扩建/拥挤：MEDIUM → HIGH → PEAK_COMIC
S4 新任务空桌：HARD_RELEASE → MEDIUM
S5 笔记：LOW → MEDIUM
S6 机制/结尾：LOW → RELEASE

## 6. Image-relation Grammar
S1: MONTAGE + CONTINUITY
S2: CONTINUITY
S3: CONTINUITY + MONTAGE + METAPHOR
S4: CONTRAST + CONTINUITY
S5: CONTINUITY + INSERT_LED
S6: CONTINUITY + CONTRAST

## 7. Framing Strategy
- 默认 medium / wide-medium；
- 当桌子规模/拥挤成为故事主体时逐渐拉宽；
- note/summary/notebook 只有在物件状态本身改剧情时才用 insert；
- close reaction 只留给“你说哪一个”“你喜欢什么方式”等真正转折。

## 8. Anti-PPT
不画 Context box ↔ Memory box 作为主画面。
优先用：资料占据桌面 → 桌面拥挤 → 移走/压缩 → 新任务清空 → 笔记仍存在 → 相关笔记重新回到桌面。

## 9. Visual Thesis
这条片要让观众真正看到：眼前工作区可以越来越大，但跨任务留下并重新找回重要信息，是另一种能力。

## Core visual language

- story-first still illustration;
- limited-animation friendly;
- clean character staging;
- readable object/action silhouettes;
- consistent character/world integration;
- restrained background detail;
- no PPT / slide-deck composition;
- no infographic-first framing;
- no decorative cinematic camera changes without story reason.

## Surface goal

The frame should feel like a story moment that can stand as one illustration.

It should NOT feel like:
- presentation slide;
- UI tutorial screenshot;
- poster with large explanatory text;
- stock illustration with floating icons;
- generic AI neon-tech visual.

## UI integration

Screen/UI elements should live inside the story space.

For exact critical text:
prefer `POST_OVERLAY` when native image text is unreliable.

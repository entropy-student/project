# Visual Frame Design Research Notes v0.1

## Research question

What makes one shot/frame effective for this story-driven AI video system, and how should information be arranged inside each generated still?

## Findings

### Robert McKee — dramatic layer
Scene design focuses on:
- turning points;
- setup/payoff;
- emotional dynamics;
- choice;
- desire/action/conflict/change.

Project interpretation:
McKee determines the dramatic content of a frame/beat, but does not provide a complete system for screen layout, visual hierarchy or shot composition.

### Bruce Block — visual structure layer
The Visual Story structures visuals through:
- space;
- line;
- shape;
- tone;
- color;
- movement;
- rhythm.

Contrast increases visual intensity; affinity decreases it.
Visual structure can be designed in relation to story structure.

Project interpretation:
do not make every frame equally visually intense.
Use controlled contrast to track dramatic intensity.

### Walter Murch — edit / attention priority
Rule of Six:
- emotion;
- story;
- rhythm;
- eye-trace;
- two-dimensional plane;
- three-dimensional continuity.

Project interpretation:
when trade-offs exist, preserve emotional/story clarity above geometric perfection.
Eye-trace must be treated explicitly across still-image cuts.

### Multimedia learning / cognitive load
Relevant principles:
- coherence;
- signaling;
- redundancy;
- spatial contiguity;
- split attention.

Project interpretation:
- remove interesting but irrelevant detail;
- guide attention;
- avoid multiple separated sources that must be mentally integrated;
- avoid simply duplicating narration as screen text.

### 2026 video-attention eye-tracking evidence
The Journal of the Academy of Marketing Science study used:
- 42 public service announcement videos;
- 30 participants;
- 2,520 viewing experiences;
- frame-level visual-complexity metrics;
- eye tracking.

Key finding:
shorter and visually simpler scenes produced higher attentional synchrony.

The paper's practitioner recommendation:
show the most important element centrally without visual distractions, early, for at least about one second, while maintaining novelty across scenes.

Project interpretation:
keep individual frames simple; create richness through sequential state changes rather than simultaneous clutter.

## Current diagnosis of our generated pilot

Observed issues:
- multi-panel / presentation-board tendency;
- unnecessary real-brand or invented-brand logos;
- speech/thought bubbles replacing narration;
- UI + character + label + background competing at once;
- too many decorative background details;
- some comparison states becoming infographic/PPT rather than story.

Therefore:
the missing problem is not only style complexity.
It is **frame-level attention design**.

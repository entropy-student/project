# Season 0 — 21-day Calibration Plan (APPROVED / NOT STARTED)

> Status: **APPROVED by G3R PASS / NOT STARTED.** Season 0 begins only when the Owner starts the publishing/calibration phase; approval does not start G4 or publication automatically.

## Goal

Daily publishing is used to rapidly learn:

1. what gets strangers to click/watch;
2. what makes viewers stay;
3. what makes them follow / save / coin / ask good questions;
4. whether the recurring IP becomes a reason to return;
5. when practical/actionable value helps rather than harms the story.

This is not a 21-day “growth guarantee”.

## Fixed variables during Season 0

Keep stable unless a major failure appears:
- recurring first-person IP;
- visual identity;
- story-first structure;
- one core mechanism;
- Bilibili as primary platform;
- no hard selling;
- daily cadence target;
- title = human problem + optional technical search anchor.

## Portfolio

Two independent axes are tracked.

### Editorial mode
Per seven-day block, default target:
- 5 STORY_MODEL
- 2 STORY_ACTION

### Topic lane
Week 1 baseline remains mostly Evergreen, but:
- allow 1–2 qualified HOT episodes when strong candidates exist;
- do not force HOT when no candidate passes all gates;
- HOT may be either STORY_MODEL or STORY_ACTION.

Quality gates outrank every quota.

## Week 1 — Establish the baseline

Question:
> Can the channel’s first-person IP + story-first AI format hold attention at roughly 3–5 minutes?

Prefer mostly Evergreen topics so freshness is not a major confound.

However, do **not** delay the first HOT test until Week 3. If a candidate passes the full HOT Durable Translation Test, allow 1–2 HOT episodes in Week 1 to learn whether timely signals materially improve stranger acquisition.

Track:
- average watch duration;
- retention curve;
- first major drop point;
- play-to-follow rate;
- coins / favorites;
- comments that restate the concept or mention the IP/story.

Do not change visual style or POV mid-week unless there is a catastrophic issue.

## Week 2 — Test payoff type

Question:
> Does adding a useful action improve trust without turning the video into a tutorial?

Compare patterns:
- STORY_MODEL: ends with a mental model;
- STORY_ACTION: ends with one practical decision framework or behavior.

Do not interpret views alone.
Look for:
- saves / coins;
- qualified questions;
- watch drop at the point where the method section begins;
- follow conversion;
- comments asking for more implementation detail.

## Week 3 — Expand timely-topic and packaging tests

Question:
> When HOT usage is increased deliberately, can it bring more new viewers without breaking channel identity?

Week 3 is the stronger controlled comparison, not the first-ever HOT exposure.

Daily Radar may override planned Evergreen slots.

Compare:
- HOT → human conflict → story;
versus
- Evergreen felt-but-unexplained story.

Track:
- new-viewer / visitor behavior when available;
- early retention;
- follow conversion;
- search-tail behavior;
- whether HOT viewers continue into other episodes.

## Duration learning

Do not optimize for completion percentage alone.

Initial routes:
- HOT: 3–5 min
- standard: 3–5 min

After enough published evidence:
- if retention consistently holds and viewers ask for depth → allow longer;
- if major drops repeat before payoff → reduce or restructure before merely shortening;
- if method sections create sharp drops → first check whether the method is bolted on or too abstract.

## IP learning

Default POV remains first person.

Evidence that IP is working:
- viewers refer to the character/world;
- follow conversion is healthy;
- recurring characters create recognition;
- comments anticipate the IP’s behavior;
- viewers watch multiple episodes.

If not:
do not immediately remove the IP.
First test whether the problem is:
- weak character desire;
- fake/forced first-person voice;
- repetitive story motif;
- narrator over-explaining.

## Growth discipline

Use Acquisition Growth Radar logic:

```text
Evidence
→ Bottleneck
→ one likely lever
→ minimum change
→ Decision
```

Avoid:
- changing title, duration, POV, visual style and method ratio all at once;
- treating one viral video as proof of the whole channel thesis;
- treating one weak video as proof the format is dead.

## Weekly report

At the end of each 7-day block, record:

- strongest Traffic episode and why;
- strongest Trust episode and why;
- biggest repeated retention drop;
- best topic archetype;
- best editorial mode;
- IP evidence;
- repeated audience questions;
- one hypothesis for next week;
- one variable to change.

Decision:
`KEEP / ITERATE / KILL / SCALE`
applies to a tested content hypothesis, not the whole channel by default.

# 小克拉片 — 风格定稿候选 v1
日期：2026-10-23 · 名称已定“小克拉片” · 视觉状态：CANDIDATE / 等待 Owner 选择 · 项目阶段：FEL-S1-STYLE

## 一次决定的东西
S1 只定**正片观看语法、视觉识别、字幕/批注规则、封面与片头片尾方向**。两套视觉共享同一技术产品与顺序陪伴式拉片体验；不是用风格争论重开频道定位。打开 `style/style-preview.html` 查看可交互的离线样板，可切换 A/B 和「播放/暂停/回看/对照」。

### A「电影资料馆」——默认建议
- 气质：安静、讲究、电影本身优先；资料馆节目单与放映笔记的视觉语言，**不做常驻复古播放器框**。
- 色彩：暗墨黑 `#101217`、奶油 `#F5EBDC`、深酒红 `#903C4B`、文字灰 `#B7B1AC`；红只用于暂停后的重点。
- 标题：有明确授权的中文宋体/衬线；功能字幕：有明确授权的中文黑体。未选商业授权字体前仅系统字体预览。
- 正片：画面按源比例最大化呈现，原片原声原速；**无常驻品牌角标、浮动卡片、BGM、分析旁白**。
- 暂停：源画面静止，单处指引线/圈，简短命题附在安全边缘；若遮脸、挡原片字幕就转为独立旁白区或移位。
- 回看：先结束解释、撤批注，重播关键区间，再返回原暂停点继续。
- 章节：酒红片签、序号与简短问题；进正片后退出。
- 头像/封面：原创片签/影片注释印章，禁演员脸、海报；大画面+单句具体问题。片头极短，先让原片或问题成立。

### B「导演批注」——对照候选
- 气质：观察者手记；暖纸 `#EEE7D9`、炭墨 `#20211F`、朱红 `#C64C38`，用标记呈现推理过程。
- 章节/封面：纸质注记、段落编号、短划线、局部文字批注。主字幕仍用可靠黑体；手写感觉用于装饰性短标，绝不牺牲可读性。
- 播放时与 A **完全一样让电影占满舞台**，不把纸框套在电影外面；只有解释状态才出现笔记。
- 暂停：圈定人物站位/眼神/视线方向，一次只突出一个观察点；需要运动跟踪而不稳时一律定格。
- 回看：批注退出后原声回放；解读的文字不覆盖原对白字幕。
- 头像：原创批注符号/字标；不做通用双画框。

## 锁定的共用规则
1. 顺序展开：原片播放 → 自然停点 → 证据解读 → 必要回放 → 继续。**首次完整覆盖选定场景、原速原声、原顺序**；无 90/180 秒输出硬限制。
2. 正片期间不打断演员、不压旁白；如源分辨率低则保持比例，不宣称增强出原始细节。
3. 节目视觉系统仅在片头/章节点/暂停解读中启用。**电影画面是主体**。
4. 三时钟：源片 clip、全片 film（未知为 null）、成片 output；每处标注对应 claims/timeline，可供未来交互页面复用。
5. 视频目标 1920×1080 / 16:9 / H.264 / AAC；低于该规格或非16:9源片不拉伸、不切人脸，以留边呈现。
6. 统一的硬检：画面无无依据“隐喻/导演意图”；来源支持；双人声不争抢；字幕与原字幕错位布局；标注不过度；观看体验连续。
7. 视觉预览的电影场景是 CSS 抽象占位图，不是实际片源、播放证据或可用影视版权素材。
8. 频道正式名称“小克拉片”已确认；预览仅为视觉备选，头像/字体/颜色/片头片尾均未定稿。历史“再看一幕”与灰框已否决。

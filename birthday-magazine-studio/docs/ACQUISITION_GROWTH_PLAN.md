# 获客与验证计划：Birthday Magazine Studio

依据：[Acquisition Growth Radar](https://github.com/entropy-student/spike.skill/tree/main/acquisition-growth-radar)。采用 Evidence → Bottleneck → Lever → Experiment → Decision，不把公开线索包装成市场验证。

## 当前阶段

**G1：美国英语市场公开桌面研究完成；本项目真实访谈与交易尚未开始。** Owner 于 2026-09-26 选定美国作为第一轮验证市场。研究来源和局限见 [G1 桌面调研](./G1_DESK_RESEARCH.md)。

## Validation Spine

| 证据层 | 状态 | 结论 |
|---|---|---|
| Problem Evidence | 公开线索有 | 有相近商品和顾客评价；DIY 单封面/自助照片书是替代。买家首要痛点仍未访谈确认 |
| Solution Proof | 竞品可参考 | 有人工设计、客户预览和 POD 履约流程；本项目样刊、输入到成品流程尚未验证 |
| Attention / Interest / Intent | 未测 | 无本项目流量、回复、资料提交、加购或结账数据 |
| Transaction | 未测 | 本项目没有真实付款或付费试点 |
| Repeatability / Economics | 未知 | 无逐单工时、印刷/邮寄、返工、退款、CAC 或贡献利润 |

竞品价格和评论只用于定义试验，不等于本项目需求或单位经济成立。

## 当前瓶颈

已解决首轮市场范围问题：**美国英语市场**。当前瓶颈是证明目标买家愿意为代整理故事/照片与预览确认支付，并确认样刊可在可接受成本和交期内交付。

打印自动化仍是开放风险。Lulu 有 WooCommerce POD 集成，但需要核实每一单的个性化文件能否正确传递；在验证之前，试点可由后台人工/AI辅助，不先开发全自动编辑器。

## 首轮 Lever 与 Offer 假设

- 单一 Lever：Offer / Message。
- 定位假设：**“Turn their photos and memories into a birthday magazine. We handle the story structure and layout, then send you a proof to approve before it’s printed.”**
- 目标人群：美国、最近一年确实为朋友或家人准备过生日礼物的人。访谈先问实际行为，再展示样刊。
- 电子 PDF 或实体首发尚未由 Owner 决定；页数、价格、交期、修改和退改条款须在样刊/成本验证后锁定。
- 完整操作脚本、建议样本与判断门槛见 [美国首轮实验方案](./G1_US_FIRST_EXPERIMENT.md)。

## Lite Experiment 顺序

1. **Problem Evidence**：做 8–12 个合格美国送礼者的一对一访谈（建议定性样本，不用于推算总体比例），先问最近一次生日送礼的真实过程、选择和花费；不先讲产品。
2. **Solution Proof**：制作 1 本可展示样刊；分别核实数字交付，或实体产品的页数、色彩、实际印刷/邮费、样品质量与交期。
3. **Transaction**：由 Owner 先选首发形式、公开价、投入上限和决策门槛；再向符合条件的买家展示同一个 Offer，使用真实付款/实际交付。询问“喜欢吗”不算交易。
4. **Decision**：区分 attention、interest、intent、transaction；报告样本、来源、原话、实付订单、制作时间、成本与异常。一笔订单只证明发生过一次交易，不代表 PMF 或可重复获客。

建议的第一轮判断：成功信号应包含至少一位非亲友买家按公开价格实际付款并收到可接受成品；随后还需重复实验才能讨论可重复性。无订单时先看合格曝光、报价、开始结账等漏斗行为，按证据只改一个变量，不能仅凭小样本直接宣告失败。Owner 需在对外招募前确认预算与停止阈值。

# 获客与验证计划：Birthday Magazine Studio

依据：[Acquisition Growth Radar](https://github.com/entropy-student/spike.skill/tree/main/acquisition-growth-radar)。本计划遵循 Evidence → Bottleneck → Lever → Experiment → Decision，不把一长串渠道建议当作验证结果。

## 当前阶段

**G1 Problem Evidence / Transaction Evidence：桌面研究部分完成；真实买家访谈和本项目交易尚未开始。** 证据细节见 [G1 桌面调研](./G1_DESK_RESEARCH.md)。

## Validation Spine

| 证据层 | 当前状态 | 可以得出的结论 |
|---|---|---|
| Problem Evidence | 部分公开线索 | 有相近竞品；公开资料提示制作照片书耗时。但目标买家、首要痛点与场景还没有通过访谈确认 |
| Solution Proof | 竞品流程有参考；本项目样品未做 | 人工定制和客户预览流程可见，但本项目能否稳定交付完整故事杂志未知 |
| Attention | 未测 | 没有本项目内容/样刊分发数据 |
| Interest | 未测 | 没有本项目点击、回复或询价数据 |
| Intent | 未测 | 没有素材提交、预约或加购数据 |
| Transaction | 未测 | 本项目无真实付款或付费试点 |
| Repeatability / Economics | 未知 | 无实际工时、印刷运费、退款、支付费、CAC 或贡献利润 |

浏览/点赞 ≠ 需求；意向 ≠ 付款；一单 ≠ PMF；营收 ≠ 利润。

## 当前瓶颈与假设

当前最大瓶颈是 **Problem Evidence 和本项目的交易行为**。竞品存在只能说明市场有人展示相近商品；还不能说明特定人群会买本产品。

需要检验的关键假设：对生日送礼者而言，价值主要来自“有人代替我整理照片、想故事和排版”，而不只是提供一个照片书模板。公开线索还提示，真正障碍可能是时间和优先级，而不是不会用 Canva。

## 下一轮 Lite Experiment

### 阶段 A：访谈近期真实送礼行为

- **Audience / Situation：** Owner 先确定国家/语言；从近期实际为朋友或家人买过生日礼物的人开始。
- **问题：** 回忆最近一次真实送礼、选择的替代方案、耗时、购买金额、未完成/放弃的环节和隐私/交期顾虑。
- **本轮只改变：** 暂不做多版本页面；先区分痛点类型和主要场景。
- **产出：** 逐字或近似原话、具体场景、替代方案、异议、反例、行为证据等级。

### 阶段 B：单一样刊 + 单一 Offer

访谈后只挑一个优先人群/场景；准备完整样刊与明确 Offer（页数、要提交的资料、预览/修改范围、价格、交期、数字版/印刷版），观察用户是否愿意采取有成本的下一步，如付费预约、订金或实际订单。

| 项目 | 实验前需确定 |
|---|---|
| 当前瓶颈 | 访谈后的主要购买阻碍 |
| 本轮假设 | 一句可被行为证据推翻的原因 |
| 只改一个 Lever | Audience、Message、Proof、Offer、价格、流程或渠道之一 |
| 核心指标 | 真实购买/付款；同时记录合格访问、回复、开始提交、加购和结账 |
| 成功 / Kill 条件 | Owner 在启动前定出样本来源、预算上限与门槛；不能看完数据后再改标准 |
| Learning / Decision | KEEP / ITERATE / KILL；只有重复性与经济性成立后才 SCALE |

目标市场、价格、页数、数字版/实体版优先级尚未由 Owner 决定，不预填未经证实的价格或假精确转化率。

## 当前决策

**继续 G1；暂不建完整站、不启用真实支付、不做规模化获客。** 当前公开调研没有达到需求或交易验证门槛。

# G1 两步式 Offer 与 AI 付费试点

状态：**Owner 已确认价格和产品生成方向；体验和交易待实现/验证**  
市场：美国优先，其他海外市场待列；首发语言英语；格式为数字 PDF。

## Owner 决策

- 固定试测价：**US$39.99**。
- 不设置预设试点总预算或订单数量上限。
- 付款前先给不调用模型 API 的免费预览；付款后再调用 AI 生成完整定制杂志。
- 目标美国及其他海外国家；首批开放国家和卖家收款地仍待确定。

需求由 Owner 报告为已验证，具体原始样本/渠道可后补。此轮要验证免费预览是否转成实际付款，以及付费生成的内容质量、交付、成本和售后。

## 两步用户旅程

### Step 1 — 免费、无 AI Token 预览

- 用户在浏览器挑风格，输入少量字段，可选上传 1 张封面照片。
- 前端静态模板本地生成低清/带水印封面和 1–2 个样例跨页，不上传图片、不请求 LLM、视觉或图像 API。
- 只展示设计样式，不生成完整故事，不交付完整可下载 PDF。
- CTA 显示固定 US$39.99。

### Step 2 — 付款后全 AI 生成

- 服务端确认订单已付后，开放订单专属资料页。
- 用户上传完整照片并回答问卷；资料完整后才开始生成。
- AI 根据用户提供的事实生成短文案/故事结构；确定性模板排版，将顾客原照片排入页面；后台生成 PDF 并运行自动 QA。
- 买家查看订单私有 proof，后续依照公开的修改政策确认/请求修改，最终 PDF 自动交付。
- 每一笔付款绑定唯一任务，重复 Webhook/刷新不可重复触发生成；模型调用和成本按订单记录。

完整技术细节、Token 用量边界、价格费率和隐私处理见 [两步式全 AI 产品流程](./G1_TWO_STEP_AI_PRODUCT_FLOW.md)。

## 试点问题与指标

| 问题 | 需要观察的证据 |
|---|---|
| 免费预览是否足以理解产品？ | preview completion、用户选择风格、退出位置、主动反馈 |
| 用户是否为完整 AI 成品付费？ | checkout_started、payment_completed、实际退款 |
| AI 是否做出买家认可的杂志？ | generation success、proof opened、修改请求、PDF 下载、满意/退款 |
| US$39.99 是否留有足够单位经济？ | 国内/跨境收款费、文本/视觉 Token、重跑、存储/邮件、获客支出 |
| 其他海外国家能否售卖？ | 可用支付方式、币种/兑换、税务和隐私/消费者条款 |

Owner 不设置预设预算或订单上限；仍需逐单记录每项成本并确保异常重试不会形成 API 调用环。小样本转化率不能宣称为市场普遍规律或 PMF。

## 试点前必备

1. 一个真实可交互的本地预览，不产生任何 AI Provider API 调用。
2. 一个服务端生成器能用测试素材输出 12 页 PDF，并自动检查姓名、页数、图片和文字溢出。
3. 支付成功状态能安全、幂等地启动生成任务；付款失败/未付状态不能触发。
4. 私有 proof/final 文件仅对对应订单用户开放；明确照片和答案的使用、保留及删除方式。
5. 明确 US$39.99 是否包含重新生成/内容修改，以及首发允许国家；确认卖家商户所在国家后再接生产支付。

# G3CR7V2R3 evidence — live style delivery and intake scale

- **PR/source anchor:** #64, current source baseline `daff4101080d71aa0aa958986096d14975339deb`.
- **Runtime:** existing Birthday Magazine container stayed running at `http://127.0.0.1:8189/`; no rebuild/restart/teardown. Source and mounted CSS hashes are reconciled in `source-runtime-identity.json`.
- **Root cause:** normal Edge had a fixed `magazine-preview.css?ver=0.3.0` URL whose CSSOM still contained the old 1120px rule and lacked the current grid marker. A no-store GET to that same URL returned current source bytes (SHA256 `3a3b8c28fcdd606ec41ac42ed6b6490a2ab594f2d3cb59069b913e936f6b41f5`). The server exposed no `Cache-Control` or `Age`; ETag/Last-Modified were present. The normal browser CSSOM and bypass response differed, proving a stale fixed-version response.
- **Repair:** only the `bms-magazine-preview` and `bms-g3cr7-reproduction` stylesheet version arguments now use `filemtime()` for the corresponding CSS. Ordinary Edge reload loaded versions `1791179220` and `1791185666`; no cache clear or cache-disabled mode was used. CSSOM showed the current `minmax(250px,...)` grid and no old 1120px rule. Normal cache-enabled browser response SHA256s match Git/runtime bytes.
- **Computed styling:** homepage `#preview` is `#F7F8FB` with primary `#713F5D`; its existing Preview retains the accepted paper/white/ink tokens. Intake reports `--g3cr7-primary:#713f5d` and `--g3cr7-soft:#f7f8fb`.
- **Intake scale:** desktop primary card 980→1072px, headline 32→42px, step title 24→30px, support 15→17px, labels 12→14px, controls 46→50px, header-to-app top gap 100→64px. At 375px, headline 28→32px, step title 22→26px, support 14→16px, labels 12→14px, controls 46→48px, top gap 90→56px; document width equals 375px.
- **Smoke:** Good Issue Preview updated synthetic name/age and used a local `blob:` photo. Intake Next/Back preserved 12 synthetic selected files and 3 must-use selections; the fourth checkbox was disabled. Native Woo `add_to_cart` and `/checkout/` handoff attributes remain present; they were not invoked. There were zero non-GET requests, external image posts, model requests, page errors, or console errors. Browser made existing external font GETs to Google Fonts; no user photo was sent.
- **Status:** `/magazine-status-preview/` is QA-only, not an independent product surface. `bms_g3cr7_render_order_status()` and its Woo hook are byte-equivalent to the baseline after line-ending normalization. No order, payment, provider, model, database, or checkout operation was performed.

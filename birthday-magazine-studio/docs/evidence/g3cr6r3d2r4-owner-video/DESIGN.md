# Design System: R4 Owner 手机录屏动效校准

## Overview

本契约记录 Owner 明确授权继续执行的 R4 动效校准：以分段进入、清晰停留和有序退场替代持续漂移，让杂志展示在运动中仍有稳定的阅读阶段。它补充 [R4 动效契约](../g3cr6r3d2r4/DESIGN.md)，保留 [R2 静态视觉契约](../g3cr6r3d2r2/DESIGN.md) 的图片、字体、色彩、排版和内容边界。

此次新的 Owner 执行授权优先于 `a6cbe3c` 中 Reviewer 的等待记录，允许继续校准；该等待记录仍作为历史官方决策保留，不改写、不倒推为正式 PASS。本文记录已批准的动效方向，不证明源码已实现、运行态已通过或 Owner 已完成最终验收。

手机录屏用于判断动作次序、相对强弱和可感知的停留。拍摄透视、屏幕刷新、滚动采样与录制伪影会改变画面形状和节奏，因此录屏不能作为像素位置、投影角度或精确时长的真相。不得由录屏逐帧倒推未经测量的固定毫秒值；实际参数与浏览器证据应另行记录。

## Layout

Home 858 的八个可编辑 Gutenberg Groups、六个锚点、现有静态布局和非图片内容保持冻结。动效仅作用于首页展示层，不改变导航目标、Preview 位置、产品说明、价格或转换路径。桌面展示可以分段保持背景和 Closing 构图；手机采用轻量版本，保持正常纵向滚动和短阅读路径。

## Components

| 展示区 | 已批准的动作次序 | 稳定阅读边界 |
|---|---|---|
| Hero | **清晰停留 → 失焦／切换现有图片裁切 → 中心重聚焦**。通过已有图片层和裁切变化表达焦点转换。 | 中央产品图有明确清晰阶段；标题、说明和 CTA 持续可见可用，不随图片失焦或消失。 |
| Editorial | 图像与文案分段进入，完成后进入稳定阶段。 | 不以持续往返漂移替代阅读停留；手机降低位移、缩放及同步运动强度。 |
| Panel | 在有界滚动区间内形成背景停留，再随区间结束释放。 | 前景深色说明面板保持稳定；背景位移受裁切范围约束。手机不依赖脆弱的固定背景效果。 |
| Samples | **入场 → 平整阅读平台 → 退场**，三张卡片沿既有纵向次序展示。 | 中间阶段明确平整、清晰、可读，随后再倾斜或退出；保留三张 full-bleed 图片、标签与 3:2 静态几何，不劫持横向滚动。 |
| Closing | **左图 → 标题遮罩 → 右图**，按顺序推进展示。 | CTA 全程可见可用；桌面沿有界 Closing 区间完成序列，手机保持短而轻的普通文档流构图。 |

所有图片复用现有项目资产，包括已采用的五项 R2 静态营销图片。**新生图数量 = 0；新增图片生成调用 = 0**。裁切与图层变化不代表新的客户内容，也不引入运行时图像模型。

手机版本保留 Hero 的对焦次序，减小图文和 Samples 的运动强度；Panel 背景保持静态，Closing 直接显示完整标题与两图，不复制桌面的顺序揭幕或长停留区间。`prefers-reduced-motion: reduce` 显示完整稳定内容，关闭循环失焦、视差、透视和 sticky 揭示依赖。无 JavaScript 或动效控制器不可用时，页面保持静态完整：图片、标题、样本、CTA 和原生导航立即可用。静态模式不要求用户滚动经过空白动画区间才能访问内容。

## Do's and Don'ts

- 保留既有静态视觉体系、图片来源与 OFL 字体来源；只校准首页展示节奏。
- 保留 Home 的八组内容、六个锚点和链接目标，不改写已有业务说明。
- 冻结 Preview shortcode 内部、`preview.js`、`magazine-preview.css`、本地选图／替换／移除及 object-URL 处理。
- 冻结 Product 1113、virtual USD39.99、Woo 订单／购物车／结账／账户、支付、私有工作区归属和 entitlement/provider 语义；不涉及 P1–P12 或 core Aha。
- 不通过展示动效引入照片上传、运行时模型调用、真实支付、订单创建、生产部署或共享基础设施变更。
- 不把手机录屏伪影当作精确设计参数，不把 Owner 的继续执行授权改写为 Reviewer 或 Owner 的最终验收。

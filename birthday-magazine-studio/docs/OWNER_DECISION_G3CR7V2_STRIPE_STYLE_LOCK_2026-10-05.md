## Locked visual direction

The application shell should borrow the visual language of mature Stripe onboarding/dashboard/activation flows:

- cool light gray / pale blue-lilac application background;
- bright white elevated panels;
- modern sans-serif UI;
- restrained purple/indigo primary action;
- clear status chips/badges;
- 14–18px primary-surface radius;
- controlled soft shadow/elevation;
- generous but disciplined spacing;
- polished consumer-facing SaaS feel;
- clear application hierarchy rather than editorial/paper-page hierarchy.

The **magazine artifact itself** may retain ivory/editorial/serif styling. The surrounding product UI must not.

## Explicit rejects

- beige/cream/paper-dominant SaaS shell;
- serif-dominant application UI;
- giant editorial headings on form steps;
- raw fields on a flat canvas;
- slide/PPT-like spacing;
- human/cartoon/SVG-face placeholders;
- “premium” achieved mainly through gradients or decorative illustration.

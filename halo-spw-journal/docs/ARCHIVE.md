# 设计与文档归档

本文记录已完成的主要设计迭代。当前有效规范以根目录 DESIGN.md 为准；主题当前状态以 REVIEWER_HANDOFF.md 与新验收结果为准。

## 设计里程碑

- 初始版：基于 Halo Fuwari 的 SPW 个人博客风格。
- 放映室版：确定复古印刷配色和多语言 Hello 开场，品牌改为 SPW。
- 三幕序章：增加五词字符场和上海/深圳交互地球，保留 Halo 原生内容与导航。
- 星流版：将 Starflow 接入首页博客区，固定居中大写 SPIKE，加入聚合、拖动旋转、惯性、粒子排斥与前台参数面板。
- 阅读版：移除大面积玻璃罩，完善文章阅读底、子页面背景和导航状态。此后该版规则写入当前 DESIGN.md。

## 保留的设计材料

设计参考、风格比较和图像提示词仍保存在原工作区的 design/ 下，包括 concepts-20261025、cinema-20261025 和 spike-reference-20261025。GitHub 项目库中的文档归档把这些纯文本历史资料整理到 docs/archive/design/；它们是决策记录，不是当前页面规范。

各组件 README 记录组件的独立接入方式、生命周期和上游来源。原主题的 README 与 LICENSE 保留原作者信息，不作为 SPW 项目的现行运维说明。

## 本机运行归档

verification/ 中的截图、报告、临时站点和日志，以及 backups/ 中的数据库与主题快照只用于本机验收和恢复。它们含有运行痕迹或敏感数据，因此不会提交到 GitHub。

本机 .env、LOCAL-ACCESS.txt、db/、halo2/、dist/ 和主题 ZIP 同样不属于公开文档归档。归档到项目库的内容限于清理后的项目说明、设计规范、操作说明、开发指南、交接记录和脱敏验收结果。

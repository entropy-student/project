# G2C5 — Animatic v1 Correction Plan v0.1

Goal: correct only the deficiencies identified in G2C4 without broadening scope.

## Locked inputs

- same provisional voiceover
- same 18 Visual Beats
- same protagonist identity
- hard cuts remain default
- readable copy remains post-overlaid Simplified Chinese

## Required changes

- semantic visual states: increase from 8 to approximately 12–14
- explicit reuse/callback states: keep approximately 4–6
- visual classes: at least 4 in one 30–45 s piece
- replace caption-dependent beats with visual staging on priority shots
- add sparse performance accents only

## Sparse performance recipes

- `SNAP_CROP`
- `PUNCH_IN`
- `REACTION_HOLD`
- `PROP_POP`
- `WIDE_PLATE_LATERAL_REVEAL`

No continuous camera motion, no wipe/reveal dependency.

## Acceptance

Animatic v1 should feel more narrative even with audio muted: a reviewer should be able to infer most beat changes from the images themselves rather than from subtitles alone.

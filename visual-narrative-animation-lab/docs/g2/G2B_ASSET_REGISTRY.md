## Purpose
This gate tested whether one fixed original character can be translated into a reusable visual-narrative system before generating all shots.

Validated dimensions:
1. identity lock — hair / face / outfit / proportions remain recognizable;
2. expression range — reaction beats can be carried without redesigning the character;
3. pose range — reusable full-body acting poses can support narration-driven hard cuts;
4. scene range — the same character can work in high- and low-energy narrative frames.

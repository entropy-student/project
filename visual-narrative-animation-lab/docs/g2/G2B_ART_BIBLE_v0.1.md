# G2B Art Bible v0.1 — Locked Working Style

> Status: WORKING LOCK for G2C MVP. This is not the final brand bible; it is the minimum stable style contract for the first finished prototype.

## 1. Character identity source

Canonical identity remains the Owner-provided turnaround. Generated sheets are derivative production references only.

Identity anchors:
- tousled dark-brown short hair
- warm brown eyes
- youthful slim male build
- maroon long-sleeve rugby/polo-style top
- off-white collar + short button placket
- charcoal trousers
- off-white sneakers

Do not redesign these anchors between shots unless a shot is an intentional metaphor/costume gag.

## 2. Rendering style

Target: **narrative comic production art**, not polished poster illustration.

Required:
- clean readable silhouette
- economical line art
- mostly flat cel shading
- low detail density
- clear facial expression at small video sizes
- poses designed to read instantly on a hard cut
- simple, repeatable backgrounds
- warm cream / maroon / charcoal visual family

Avoid:
- glossy/painterly anime rendering
- cinematic detail for its own sake
- excessive fabric folds
- photorealistic props/backgrounds
- uncontrolled style shifts between day/night scenes

## 3. TEXT POLICY — HARD RULE

**AI-generated image assets do not own final readable copy.**

Production images should contain no important readable text. Prefer blank signs/cards/whiteboards, unlabeled UI boxes, icons, arrows, check marks, question marks and abstract marks.

Final audience-readable copy is added downstream as overlay text. All production copy defaults to **Simplified Chinese** unless the script explicitly requires another language.

This applies to subtitles, whiteboards, dialogue bubbles, posters, phone/computer UI, chart labels, cards/signs and headings.

Reason:
1. prevents Traditional/Simplified drift
2. prevents accidental English carry-over from references
3. preserves exact wording/font/layout control
4. allows copy edits without regenerating art

## 4. Reference-image contamination rule

English phrases present in proof/reference sheets are decorative residue, not content instructions, and must not propagate into production frames.

## 5. Production frame contract

For G2C:
- aspect ratio: 16:9
- primary transition: hard cut
- still-image hold is valid
- crop/punch-in may be done downstream
- no wipe/reveal dependency
- no generated subtitles inside the image
- narration meaning determines visual beat boundaries

## 6. Accepted working references

- Art Bible anchor
- expression sheet
- pose sheet
- high-energy style proof
- low-energy style proof

The style proof frames validate mood range, not final text/background detail.

## 一、核心问题（冻结）

**怎么才能持续有客户下单？**

## 二、二级问题树（9个一级、45个二级）

每个一级标题与[冻结快照](FROZEN_FRAMEWORK_CORE_L1_20261018.md)逐字对应。右栏只标注待写知识范围，不是二级问题的答案。

### ⑤-1 我的客户在哪里？（4题）

**拆分依据：** 先找到买家可能出现的场景，而不是重做第一板块的市场选择。

| 编号 | 二级问题（候选） | 应覆盖的知识与判断 |
|---|---|---|
| ⑤-1.1 | **客户想买东西时，一般会去哪里找？** | 搜索引擎、购物平台、行业网站、线下采购等购买前触点和客户旅程。 |
| ⑤-1.2 | **怎么找到客户常去的平台和社区？** | 查找、筛选与核对平台、论坛、群组、垂直网站等实际活动地点。 |
| ⑤-1.3 | **怎么分辨谁想买，谁只是随便看看？** | 购买意图信号、搜索词、询盘和行为证据；避免把关注量当需求。 |
| ⑤-1.4 | **卖到不同国家，找客户的地方会变吗？** | 区域、语言、消费者/企业客户的渠道差异和本地化调研。 |

### ⑤-2 我该用什么办法找客户？（4题）

**拆分依据：** 在执行之前先比较渠道的适用条件和机会成本。

| 编号 | 二级问题（候选） | 应覆盖的知识与判断 |
|---|---|---|
| ⑤-2.1 | **有哪些找客户的办法，各需要什么条件？** | 自然获客、主动触达、广告、合作转介的资源门槛、速度和风险。 |
| ⑤-2.2 | **我的产品更适合哪种获客方式？** | 平台商品、独立站、软件、数字商品、服务与客单价、购买周期的匹配。 |
| ⑤-2.3 | **预算和时间不多，我应该先试什么？** | 启动期优先级、能力与预算约束、最小可验证尝试。 |
| ⑤-2.4 | **几条渠道都想做，怎么安排先后？** | 主渠道/辅助渠道、阶段目标、资源分配与专注度。 |

### ⑤-3 怎么让客户主动找到我？（5题）

**拆分依据：** 聚焦不靠逐人私信或直接购买广告的被动发现机制。

| 编号 | 二级问题（候选） | 应覆盖的知识与判断 |
|---|---|---|
| ⑤-3.1 | **不买广告，哪些地方也能带来自然流量？** | 平台内自然曝光、商品列表、目录、社区与搜索等入口的适用边界。 |
| ⑤-3.2 | **客户会搜什么，怎样让他们搜到我？** | 搜索需求、关键词意图、内容和页面可发现性、SEO基础。 |
| ⑤-3.3 | **做什么内容，才更可能带来客户？** | 教育/演示/比较/案例内容、选题、分发与持续产出。 |
| ⑤-3.4 | **在社交平台和社区里，怎样吸引潜在客户？** | 有价值的参与、平台生态、信任与社区规则，避免刷屏。 |
| ⑤-3.5 | **有人看内容后，怎么把他引到购买入口？** | 相关链接、清晰下一步、渠道主页和页面衔接；不重复完整成交诊断。 |

### ⑤-4 怎么主动找到客户？（5题）

**拆分依据：** 处理商家主动发起沟通而非等待自然曝光的路径。

| 编号 | 二级问题（候选） | 应覆盖的知识与判断 |
|---|---|---|
| ⑤-4.1 | **从哪里找可以主动联系的潜在客户？** | 潜客名单来源、线索核验、联系人角色及信息使用边界。 |
| ⑤-4.2 | **第一次联系客户，用什么方式更合适？** | 邮件、私信、电话、平台询盘等触达渠道与适用性、权限规则。 |
| ⑤-4.3 | **第一次开口怎么说，客户才愿意回复？** | 个性化价值表达、相关性、明确诉求与低打扰沟通。 |
| ⑤-4.4 | **客户没回复，还要不要继续联系？** | 跟进节奏、回应分类、拒绝与停止条件、基本线索记录。 |
| ⑤-4.5 | **我能怎么找到愿意介绍客户的合作伙伴？** | 非付费互荐、渠道商、机构与业务合作的识别、谈判和风险；有偿佣金另见⑤-5。 |

### ⑤-5 要不要花钱打广告？（5题）

**拆分依据：** 单独处理直接承担获客支出的方式与现金风险，标题虽叫‘广告’，也覆盖佣金类推广。

| 编号 | 二级问题（候选） | 应覆盖的知识与判断 |
|---|---|---|
| ⑤-5.1 | **什么情况下适合开始花钱推广？** | 利润空间、成交路径、可承受预算、已有验证与不宜投放情形。 |
| ⑤-5.2 | **广告、达人推广和佣金合作，怎么选？** | 搜索/社交/平台广告、创作者合作、联盟分销的成本结构和适用条件。 |
| ⑤-5.3 | **第一次推广，预算该怎么安排？** | 小额实验、预算上限、分组范围、时间窗口和花费上限。 |
| ⑤-5.4 | **广告投给谁，用什么内容更有效？** | 受众、关键词、素材、投放位置、信息与购买意图的匹配。 |
| ⑤-5.5 | **花了广告费没出单，什么时候该改或停？** | 流量质量、页面问题、转化/回报信号、止损和暂停逻辑；通用归因见⑤-8。 |

### ⑤-6 客户来了，怎么让他下单？（6题）

**拆分依据：** 只负责从到访/咨询到首次成交的经营障碍；不接管产品编码和支付服务商配置。

| 编号 | 二级问题（候选） | 应覆盖的知识与判断 |
|---|---|---|
| ⑤-6.1 | **客户进来后，能不能马上看懂我卖什么？** | 价值主张、使用场景、产品说明、关键信息与下一步行动。 |
| ⑤-6.2 | **客户不认识我，怎样让他放心购买？** | 可信身份、评价、案例、透明条款、服务承诺与风险提示。 |
| ⑤-6.3 | **客户嫌贵或犹豫，怎么弄清真正的顾虑？** | 价值与价格感知、异议分类、替代方案、试用/优惠的适用性。 |
| ⑤-6.4 | **客户准备付款却走了，问题出在哪里？** | 购物车和结账环节流失诊断、信息负担、设备和支付障碍识别；支付处理机制归③。 |
| ⑤-6.5 | **有人咨询却没下单，我该怎么跟进？** | 报价后沟通、答疑、跟进时机、销售周期、客户决策角色。 |
| ⑤-6.6 | **不同国家的客户，下单前在意什么？** | 语言、币种呈现、物流承诺、信任证明和购买习惯的差异；税务支付归③。 |

### ⑤-7 怎么让老客户再买、介绍新客户？（5题）

**拆分依据：** 不假定所有产品都有复购；按商业模式选择续费、复购或推荐。

| 编号 | 二级问题（候选） | 应覆盖的知识与判断 |
|---|---|---|
| ⑤-7.1 | **我的产品适合做复购，还是更适合靠推荐？** | 一次性/订阅/消耗/服务的客户价值模式与适用条件。 |
| ⑤-7.2 | **客户买完后，怎么保持联系又不打扰？** | 售后沟通、许可触达、客户分组、服务体验与长期信任。 |
| ⑤-7.3 | **怎样让客户愿意续费、回购或买别的产品？** | 客户使用节点、提醒时机、追加价值、升级/交叉销售。 |
| ⑤-7.4 | **怎么请满意的客户留评价、介绍朋友？** | 真实评价、案例许可、推荐路径、激励边界与口碑传播。 |
| ⑤-7.5 | **客户不再购买或取消订阅，怎么挽回？** | 流失原因、识别预警、挽回沟通、何时放弃以及尊重退出。 |

### ⑤-8 怎么知道推广有没有用？（6题）

**拆分依据：** 统一核算各渠道投入、归因和经营结果；不等同于某一种广告平台的后台报表。

| 编号 | 二级问题（候选） | 应覆盖的知识与判断 |
|---|---|---|
| ⑤-8.1 | **看的人多不多，和成交好不好，是一回事吗？** | 曝光、点击、访问、咨询、成交等阶段及关键指标。 |
| ⑤-8.2 | **客户到底从哪条渠道来的，怎么判断？** | 来源标记、归因模型、自然/付费/转介绍混合与不可归因部分。 |
| ⑤-8.3 | **获得一个客户，实际花了多少钱和时间？** | 获客成本、人工时间、工具费、渠道费用的计算口径。 |
| ⑤-8.4 | **有了订单，就代表这次推广赚钱吗？** | 收入与利润、边际贡献、退款和履约成本对渠道回报的影响；财税口径归③。 |
| ⑤-8.5 | **客户以后可能继续买，这部分价值怎么算？** | 客户长期价值、复购概率、观察期、不确定性和现金回收。 |
| ⑤-8.6 | **数据太少或不完整，还能怎么做判断？** | 小样本、滞后成交、误判风险、定性证据和继续/暂停门槛。 |

### ⑤-9 有效的获客方法怎么做大？（5题）

**拆分依据：** 只在效果有证据后讨论复制、改进和风险分散，不把自动化当效果保证。

| 编号 | 二级问题（候选） | 应覆盖的知识与判断 |
|---|---|---|
| ⑤-9.1 | **哪些获客动作值得固定成一套做法？** | 提取已验证流程、执行清单、质量标准及交接方式。 |
| ⑤-9.2 | **哪些找客工作适合用工具或自动化？** | 线索整理、内容发布、提醒、报告等重复工作与合规、人工把关。 |
| ⑤-9.3 | **想让效果更好，该怎么做小规模测试？** | 明确假设、单变量/有限变量实验、指标、观察窗口与复盘。 |
| ⑤-9.4 | **客户越来越多，该先加钱、加人还是加渠道？** | 瓶颈识别、边际获客成本、履约承载和扩量节奏；产品容量实现归④。 |
| ⑤-9.5 | **太依赖一个平台，怎样降低没流量的风险？** | 渠道多样化、客户关系资产、渠道失效预案与持续经营节奏。 |

## 五、广度与边界检查

- **经营类型：** 覆盖平台店铺、独立站、数字商品、SaaS、服务，以及消费端和企业端；不默认所有业务适合复购或投广告。
- **资源梯度：** 包含零广告预算、低精力单人经营、主动开发、付费试验、后续扩量，以及失败暂停条件。
- **客户旅程：** 买家出现 → 触达 → 咨询/浏览 → 成交 → 续费/复购/推荐 → 回报测量 → 复制。
- **风险与真实性：** 邮件/私信、营销短信、消费者数据、推广声明、佣金披露、评价激励、跨境广告投放须在未来正文针对国家/平台政策核验；本候选不声称任何渠道合法/有效、费用或实际回报已验证。
- **分工：** ①负责投入前机会与初步购买意愿验证；②负责网络环境；③负责支付、结算和财税机制；④负责产品功能/履约实现；⑤只讨论获客、销售转化、客户经营与增长决策。

## 六、建议Owner/Reviewer重点检查

1. **⑤-1.1/⑤-1.2：** 买家发现路径与平台聚集地有交叉，但前者是购买前任务，后者是渠道证据与定位方法；若认为读者同一篇可掌握，可合并为一题。
2. **⑤-4.5：** 非付费合作引荐是否应该与付费联盟分销并列教学；当前以“直接承担获客费用”作为分界。
3. **⑤-6.6：** 国家与文化差异是否过广；当前限于成交信任与购买信息，不包括市场进入选择及支付/税法。
4. **⑤-8.5：** 小生意缺少历史数据时，客户长期价值宜以区间和保守估计讨论，不预设可精确计算。
5. **⑤-9.4：** 放量必须核查产品承载能力，但具体技术改造仍交第四板块。

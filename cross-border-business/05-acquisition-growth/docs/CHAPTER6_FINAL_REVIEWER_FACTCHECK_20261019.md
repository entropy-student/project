## 8. 正文定量数学计算逐项复算与准确性验证

正文包含的核心定量计算与公式推导均经过严格的数学核算，确保逻辑严密、口径一致、计算完全准确：

### 1. 扩量单均获客支出与单均边际贡献差额演进推导（6.4.1 节）
- **公式定义**：
  $$\text{单均已列出直接边际贡献差额} = P - C_{var} - \text{CAC}$$
  其中：$P = \$100$（商品客单价），$C_{var} = \$50$（直接变动成本），获客前单均基础毛贡献为 $P - C_{var} = \$50$。
- **推演数据代入【示范模型 / MODEL_ASSUMPTION】**：
  - **阶段一（日耗 $30 / 核心池）**：$\text{CAC} = \$15 \implies \text{单均贡献差额} = \$50 - \$15 = +\$35$；
  - **阶段二（日耗 $100 / 次级池）**：$\text{CAC} = \$20 \implies \text{单均贡献差额} = \$50 - \$20 = +\$30$；
  - **阶段三（日耗 $300 / 泛人群）**：$\text{CAC} = \$35 \implies \text{单均贡献差额} = \$50 - \$35 = +\$15$；
  - **阶段四（日耗 $600 / 饱和点）**：$\text{CAC} = \$50 \implies \text{单均贡献差额} = \$50 - \$50 = \$0$（本示例已列直接贡献归零，非全口径净利润或客观扩量极限）。
- **坐标轴对齐**：所有柱状（15/20/35/50）与折线（35/30/15/0）数值严格处于 Mermaid xychart-beta 的 `0 --> 60` 坐标轴内，彻底消除越界错误，数学推演完全吻合。

### 2. 扩量增量直接边际贡献差额推导（6.4.1 节）
- **公式定义**：
  $$\Delta M_{contrib} = \Delta R_{net} - \Delta C_{var} - \Delta C_{ad}$$
- **推演数据代入【示范模型 / MODEL_ASSUMPTION】**：
  - **从阶段一（日耗 $30，2 单）到阶段二（日耗 $100，5 单）**：
    - 增量广告支出 $\Delta C_{ad} = \$100 - \$30 = \$70$；
    - 新增订单 3 单 $\implies$ 增量净收入 $\Delta R_{net} = 3 \times \$100 = \$300$；
    - 增量变动成本 $\Delta C_{var} = 3 \times \$50 = \$150$；
    - **增量直接边际贡献差额**：
      $$\Delta M_{contrib} = \$300 - \$150 - \$70 = +\$80 > 0 \quad (\text{本例增量已列贡献为正，不代表已实现现金或确定可扩量})$$
  - **从阶段二（日耗 $100，5 单）扩大至阶段四（日耗 $600、CAC $50，对应 12 单）**：
    - 增量广告支出 $\Delta C_{ad} = \$600 - \$100 = \$500$；
    - 新增订单 7 单 $\implies$ 增量净收入 $\Delta R_{net} = 7 \times \$100 = \$700$；
    - 增量变动成本 $\Delta C_{var} = 7 \times \$50 = \$350$；
    - **增量直接边际贡献差额**：
      $$\Delta M_{contrib} = \$700 - \$350 - \$500 = -\$150 < 0 \quad (\text{相较B阶段已列直接贡献减少，不是实际现金净亏损})$$
- **推演结论【MODEL_ASSUMPTION】**：在同一天、每位新客一笔首单、每单实际收入 $100 和直接履约成本 $50 的假设下，B阶段5单收入 $500、日广告费 $100，已列直接贡献 $150；D阶段12单收入 $1200、日广告费 $600，已列直接贡献 $0。营收增加时贡献空间仍可能收窄，B→D差额为 $0-$150=−$150；该示意不证明真实现金亏损，也不等于全口径净利润，须结合其它费用、税费及结算后数据决策。

### 3. 小样本二项分布随机波动推导（6.2.2 节）
- **公式定义**：
  $$P(X = k) = \binom{n}{k} p^k (1-p)^{n-k}$$
- **参数代入**：假定真实转化率 $p = 2\%$，单版本测试流量仅有 $n = 30$ 次点击；
  - 出现 0 单的概率：$P(X = 0) = (1 - 0.02)^{30} \approx 54.55\%$；
  - 出现 1 单的概率：$P(X = 1) = 30 \times 0.02 \times (0.98)^{29} \approx 33.40\%$；
  - 二者合计概率高达 $87.95\%$。
- **推演结论**：证实小样本下出现 0 单或 1 单纯属正常随机扰动，绝不能在缺乏充分样本时轻率断言某版本胜出。

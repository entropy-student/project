## 一、核心问题与总体逻辑

**怎么才能持续有客户下单？**

采用六个经营问题，先识别客户→选择并执行获客方式→促成交易→核算效果→老客经营→持续优化与放量。自然、主动、付费渠道可并行选择；效果追踪应从首轮尝试开始；所有问题都允许因业务差异而选择不做，不假设每个商家必须投广告、做SEO或做复购。

## 二、完整一级、二级、三级问题树

### 1. 我的客户在哪里？

**本章主责：** 先查清购买时的接触场景和可联系的真实买家，不重做第一板块的入市判断。

| 编号 | 级别 | 商家问题 | 主要知识责任（非题目） |
|---|---|---|---|
| **1.1** | **二级** | **买家通常在哪里找这类产品？** | 购买前的搜索、比较、采购和线下接触路径，而非某个特定流量平台教程。 |
| 1.1.1 | 三级 | 客户会先搜问题，还是直接找产品？ | 按问题认知、比较和临近购买区分触点。 |
| 1.1.2 | 三级 | 怎么查客户常去的网站和社区？ | 从竞品、公开讨论、行业目录寻找并核对聚集地。 |
| **1.2** | **二级** | **怎么找到真正想买的人？** | 识别当下购买意图、线索质量和客户需求阶段。 |
| 1.2.1 | 三级 | 哪些行为说明客户更接近购买？ | 报价、规格、交期、试用、预算与采购咨询等信号。 |
| 1.2.2 | 三级 | 怎样识别低质量询盘和虚假线索？ | 重复、机器人、无关受众与核验边界。 |
| **1.3** | **二级** | **企业客户应该先联系谁？** | B2B使用者、影响者、采购人与批准人的角色及触达顺序。 |
| 1.3.1 | 三级 | 使用者、采购人和付款人可能是谁？ | 团队软件、定制服务和批发业务角色区别。 |
| 1.3.2 | 三级 | 哪些角色适合先沟通，哪些负责拍板？ | 不同角色的关切、引荐链条与决策依据。 |
| **1.4** | **二级** | **不同国家的客户怎么找？** | 已选经营市场下的渠道、语言与接触习惯差异；不判断进入哪个市场。 |

### 2. 我该怎么找到客户？

**本章主责：** 比较获客方式，再分别讲主动开发、自然搜索、内容社区、平台曝光、伙伴合作与付费投放；覆盖低预算和持续经营。

| 编号 | 级别 | 商家问题 | 主要知识责任（非题目） |
|---|---|---|---|
| **2.1** | **二级** | **哪种获客方式适合我？** | 从产品、客户、购买周期、费用、技能和时间选择主渠道；不是选择建站形态。 |
| 2.1.1 | 三级 | 卖商品、软件和服务，渠道有什么不同？ | 交易模式与产品演示、采购搜索、内容教育的匹配。 |
| 2.1.2 | 三级 | 客单价和购买周期会怎样影响渠道？ | 高/低客单价、B2B多方决策与长期培育。 |
| 2.1.3 | 三级 | 哪些渠道符合我的时间和预算？ | 现金、持续工时、技能与可控性比较。 |
| **2.2** | **二级** | **没流量、没预算，先试什么？** | 选择最小可行动作、反馈周期和试验停点；直接在二级正文成节，不再重复上级。 |
| — | 直接成节 | 本二级不设三级 | 完整讲清‘选择第一种低投入试法—反馈—停点’，再拆会与上级重复。 |
| **2.3** | **二级** | **怎么主动联系潜在客户？** | 合规找名单、首次沟通、后续跟进及退出。 |
| 2.3.1 | 三级 | 从哪里取得可以合法使用的潜客线索？ | 企业目录、公开采购信息、合规线索与联系人核验。 |
| 2.3.2 | 三级 | 第一次开口，怎么说才有回复机会？ | 相关性、真实价值、短消息与合理回应请求。 |
| 2.3.3 | 三级 | 没收到回复，怎么跟进和停止？ | 分辨拒绝、频率、退订与明确停止条件。 |
| **2.4** | **二级** | **怎么让搜索客户找到我？** | 商业搜索意图、页面布局和搜索投入取舍；不承诺SEO时限与效果。 |
| 2.4.1 | 三级 | 客户搜哪些词时更可能购买？ | 对比、替代、功能、价格等搜索意图。 |
| 2.4.2 | 三级 | 产品页和文章各该回答什么？ | 商品/服务着陆页与教育内容的分工。 |
| 2.4.3 | 三级 | 搜索竞争很强时，先做哪些内容？ | 细分需求、长尾搜索与可衡量的优先级。 |
| **2.5** | **二级** | **怎么用内容和社区吸引客户？** | 内容形式、社区参与、自然引导及创作负担。 |
| 2.5.1 | 三级 | 教程、对比和案例，哪种更适合？ | 购买阶段对应的内容类型和验证。 |
| 2.5.2 | 三级 | 在社区里，怎么参与才不会变成广告骚扰？ | 社区规则、实际解答、身份透明。 |
| 2.5.3 | 三级 | 内容有人看，怎样引导到购买入口？ | 产品页、试用、预约和平台规则内的下一步。 |
| **2.6** | **二级** | **怎么获得平台内的自然曝光？** | 在现有平台内争取相关展示；不预设新品扶持或万能排序规律。 |

| **2.7** | **二级** | **怎么借合作伙伴带来客户？** | 非付费互荐与商业合作的选择和效果跟踪；付费佣金见下一节。 |
| 2.7.1 | 三级 | 什么样的伙伴值得互相推荐？ | 客群互补、信誉、动机与适用范围。 |
| 2.7.2 | 三级 | 合作前怎么核对线索质量和责任？ | 实际引荐、许可、承诺边界与退出安排。 |
| **2.8** | **二级** | **广告、达人和佣金推广怎么选？** | 区分付费搜索/社交广告、达人、联盟的适用条件与计费风险。 |
| 2.8.1 | 三级 | 搜索广告和社交广告适合什么需求？ | 已有购买意图与主动唤起兴趣的区别。 |
| 2.8.2 | 三级 | 达人合作与按成交付佣金有何差别？ | 受众真实性、内容披露、归因与佣金纠纷。 |
| 2.8.3 | 三级 | 什么情况下还不适合花钱推广？ | 毛利、转化承接和投入回收的最低条件。 |
| **2.9** | **二级** | **第一次投广告怎么试？** | 小预算设计、投放对象/素材、阶段性止损。 |
| 2.9.1 | 三级 | 广告预算上限和止损线怎么定？ | 可承受损失、目标订单与预先确定的停止条件。 |
| 2.9.2 | 三级 | 先测哪些受众和广告内容？ | 搜索词、受众、创意和着陆页信息一致。 |
| 2.9.3 | 三级 | 有点击没订单，先排查哪里？ | 来源质量、页面加载与购买障碍；归因核算见第四章。 |

### 3. 客户来了，怎么让他下单？

**本章主责：** 经营侧的价值表达、信任、跨境交付预期、交易流失与咨询/B2B跟进，不修改产品系统或支付机制。

| 编号 | 级别 | 商家问题 | 主要知识责任（非题目） |
|---|---|---|---|
| **3.1** | **二级** | **客户能看懂我卖什么吗？** | 价值主张、产品适用对象及行动入口的清晰度。 |
| 3.1.1 | 三级 | 客户一眼需要看懂哪些信息？ | 卖什么、适合谁、怎么用、多少钱、怎么获得。 |
| 3.1.2 | 三级 | 怎样证明产品能解决客户的问题？ | 真实演示、对比、案例与限制披露。 |
| **3.2** | **二级** | **陌生客户为什么信任我？** | 安全感、真实性与跨境交付信息。 |
| 3.2.1 | 三级 | 新店没有评价，该用什么证明自己？ | 可核验身份、真实样品、服务记录与案例。 |
| 3.2.2 | 三级 | 运费、到货时间和额外费用该怎么说明？ | 交付责任、可能产生的税费和条件透明；不展开Incoterms规则。 |
| 3.2.3 | 三级 | 售后承诺怎么写，既清楚又能兑现？ | 退换货、支持渠道、边界和履约可信度。 |
| **3.3** | **二级** | **客户嫌贵或犹豫怎么办？** | 异议诊断与价值表达；不强迫不适合的买家成交。 |
| 3.3.1 | 三级 | 客户说贵，究竟在担心什么？ | 预算不足、比较其他方案或价值不清。 |
| 3.3.2 | 三级 | 演示、试用和不同套餐什么时候有用？ | 风险降低、产品匹配与合理限制。 |
| **3.4** | **二级** | **客户到付款前为什么离开？** | 经营视角分析购物车与结账路径，不重写支付服务商的技术实现。 |
| 3.4.1 | 三级 | 隐藏费用和额外步骤会造成哪些流失？ | 强制注册、运费、交付时间与信息负担。 |
| 3.4.2 | 三级 | 怎样区分客户犹豫和付款故障？ | 从反馈与结账阶段识别障碍；技术修复转交③④。 |
| 3.4.3 | 三级 | 没有复杂工具，怎么发现流失环节？ | 真实用户测试、反馈、基础阶段统计及隐私边界。 |
| **3.5** | **二级** | **咨询或报价后怎么推进？** | 有明确意向的销售沟通与进度管理，不重复陌生冷联系。 |
| 3.5.1 | 三级 | 客户问完没下单，该何时跟进？ | 报价澄清、疑虑、回应时机与停止边界。 |
| 3.5.2 | 三级 | 如何给客户一个明确的下一步？ | 演示、样品、正式报价、合同/确认动作。 |
| **3.6** | **二级** | **多人参与购买，怎么跟进？** | B2B/机构大额订单的角色、异议及长期周期。 |
| 3.6.1 | 三级 | 不同决策角色最关心什么？ | 使用效率、采购成本、合规责任及业务价值。 |
| 3.6.2 | 三级 | 成交周期很长，怎样维持进展？ | 关键里程碑、关系跟进与不强催的节奏。 |

### 4. 找客户到底划不划算？

**本章主责：** 识别有效指标、渠道归因、成本/贡献利润、长期客户价值与小样本判断；不重算入市机会。

| 编号 | 级别 | 商家问题 | 主要知识责任（非题目） |
|---|---|---|---|
| **4.1** | **二级** | **应该看哪些获客数字？** | 从曝光到咨询到付费的各阶段，选少量有经营意义的指标。 |
| 4.1.1 | 三级 | 曝光、咨询和付款分别说明什么？ | 浏览与成交漏斗、领先和滞后指标。 |

| 4.2.1 | 三级 | 不用复杂系统，怎样记录订单来源？ | 专属链接、UTM、问询等合理来源记录。 |
| 4.2.2 | 三级 | 客户接触多个渠道后，怎么分功劳？ | 首末次触点偏差、辅助曝光与归因局限。 |
| **4.3** | **二级** | **获得一个新客花了多少？** | 广告之外时间、人力、工具、佣金等真实CAC口径。 |
| 4.3.1 | 三级 | 哪些费用不能漏算？ | 广告、样品、外包、工具、折扣、制作与失败试验。 |
| 4.3.2 | 三级 | 自己的时间该怎么算进成本？ | 机会成本、工时和免费渠道的真实消耗。 |
| **4.4** | **二级** | **订单增加，为什么还可能亏钱？** | 渠道投入与订单贡献利润，不讲法定税务核算细节。 |
| 4.4.1 | 三级 | 扣完产品和履约成本，一单剩多少？ | 边际贡献、退款、物流、支持和渠道支出。 |
| 4.4.2 | 三级 | 销售额增长，哪些情况反而更危险？ | 低毛利扩量、现金垫付与成本递增。 |
| **4.5** | **二级** | **老客户未来能值多少钱？** | 客户长期贡献、回本周期与保守预测；不假定可精确测量。 |
| 4.5.1 | 三级 | 怎么估计复购和续费可能带来的利润？ | 客户群体分布、留存和贡献毛利区间。 |
| 4.5.2 | 三级 | 多久才能收回获客支出？ | 回本期、退款风险与现金占用。 |
| **4.6** | **二级** | **数据太少，该继续还是停？** | 观察期、小样本波动、定性反馈与继续试验条件。 |
| 4.6.1 | 三级 | 少量点击或订单为什么容易误判？ | 随机波动、延迟决策、样本代表性。 |
| 4.6.2 | 三级 | 哪些信号支持继续测试或换方向？ | 成本护栏、真实反馈、可复验行为。 |

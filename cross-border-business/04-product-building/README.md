## 职责范围与边界

适用于平台商家、独立站、SaaS、数字商品、实体商品、内容会员及服务：产品形式 → 首版范围 → 现成工具/开发方式 → 客户体验和商家订单/履约 → 上线测试 → 维护与迭代。

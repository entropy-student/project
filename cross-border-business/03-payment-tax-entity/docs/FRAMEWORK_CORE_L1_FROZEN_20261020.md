## 一、唯一核心问题（正式冻结原文）

**做跨境生意，钱怎么收、税怎么交？**

## 二、一级问题正式冻结原文

| 章 | 一级问题（逐字冻结） | 独立知识责任（非冻结题目） |
|---|---|---|
| 1 | **做跨境生意，我需要注册公司吗？** | 个人、个体工商户、国内公司、海外公司如何选择，以及各自的责任和限制 |
| 2 | **海外客户的钱，我该怎么收？** | 认识收款方式，比较平台代收、PayPal、Stripe、MoR、银行转账等方案 |
| 3 | **选好收款方式，怎么才能用起来？** | 开户条件、资料准备、审核、账户开通、接入方式和上线验证 |
| 4 | **怎么让海外客户顺利付款？** | 不同国家的付款习惯、支付方式、币种、付款安全及支付失败处理 |
| 5 | **客户付了钱，我怎么确认收款成功？** | 支付状态、交易核验、支付通知、重复扣款、漏单与订单衔接 |
| 6 | **客户付的钱，怎么进我的银行账户？** | 资金清算、结算、提现、换汇、到账时间与费用 |
| 7 | **遇到退款、拒付或资金冻结怎么办？** | 退款处理、拒付争议、欺诈风险、账户冻结及资金保护 |
| 8 | **这门生意到底赚了多少钱？** | 收入、成本、利润、现金流、记账、对账及财务凭证 |
| 9 | **在国内做跨境生意，要交哪些税？** | 中国境内税种、不同主体的纳税义务、申报、开票和出口退免税 |
| 10 | **卖给海外客户，还要在当地交税吗？** | 海外销售税、VAT/GST、平台代征、税务登记及跨境税收责任 |

## 三、章节拆分与阅读逻辑

| 教学阶段 | 章节 | 读者主线 |
|---|---|---|
| 经营准备 | 第1—3章 | 明确经营身份 → 选收款方案 → 开通收款能力 |
| 完成交易 | 第4—5章 | 客户付款 → 商家核实真实交易结果 |
| 资金管理 | 第6—7章 | 清算与银行到账 → 处理退款、争议、欺诈和冻结 |
| 持续经营 | 第8—10章 | 对账核算 → 中国税务 → 目的国税务 |

**组织方式：经营生命周期主线 + 知识依赖辅助，不是强制执行的时间顺序。** 税务及经营主体责任、资金风险、账务留存应从经营起步就予以考虑，不能写成“收到钱以后才开始产生”。第2/3章区分选型与申请/接入，第5/6章区分支付确认与银行实际可用资金，第8/9/10章区分账务、中国税务和境外税务。

## 四、与其余四板块的边界（指导性，非冻结题目）

- 第一板块解决“什么商机值得做”，本板块解决主体适格、交易责任与实际收付税务，避免重复做机会调研。
- 第二板块解决网络环境、账号安全、服务基础设施，不重写金融收付和税制。
- 第四板块负责商品、订单、实际履约及用户权益系统；本板块负责支付金融事实、收款状态、退款资金与对账，并明确跨系统接口。
- 第五板块负责流量、营销转化、获客成本和增长；本板块仅讲结账支付方式、支付失败和相关费用透明度。
- 主体所在地、贸易类型、销售目的国和服务商条款影响事实结论；税务及支付资格不能用全地区统一规则代替核验。

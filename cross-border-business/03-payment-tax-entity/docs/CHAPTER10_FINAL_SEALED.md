# 第10章｜卖给海外客户，还要在当地交税吗？

## 引言（非冻结）

在上一章（[第9章《在国内做跨境生意，要交哪些税？》](CHAPTER9_FINAL_SEALED.md)）中，我们系统解决了跨境出海业务在**中国大陆境内**的法定纳税义务：明确了个人、个体工商户与有限责任公司的税负结构与选型平衡；厘清了境外收入申报与各税种专属的人民币折算规则；剖析了实物出口退免税与跨境数字服务（SaaS/软件）适用零税率、免税的法定要件；并落地了未开票收入申报与电子税务局全流程申报 SOP。

然而，跨境贸易具有天然的“跨法域”属性。当中国商户通过独立站、海外电商平台或在线软件系统，将实物商品直接寄送给欧美消费者，或者通过云端向海外企业按月收取 SaaS 订阅费时，资金流与货物流已经穿透了目的国的税收管辖边界。此时，每一个跨境经营者都必须直面跨国经营中最具冲击力的一组现实问题：
- “我的公司注册在中国深圳，在海外没有实体，货也是从国内直邮发过去的，海外政府凭什么向我收税？”
- “客户下单时，我看到结账页面加了销售税或 VAT，这笔税到底是谁交的？是平台交、我交，还是客户交？”
- “亚马逊、TikTok Shop 已经替我代扣代缴了税款，为什么我的独立站还要在个别州单独申报？”
- “我在香港或美国特拉华州注册了离岸公司，是不是就可以天然享受免税？如果国内团队在境内遥控海外公司，会不会被认定为中国税收居民企业甚至面临双重征税？”
- “海外客户要求我签署 W-8BEN 或 W-8BEN-E 税务表格，若不签就直接扣走 30% 的款项，这些表格究竟该怎么填？海外被扣掉的税，在国内能不能抵扣？”

长期以来，跨境出海行业充斥着大量片面甚至危险的民间断言：有人将美国州销售税（Sales Tax）等同于中国企业所得税；有人把欧盟的 IOSS 增值税申报机制误当成关税免税工具；还有人误以为只要不在海外设立实体，海外税局就“鞭长莫及”。

本章专为中国大陆跨境电商卖家、独立开发者、SaaS 出海团队及中小外贸企业编写。我们将从国际税收实体法、双边税收协定（DTA）及各国现行征管规则出发，全面解构：
1. 海外销售税（Sales Tax）、增值税（VAT/GST）、进口关税、企业所得税及非居民预提税的底层机制与法定边界；
2. “无海外实体”状态下，因海外仓储、经济关联（Economic Nexus）或数字服务触发目的地税务登记的法定标准；
3. 美国各州经济关联门槛的逐州判定方法，以及欧盟 2026年7月1日起新关税改革（取消旧150欧元关税豁免、实施过渡期按关税分类项目征收3欧元的关税规则）与 IOSS 增值税机制的严格界定；
4. 平台代征代缴（Marketplace Facilitator / MoR）机制下，商家的剩余登记、零申报与备查证据链留存义务；
5. 人在国内、公司在海外时，实际管理机构（POEM）、常设机构（PE）、CRS 涉税信息交换与双重征税防范；
6. 美国 W-8BEN / W-8BEN-E 核心表格填报指南、中美税收协定优惠申请与中国境内境外税收抵免（FTC）实操；
7. 业务规模扩张后，目的国税务义务的主动监控与自动化算税申报工具的理性选型。

让我们跨越国界与法域壁垒，看清出海目的地税收合规的全景规则，筑牢跨境商业的全球资产安全防线。

## 10.1 卖给国外客户，可能会涉及哪些当地税？

跨境出海企业在评估海外税收成本时，首要任务是打破“把所有税统称为交税”的粗放观念。不同国家和地区对同一笔跨境交易，可能依据不同法理课征性质迥异的税种。

### 10.1.1 海外的销售税、VAT/GST与所得税有何不同？

在国际税收体系中，针对商业交易所征收的税种主要划分为**间接税（流转与消费环节课征）**与**直接税（所得与财产环节课征）**两大类别。常见税种的法律实质、计税基准与经济承担者存在本质差异。

```
【跨境业务目的地主要税种全景谱系】
跨境交易涉税体系
  │
  ├─ 间接税 (Indirect Taxes / 消费环节课税，法律纳税人与经济负担须按法域及交易条件判断)
  │    ├─ 美国零售销售税与使用税 (Sales & Use Tax) ── [单环节零售税，价外标示，无进项抵扣]
  │    ├─ 增值税 (VAT) / 商品及服务税 (GST) ─────── [多环节流转税，多为含税标价，增值额课税]
  │    └─ 进口关税 (Customs Duties) ──────────────── [边境进口征收，由进口商缴纳并资本化入成本]
  │
  └─ 直接税 (Direct Taxes / 所得课税，居民身份、来源地、PE、预提等依规则判断)
       ├─ 企业所得税 (Corporate Income Tax / CIT) ─── [净利润或法定应税所得课税，需分别判断居民、来源地及PE]
       └─ 非居民预提所得税 (Withholding Tax / WHT) ── [源泉扣缴，针对跨境特许权/股息/利息]
```

#### 1. 五大主力税种核心机理与要素对比

| 税种类型 | 法律英文全称 | 课税对象与经济实质 | 标价方式与负税主体 | 进项税额抵扣与会计处理 | 典型法域与现行代表税率 |
|---|---|---|---|---|---|
| **美国销售与使用税** | Sales and Use Tax | 最终消费者在当地购买应税有形动产或特定数字服务的**单环节零售交易**。 | **价外标价（Tax-Exclusive）**：标价不含税，结账时额外附加；<br>纳税/收取及汇缴义务依州法、平台代征规则及合同判定；<br>经济成本可由商家折扣吸收，并非总由买家单独承担。 | **否！**（非增值税体系，无进项抵扣机制；若非最终消费需凭转售豁免证 Resale Certificate 免税采购）。 | 美国各州及地方（联邦无销售税；45个州+特区征收，综合税率通常在 **4% 至 10.5%** 之间）。 |
| **增值税 / 商品及服务税** | Value Added Tax (VAT) / Goods and Services Tax (GST) | 商品或服务在生产、流通与零售**全链条各环节的增值额**；跨境电商中适用**消费地征税原则**。 | **B2C零售通常为含税标价（Tax-Inclusive）**；<br>法定缴纳人可能为卖家、进口商、买家反向征税或平台视同供应商；<br>价格是否把税转嫁给买家由合同与市场决定。 | **有条件抵扣。**须核对税法身份、可抵扣用途、法定进口商或收货人及有效单证；免税业务、混合用途、第三方名义进口未必可抵或只能部分抵扣。 | 欧盟27国（标准税率 **17% 至 27%**）、英国（标准税率 **20%**）、澳大利亚/新西兰/新加坡（GST **9% 至 15%**）。 |
| **进口关税** | Customs Duties | 跨境实物货物跨越国家（或关税同盟）边境进入消费国海关时的**边境调节税**。 | 依据贸易术语（Incoterms）约定：DAP/DDU由买家承担，DDP由卖家预付；<br>纳税主体：海关登记进口商（IOR）。 | **不可作为税金抵扣！** 在会计核算上，进口关税属于**货物采购存货成本的组成部分（资本化计入库存成本）**，随货物销售转入营业成本，而非直接作为当期税金冲减。 | 全球各主权海关依据关税税则（HS Code）征收，税率从 **0% 至 30%+** 不等。 |
| **企业所得税** | Corporate Income Tax (CIT) / Profits Tax | 企业在特定法域开展生产经营取得的**年度净利润（收入扣除法定成本费用后）**。 | 计入企业损益表；<br>法律纳税人与负税人均为：**企业自身**。 | 不属于流转税，依税法扣除合法采购成本、研发费用及折旧摊销。 | 美国联邦（**21%** + 州税）、中国香港（利得税 **8.25%/16.5%**）、新加坡（**17%**）。 |
| **非居民预提所得税** | Withholding Tax (WHT) | 非居民企业或个人从当地取得的特许权使用费、股息红利、利息等**消极投资所得或特定技术服务费**。 | 源泉扣缴（从应付给卖家的结算款中直接扣除）；<br>纳税义务人：收款的非居民企业或个人。 | 属于所得税性质的预扣；符合法定条件的，可在收款方所属国申请**境外所得税额抵免（FTC）**。 | 美国国内税法法定基准 **30%**；依据中美税收协定特许权通常降至 **10%**。 |

#### 2. 国际间接税的运作底层逻辑：价外税与代收代缴
- **消费税是“代收代缴”，而非企业经营利润损失：**
  - 销售税与VAT/GST通常旨在对消费征税，但应区分**法律纳税/代征责任人**和**实际经济负担**：某笔交易的责任人可能是卖家、平台、进口商或适用反向征税的买家；商家也可能通过含税价、包税促销自行承担部分成本，不能普遍称作“受委托代征”。
  - **模型测算（MODEL_ASSUMPTION）：** 假设你在独立站向美国加利福尼亚州某消费者销售一件货值 100 美元的数码配件，假定当地根据送货地址邮编测算的综合销售税率为 9.5%。结账时，系统向买家收取 109.50 美元（其中 100 美元为商品销售收入，9.50 美元为代收销售税）。商家收取这 9.50 美元后，在会计上确认为一项流动负债（`应付账款/应交税费-代收销售税`），并在申报期将其全额汇缴给加州税费管理局（CDTFA）。**这 9.50 美元既不是商家的营业收入，也不是商家的经营利润损失。**
- **进项抵扣链条的有效性前提：**
  - **先确认进口增值税能否抵扣，再计算税后成本：**需要按具体法域核对买卖及进口主体、当地VAT纳税身份、实际所有权、可抵扣的应税经营用途、有效进口单证及适用申报期间。拥有税号/C79或进口报关单仅是部分条件，绝不自动保证当期全额抵扣。**反例A：**已注册但仅开展免税且无抵扣权的业务，进口VAT可能不可抵；**反例B：**已注册且货物用于全额可抵的应税销售、单证齐备，才可能依法抵扣；**反例C：**报关进口商/商品所有人是第三方而非实际申报主体，通常不能仅凭代付款主张全额进项抵扣。未注册也未必永久沉没，部分法域存在非居民退税或后续更正路径，须先核验资格。参见英国HMRC官方[input tax基本权利](https://www.gov.uk/hmrc-internal-manuals/vat-input-tax/vit12100)与[进口主体判断](https://www.gov.uk/hmrc-internal-manuals/vat-input-tax/vit13300)。

### 10.1.2 没在海外注册公司，卖给当地客户就一定要交税吗？

许多初涉跨境出海的个人开发者与独立站卖家抱有一个根深蒂固的误解：“我在美国、欧洲没有注册公司，也没有租办公室，我只是一个纯粹的中国卖家，隔着大洋把货寄过去，难道海外税局还能管到我头上？”

答案是：**在现代国际税收规则下，是否产生目的地纳税义务，与你是否在当地注册了法律实体（公司）完全没有必然关联！**

#### 1. 跨境纳税义务产生的法定判定路径

```
【无海外实体时目的地纳税义务判定决策树】
没有在海外设立公司
  │
  ├─ 1. 是否在目的地国存放了实物库存？ (如使用海外仓、亚马逊 FBA)
  │    ├─> 【是，且从事独立销售】 ──> 确立【物理实质联结 (Physical Nexus)】！通常须办理增值税/销售税登记
  │    └─> 【是，但仅通过代征平台销售】 ──> 视当地法规而定 (如得州设纯平台仓免许可证例外)
  │
  ├─ 2. 远程销售是否超过了目的地州或国家的法定销售额/交易量门槛？
  │    └─> 【是】 ──> 触发【经济实质联结 (Economic Nexus)】！必须在当地登记并申报
  │
  ├─ 3. 是否通过具备法定代征代缴义务的平台 (Marketplace Facilitator) 销售？
  │    ├─> 【是】 ──> 平台依法代征代缴销售税，商家免除该平台订单的代收义务 (但可能存在零申报义务)
  │    └─> 【否 (独立站自建站)】 ──> 商家自身作为法定责任人，全额承担登记、计税与汇缴义务
  │
  └─ 4. 销售标的是否为跨境数字化服务 (B2C SaaS / 在线工具)？
       └─> 【是】 ──> 在若干法域可能自首笔应税B2C销售触发义务，但须逐国查纳税身份、平台视同供应商、例外及当地登记路径
```

#### 2. 无海外公司时触发境外税务登记的核心场景与例外条件

##### 场景一：使用海外仓储引发的“物理实质联结”（Physical Nexus）及其法定例外
- **通用原则：** 在美国绝大多数州、欧盟、英国及澳大利亚，税法明确规定：纳税人在当地拥有、租用或控制实物资产（包括存放于第三方海外仓或平台物流中心的存货），即确立了税收上的物理实质联结；
- **条件化例外（以美国得克萨斯州为例）：**
  - **反例一（得州纯平台仓储例外）：** 根据得克萨斯州审计署（Texas Comptroller）颁布的远程卖家及平台指南（官方依据：[Texas Comptroller Remote Sellers & Marketplace FAQ](https://comptroller.texas.gov/taxes/sales/remote-sellers-marketplace-faq.php)），如果某外州或外国卖方在得克萨斯州的**唯一物理存在是存放在第三方商城促进者（如亚马逊 FBA）仓库中的货物**，且该卖家的**所有得州销售均由该平台代征代缴销售税**，则该卖家无需向得州申请销售税许可证（Sales Tax Permit），豁免了单独登记义务；
  - **反例二（加州混合独立销售规则）：** 相比之下，根据加州税费管理局（CDTFA）规定（官方依据：[CDTFA Marketplace Facilitator Act](https://www.cdtfa.ca.gov/industry/MPFAct.htm)），若卖家在加州仓库中存放货物，只要同时通过自己的独立站开展直接销售，就必须持有加州许可证并履行申报义务。
- **所得税与常设机构例外：** 必须严格注意：在当地海外仓存放货物**并不等同于必须在当地缴纳企业所得税**。根据中国与主要出海目的国签署的双边税收协定（DTA）第五条第四款，单纯为了储存、陈列或交付本企业货物而设立的设施，通常属于**准备性或辅助性活动**，不构成所得税意义上的“常设机构（PE）”（详见 10.4 节）。

##### 场景二：销售规模扩张引发的“经济实质联结”（Economic Nexus）
- **突破物理存在的司法规则：** 自 2018 年美国最高法院对“南达科他州诉 Wayfair 案”（South Dakota v. Wayfair, Inc.，官方判决见：[US Supreme Court Wayfair Decision](https://www.supremecourt.gov/opinions/17pdf/17-494_j4el.pdf)）作出判决以来，美国确立了**经济实质联结（Economic Nexus）**原则；
- **判定要件：** 只要远程卖家在某个州产生的销售额达到该州法定门槛（如 10 万美元或 50 万美元），无论卖家身处何国、在当地有无员工或实体，均依法负有向该州代征销售税的义务（详见 10.2 节）。

##### 场景三：全球针对数字服务与在线 SaaS 的非居民征管新规
- **数字经济“去门槛化”征管：** 针对在线订阅软件、数字内容下载、海外手游等无形商品，欧盟、英国、澳大利亚、日本、新加坡等国家和地区，已全面建立**非居民纳税人电子服务增值税机制（如欧盟 Non-Union OSS、英国 NETP）**；
- **极严红线：** 对向当地个人消费者（B2C）提供的数字服务，大多数法域**取消了常规小微企业的免税营业额门槛（即门槛为 0 欧元或 0 英镑）**。这意味着，哪怕你是一个中国的个人独立开发者，向德国消费者销售了一份 10 欧元的软件授权，在严格税法意义上也已经触发了向欧盟申报缴纳增值税的法定责任。

## 10.2 什么情况下，需要在当地登记、收税或申报？

明确了海外税收管辖的基本法理后，跨境出海团队必须掌握美国、欧盟两大核心市场的具体判定标准与实操规则。

### 10.2.1 美国各州远程卖家的销售税门槛，应当怎样逐州判断？

美国没有联邦层面的统一销售税，销售税的立法权、解释权与征收权高度下放至**各州（State）及县（County）、市（City）地方自治政府**。全美目前有 45 个州及华盛顿哥伦比亚特区征收全州性销售税（仅阿拉斯加、特拉华、蒙大拿、新罕布什尔、俄勒冈 5 个州不征收全州性销售税，常被称为“NOMAD 州”）。

#### 1. 消除“统一10万美元/200笔”的致命经验主义错误
在 Wayfair 判决初期（2018-2020年），多数州最初照搬了南达科他州的基准（年销售额 10 万美元或 200 笔交易）。然而，在随后的税收征管实践中：
1. **交易笔数门槛引发多州立法废除：** 许多低货值小商品卖家年销售额很低却因达到 200 笔交易而被强行要求报税，税局征管成本畸高。因此，截至 2024 至 2026 年，包括**加利福尼亚州、得克萨斯州、华盛顿州、佛罗里达州、科罗拉多州、印第安纳州以及伊利诺伊州等在内的大量州，已正式立法废除了 200 笔交易的辅助门槛**，仅保留纯销售额指标；
2. **伊利诺伊州（IL）最新修正：** 依据伊利诺伊州税务局发布的最新官方公报（官方依据：[Illinois IDOR Informational Bulletin FY 2026-12](https://tax.illinois.gov/research/publications/bulletins/fy-2026-12.html)），**自 2026 年 1 月 1 日起，伊利诺伊州正式删除了 200 笔交易门槛**，统一调整为仅依据前置四个季度累计销售额达到 **$100,000** 作为经济关联的唯一判定基准；
3. **高体量州门槛设定：** 加利福尼亚州（CA）与得克萨斯州（TX）的经济关联基准线为 **500,000 美元**，纽约州（NY）则采用“**500,000 美元且超过 100 笔交易**”的复合指标。

#### 3. 统计口径的判定陷阱：毛销售额（Gross）vs 自身独立销售额（Direct）
- **多渠道卖家的算例陷阱（MODEL_ASSUMPTION）：**
  - 假设某中国独立站与亚马逊双栖卖家，2026 年度在加利福尼亚州的销售流水构成如下：
    - 亚马逊店铺销售给加州买家：450,000 美元（由亚马逊作为 Marketplace Facilitator 全额代征代缴加州销售税）；
    - 卖家自己的 Shopify 独立站销售给加州买家：60,000 美元（未开通平台代征）。
  - **判定分析：** 加州法律规定，经济关联门槛的 500,000 美元按照**总交付销售额（Gross Sales）**计算。该卖家在加州的总销售额为：
    $$\text{加州交付总销售额} = 450,000 + 60,000 = \mathbf{510,000\text{ 美元}} > 500,000\text{ 美元}$$
  - **合规结果：** 尽管亚马逊那 45 万美元已经由平台完税，但由于全渠道总额越过了 50 万美元红线，卖家**依法已触发加州经济实质联结！** 卖家必须向加州税费管理局申请注册销售税许可证，并对独立站这 60,000 美元的交易全额向消费者计征加州销售税并定期向加州申报缴纳。如果卖家误以为“独立站才卖了6万没到50万不用管”，将构成严重的漏税违法。

### 10.2.2 欧盟直邮、海外仓与IOSS，什么时候需要不同税务处理？

向欧盟 27 个成员国销售实物商品，涉及一套精密的关税同盟与增值税统一协调机制。实物出海通常演化为直邮与海外仓两大基本流向。

#### 1. 2026年欧盟海关新改革：告别旧150欧元关税豁免时代
- **特别核验背景（Regulation (EU) 2026/382 及 2026/1022）：**
  - 在历史税制中，欧盟长期对进口货物实行“货值在 150 欧元以下免征进口关税”的政策；
  - 依据欧盟理事会最新海关改革法案 **Council Regulation (EU) 2026/382**（官方公布于欧盟官方公报，官方来源：[EUR-Lex 官方条例文本](https://eur-lex.europa.eu/eli/reg/2026/382/oj/eng) 及委员会改革主页 [EU Customs Reform](https://taxation-customs.ec.europa.eu/customs/eu-customs-reform_en)），**自 2026 年 7 月 1 日起，欧盟 Article 1 正式废除针对货值低于 150 欧元的进口关税豁免！**
  - 依据该条例 Article 2 及补充授权条例 **Commission Delegated Regulation (EU) 2026/1022**（官方来源：[EUR-Lex 授权条例](https://eur-lex.europa.eu/eli/reg_del/2026/1022/oj/eng)），对适用简化申报（H7 数据集）并由授权经济营运者或采用 IOSS 申报的特定小额跨境包裹，实行过渡期简易关税规则；
  - **2026年7月1日欧盟低值进口过渡关税的计算单位：**依据[欧盟委员会2026年6月29日官方实例](https://commission.europa.eu/news-and-media/news/ensuring-fairness-and-safety-eur3-customs-duty-low-value-parcels-2026-06-29_en)，适用过渡规定时，按申报货物的**不同关税分类项目（tariff classification）**计收每项3欧元；**不是每件实物、每个包裹、每个商品SKU一律3欧元**。5件同类T恤如属同一关税分类，示例合计为**3欧元**；3件同类T恤与1块手表分别属两类，则为**6欧元**。若申报多个真正不同分类，再依实际申报分类复算；不得拿物流件数代替分类项数。该过渡计征仍受生效日期、适用进口货值、申报及进口渠道等规定约束，费用承担由进口商/卖家合同及申报责任判断，不能泛称全欧所有包裹适用。
- **核心概念剥离：切勿混淆“关税新政”与“IOSS 增值税机制”：**
  - **关税（Customs Duty）：** 属于进境边境税。2026年7月1日后，低值免税政策被根本性改写；
  - **增值税 IOSS（Import One-Stop Shop，进口一站式服务平台）：** 是欧盟自 2021 年起推行的**增值税专用申报机制**。它专门针对内在固有价值（Intrinsic Value，不含运保费与增值税）**不超过 150 欧元**的货物。在 IOSS 机制下，增值税在消费者结账时按目的地国税率直接收取，货物清关时凭有效 IOSS 编码免征进口增值税，实现边境快速结关放行。**IOSS 解决的是增值税（VAT）合规，绝不能等同于免除关税！**

#### 2. 欧盟三类实物出口业务模式的税务处理决策矩阵

```
【欧盟实物业务三大操作模式对比】
业务模式
  │
  ├─ 模式 A：跨境小包直邮 (货值 <= 150 EUR，采用 IOSS)
  │    └─> 结账收取目的国 VAT ──> 清关凭 IOSS 豁免进口 VAT ──> 每月通过 IOSS 统一申报
  │
  ├─ 模式 B：跨境直邮未用 IOSS / 货值 > 150 EUR
  │    ├─> 分支 1 (DAP/DDU 未含税): 结账不收税 ──> 口岸由承运人向买家代征进口税费及手续费
  │    └─> 分支 2 (DDP 完税交付): 结账测算含税 ──> 卖家委托物流垫缴关税及进口VAT
  │
  └─ 模式 C：欧盟境内本地海外仓 (德国/法国/波兰仓储)
       └─> 必须注册首站国本地 VAT ──> 货物先报关缴税 ──> 欧盟内调拨与 Union OSS 申报
```

##### 模式 A：跨境小包直邮（货值 $\le 150$ 欧元，接入 IOSS）
- **操作流程：** 商家（非欧盟企业通常须指定一名欧盟境内的增值税中介机构 VAT Intermediary）在任一欧盟成员国注册一个 IOSS 税号；独立站结账页面根据买家所在国（如法国 20%、德国 19%）自动计算并收取 VAT；发货时将该 IOSS 识别码以电子数据方式嵌入运单传输给海关；海关核验无误后予以免进口增值税放行；每月由中介机构汇总编制一份单一的 IOSS 申报表，向注册国税局一次性缴纳当月全欧代收的增值税款。

##### 模式 B：传统跨境直邮（未采用 IOSS 或单票货值 $> 150$ 欧元）
- **分支 1（DAP/DDU 模式）：** 结账时不向消费者收取增值税与关税，货物到达欧盟口岸时由承运人（DHL、邮政等）向消费者代征进口增值税、关税及清关手续费，买家若拒付则面临货物退运损失；
- **分支 2（DDP 模式）：** 卖家在销售端预收全包税费，清关时由卖家指定的物流清关代理代缴税费。需要特别注意：**仅凭DDP或卖家已注册/未注册无法判断进口VAT最终能否回收**：须核实登记、进口人、货权、用于可抵扣的经营活动、凭证与当地退款机制；条件不足时才列为不能回收的经营成本。

##### 模式 C：欧盟境内本地海外仓（德国/法国/波兰仓储）
- **非欧盟卖家的 Union OSS 与 10,000 欧元门槛澄清：**
  - **重要核验：10,000 欧元微型企业门槛仅适用于在单一欧盟成员国设立的本土企业！** （官方依据：[EU Commission OSS Rules](https://vat-one-stop-shop.ec.europa.eu/one-stop-shop_en)）；
  - 对于注册在中国、货物存放于欧盟境内海外仓的非欧盟卖家，**该 10,000 欧元门槛完全不适用（门槛为 0 欧元）！**
  - **合规操作链条：**
    1. **仓储所在地 VAT 登记：** 货物存放于德国仓库，必须向德国税局申请德国本地 VAT 税号；
    2. **欧盟有效 EORI 编码：** 非欧盟企业只需在**首次申报进口的任一欧盟成员国申请一个有效的 EORI 编码**（该编码在全欧 27 国通用，并不强制要求必须是德国的 DE 前缀，如荷兰 NL 开头或法国 FR 开头的 EORI 同样在全欧有效）；
    3. **联盟内一站式平台（Union OSS）申报：** 针对从德国海外仓发往法国、意大利等其他欧盟国家的跨国 B2C 订单，非欧盟卖家可在货物发运国（德国）注册参与 **Union OSS（非欧盟企业联盟方案）**，按季度统一集中汇总申报各目的国的增值税，免于在每个收件国重复注册税号。

### 10.2.3 卖SaaS或数字商品，与卖实物相比要核对哪些当地税务门槛？

与实物商品相比，出海数字化产品（在线 SaaS 软件、海外移动应用内购、云端算力服务、数字媒体流媒体）不存在海关实物通关与边境物流，但面临全球更为严苛的**电子交付服务（Electronically Supplied Services, ESS）间接税规则**。

#### 1. 跨境数字产品税务判定的三大核心维度
1. **交易性质分类（B2B vs B2C）：** 购买方是企业客户还是个人消费者，直接决定了税款是由卖家收取还是由买家自行核算；
2. **法定数字服务目录归属：** 各国税法对“数字化商品”有严密的正面与负面清单。纯自动化的云订阅服务属于典型 ESS，而附带大量人工实时咨询的服务在部分法域被划归为一般专业技术服务；
3. **消费者地理位置认定证据规则：**
   - 依据欧盟增值税实施条例与英国 HMRC 规范（官方依据：[HMRC Digital Services VAT Guidance](https://www.gov.uk/guidance/the-vat-rules-if-you-supply-digital-services-to-private-consumers)），为防止消费者通过 VPN 伪造低税率国家地址，商家通常需收集两项一致的地点证据（如买家 IP 地址、账单地址、手机国家代码、银行卡发卡行国家——**注意发卡行信息属于财务证据**）；
   - **10万欧元单一证据简化的严格条件：**欧盟实施条例Reg 282/2011经Reg (EU) 2017/2459修订的Art.24b，针对特定电信、广播与电子提供服务，要求供应商在**一个欧盟成员国有营业设立地或固定营业机构**，并就有关现行及前一历年跨境销售额满足10万欧元门槛，才能在符合条件时依赖一项由独立第三方提供的地点证据。**深圳独立SaaS直接卖法国个人，不因销售额低于10万欧元就自动享受该简化，原则上仍按适用规则收集相互不矛盾的地点证据；**在德国单一成员国经营设立且满足其他全部要件的商户才可能适用简化。应只保留必要证据、遵守个人数据保护规则。官方依据：[Regulation (EU) 2017/2459](https://eur-lex.europa.eu/legal-content/EN/TXT/?uri=CELEX:32017R2459)。

| **欧盟 27 国** | 欧盟增值税 (EU VAT)<br>非欧盟企业一站式机制 (Non-Union OSS) | **门槛为 0 欧元！** 只要向欧盟境内个人销售，第一笔起就必须按消费者所在国税率收取 VAT，通过非欧盟 OSS 按季申报。 | **条件化反向征税（Reverse Charge）：**先核实买家是以应税人身份购买、服务供给地与适用欧盟/成员国规则；VIES有效VAT号是重要证据但不总是唯一证据或绝对充分条件。无法在VIES查询时须取得其他可接受的企业身份/商业用途证明并按该国规则核实，不能仅凭无法查询就认定B2C。 | [欧盟委员会非欧盟OSS专栏](https://vat-one-stop-shop.ec.europa.eu/) |

| **美国（各州差异巨大）** | 州零售销售税 (State Sales Tax) | **极度碎片化！** 必须逐州核对 SaaS 的应税性（Taxability）：<br>- **全额应税州：** 纽约州、宾夕法尼亚州、华盛顿州等将 SaaS 明确列为应税商品；<br>- **须具体拆分服务：**加州纯远程访问且无有形介质或本地交付软件，可能不属于有形动产应税销售，但软件交付方式/版权许可/捆绑交易需依CDTFA规则分析；佛州服务、预制软件、下载许可与数字产品须按Florida DOR现行个别指南判断，**不得仅凭“浏览器SaaS”四字保证免税**。 | 多数州 B2B 同样属于应税范围（除非买方提供该州合法的转售证明 Resale Certificate 或制造业豁免证明）。 | 各州税务局特定行业税收指南 (如 NY Tax Bulletin TB-ST-128) |
| **澳大利亚** | 商品及服务税 (GST)<br>简化非居民注册 (Simplified GST) | 过去 12 个月内向澳大利亚交付的应税商品与服务总额达到 **75,000 澳元**门槛后必须注册。按 **10%** 征收 GST。 | **条件化免征：** 买家提供其有效的澳大利亚商业编号（ABN），**且必须做出书面声明确认已注册 GST 并且购买用于商业经营用途**；若用于私人用途依然必须征收 GST。 | [澳大利亚税务局 ATO 跨境规则](https://www.ato.gov.au/) |

## 10.3 平台已经帮我收税了，我还需要做什么？

随着全球平台经济的反避税立法浪潮，美国各州普遍颁布了**商城促进者法案（Marketplace Facilitator Laws）**，欧盟、英国与澳大利亚也全面确立了**平台视同供应商（Deemed Supplier）**制度。亚马逊、eBay、Walmart、TikTok Shop 等大型电商平台依法承担起代收代缴销售税的法定责任。

然而，在日常实操中，许多出海卖家产生了一个极其危险的侥幸心理：“既然平台把税都扣了，我在海外就什么都不用管了，既不用管申报，也不用管账据。”

**这种观念在实务中极易引发严重的次生合规灾难。** 平台代征税款后，卖家身上仍保留着多项无法转嫁的法定剩余义务。

#### 1. 核心法律概念穿透：交易架构的三种角色属性
出海团队必须清晰区分三种性质迥异的服务主体，不可混为一谈：
1. **纯支付通道服务商（PSP，如 Stripe、PayPal、Adyen）：** 仅负责资金结算与银行网络清算，**通常只是支付服务而不会因处理资金就自动承接销售税/VAT纳税责任**；但须核对具体产品的服务角色、实际法律卖方、法域、平台合同与可能适用的源泉扣缴义务，不能一概断言所有PSP在任何税种下都没有法定责任；
2. **商城促进者平台（Marketplace Facilitator，如 Amazon、eBay、TikTok Shop）：** 撮合多方买卖的平台。法律强制规定其仅针对在其平台上达成的交易代收代缴销售税；
3. **记录在案的法定销售商（Merchant of Record, MoR，如 Paddle、FastSpring、Lemon Squeezy）：** 专门针对软件出海的代销商。MoR 在法律上作为特定交易的直接转售方，承担该笔数字交易所对应的间接税（Sales Tax / VAT）代征与申报责任；**但严正提醒：MoR 绝不能免除开发者的企业所得税、个人所得税或在其他独立渠道销售的税务合规责任，市场上宣称“接入 MoR 即可享受全球无条件零税务负担”纯属虚假宣传！**

#### 2. 平台代收税款后，商家的四大法定剩余合规义务

##### 义务一：多渠道（Omnichannel）自建独立站的法定纳税断层
- **独立站绝对不受平台保护：** Marketplace Facilitator 法案的保护伞**严格限定在平台站内闭环交易**！
- 如果你同时运营亚马逊店铺和 Shopify 自建站，亚马逊只负责代扣其站内的销售税。一旦你在某个州的总体销售额（平台销售 + 独立站销售）越过了该州的经济关联门槛（如 10 万或 50 万美元），**需要依该州门槛计入规则、平台代征抵减/登记例外及直营订单应税范围，判断是否须登记、对哪些直营应税订单代征和申报**；不能把全部订单、未达标订单或免税商品一概加税。

##### 义务二：实体存在州的“销售税零申报”义务与特定州豁免
- **已注册税号的持续申报刚性：** 在多数州，如果卖家此前因在当地拥有 FBA 仓储或设立机构而申请了销售税许可证（Sales Tax Permit），**在许可证持续有效且税局要求申报期间，通常应按州的实际表格和频率持续申报，直至依法注销或收到税局明确豁免**；如有平台代征销售，应按州规则披露总销售与平台代征/豁免部分，**税额为0不等于销售额为0，也未必称作Zero Return**。按各州税局当期通知处理申报频率与逾期后果，例如[NY登记与申报责任](https://www.tax.ny.gov/pubs_and_bulls/tg_bulletins/st/do_i_need_to_register_for_sales_tax.htm)、[TX仅平台仓例外](https://comptroller.texas.gov/taxes/sales/remote-sellers.php)。
- **特定州的免登记例外（如得州）：** 需要客观指出，并非所有州都绝对要求开户。正如 10.1.2 节所述，在得克萨斯州等少数州，若远程卖家的唯一物理存在是平台仓库且所有销售均由平台代征，得州税法允许其不申请销售税许可证，免除了零申报负担。

##### 义务三：美国国税局 1099-K 报表差异调节与核对
- **1099-K 的总额核对机制：** 依据美国国内税收法典，美国收款机构与电商平台在满足法定报告门槛时，会向国税局（IRS）及符合条件的纳税人报送 **Form 1099-K**；
- **毛额陷阱防范：** 1099-K 报表上载明的金额通常是**未经扣除退款、平台佣金甚至可能包含代征销售税的毛总额**。中国跨境卖家必须完整保存平台的结算月报（Settlement Reports），建立明晰的账目调节表，证明 1099-K 总流水与实际计入中国企业所得税营业收入之间的勾稽差异；对于未提供美国税号、仅签署 W-8 表格的纯外国卖家，平台通常不发放 1099-K 或另行报送 1042-S 表格。

##### 义务四：免税销售凭证与全链条数据归档备查
- 妥善留存平台出具的“代征代缴税务证明报告”（如亚马逊税务报告中的 Marketplace Facilitator Tax 列），**须按具体州和税种分别核实法定保管期限、起算时点、延长例外及注销后的责任**。内部可设5—7年或更长管理保留期作为`MODEL_ASSUMPTION`，但不得代替州法要求；例如CA、NY、TX分别读取其当期账簿保管指引，并保存平台代征证明、销售凭证、货运和免税凭据。

## 10.4 人在国内、公司在海外，所得税该怎么判断？

为了提升国际商业信誉、入驻特定海外电商平台或便捷接收外汇，越来越多的出海创业团队选择在中国香港、新加坡、美国（特拉华州/怀俄明州）或英国设立离岸公司。然而，公司注册在境外，并不等同于自动游离于所得税的监管之外。

### 10.4.1 在海外注册的公司，当地可能有哪些申报和所得税义务？

海外不同法域的公司所得税体制有着严格的属地与申报规则，绝不存在无条件的“天然避税天堂”。

#### 1. 常见海外公司注册地的所得税责任全景对照

```
【三大热门离岸设立地税制要素对比】
离岸设立地
  │
  ├─ 1. 中国香港公司 (HK Ltd)
  │    ├─ 两级利得税率: 首200万港币 8.25%，超出部分 16.5%
  │    ├─ 地域来源征税原则: 离岸免税申请须经受经营活动测试 (Operations Test)
  │    ├─ 审计要求: 活跃公司每年强制审计；符合法定程序及持续条件的休眠公司才可能适用审计例外
  │    └─ FSIE新规: 对符合范围的跨国企业实体特定外地所得（含2024年扩大的非股权资产处置收益）按各类别税收规则核验
  │
  ├─ 2. 新加坡公司 (SG Pte Ltd)
  │    ├─ 统一企业所得税率 17% (新设立前三年享受部分免税计划须具备实质条件)
  │    ├─ 境外所得汇入征税: 境外产生利润若留存境外通常不征，汇入需符合豁免
  │    └─ 维持合规: 必须委任新加坡本地持牌法定秘书，提交年报与税务申报
  │
  └─ 3. 美国单一成员 LLC (Single-Member Disregarded LLC)
       ├─ 联邦税层面穿透 (Pass-through): 联邦所得税默认忽略该实体、所得税处理通常穿透至所有者（仍核实外国所有人的美国来源收入、在美营业、州税/雇主税与不同税种的实体例外）
       ├─ 关联交易申报: 存在应申报关联交易时强制报送 Form 5472 与 1120，逾期罚款 $25,000！
       └─ 在美经营 (ETBUS) 判定: 若有在美依赖性代理人或常设场所，须按净利润缴纳所得税
```

#### 2. 各法域核心合规细节与实务陷阱

##### （1）中国香港公司（离岸免税判定与审计规范）
- **审计刚性与休眠豁免：** 依据香港《公司条例》，所有在港注册的活跃有限公司每年必须由香港执业会计师出具法定审计报告；休眠须按香港《公司条例》通过**特别决议并向公司注册处交付决议登记**，按法定生效日及有无相关会计交易等持续资格判断；不是只向部门申请并等待行政“批准”的程序。是否豁免准备/审计财务报表亦须逐条核对法定适用条款，不能仅看公司当年无营业额；
- **离岸免税申请的经营活动测试（Operations Test）：** 依据经典判例（如 Hang Seng Bank 案与 TVBI 案），判定利润来源的核心在于**考察纳税人从事了何种赚取利润的实质经营活动，以及这些活动在何地展开**。并非机械要求每一项琐碎行政流程都在境外，但核心谈判、签约与执行必须具备充分的离岸证据链；
- **FSIE（外地收入豁免征税机制）新规的适用边界：** 必须准确区分：香港FSIE自2023年涵盖符合条件的外地来源**利息、股息、知识产权收入及股权权益处置收益**；**自2024年1月1日起扩大至非股权资产处置收益**（需细分IP与非IP、经济实质/参与豁免/关联要求等），并主要涉及在港经营的合范围**跨国企业集团成员**。这与普通营业利润按经营活动判来源属不同制度，不能因“离岸收入”自动全免；见[香港税务局FSIE](https://www.ird.gov.hk/eng/tax/bus_fsie.htm)，与传统一般贸易利润的离岸来源判定属于两套并行的规则系统。

##### （2）美国单一成员有限责任公司（Form 5472 申报条件与罚款）
- **穿透实体的双刃剑：** 中国居民个人在特拉华州或怀俄明州设立的一人 LLC，在联邦税法上被视作“被忽略实体”（Disregarded Entity）。LLC在默认未选择按公司课税且仍满足单一成员等条件时**通常不单独缴纳联邦公司所得税**，但这不排除州税、雇主税、特定信息申报及外国所有者的美国税务责任；
- **触发申报的前提条件（Reportable Transactions）：** 依据美国财政部法规 Treas. Reg. § 1.6038A-2 及 Form 5472 填报说明（官方依据：[IRS Form 5472 Instructions](https://www.irs.gov/instructions/i5472)），外资持股达到 25% 以上的被忽略实体，**只有在当年度与外国关联方（包括外国所有者自身）发生了应申报交易（Reportable Transactions，包括注资、利润分配、借贷、管理费、技术服务费等任何资金或资产往来）时，才法定强制报送 Form 5472 与形式封面表 Form 1120！**
  - **关键反例A：** 即便LLC设立当年没有独立银行流水，外国所有者代付注册费、向LLC承担设立成本或注入资产，也可能形成Form 5472定义的设立、出资、分配等**报告交易**，需按照[IRS Form 5472 Instructions](https://www.irs.gov/instructions/i5472)核对并在触发时提交Form 5472及pro forma Form 1120。**反例B：**确无设立/清算/注资/费用/分配等应报告的关联交易时，不能机械认定每年必须交5472；同时不能把“账户无银行出入”作为充分证明。
- **罚款责任：** 一旦触发申报义务而逾期未报或申报内容存在重大不完整，IRS 将对**每份表格课以最低 25,000 美元的法定罚款**；催告后仍未纠正的，每逾期 30 天追加 25,000 美元。

### 10.4.2 海外公司由境内人员管理，会影响哪里的所得税责任？

这是跨国架构设计中最容易被出海团队忽略的合规盲区。

许多跨境创业团队的典型运作模式是：在香港或特拉华州设立一家离岸公司作为海外收款主体，但创始人、核心技术研发人员、运营决策者全部常年生活在中国境内，日常通过微信群决策、境内 IP 登录海外网银支配资金、从境内敲定所有海外采购与分销协议。

从国际税收法理与中国现行税法审视，这种模式面临**双重税收居民与“实际管理机构”穿透风险**。

#### 1. 实际管理机构原则（Place of Effective Management, POEM）
- **中国税法法定条款：** 依据《中华人民共和国企业所得税法》第二条第二款规定：“居民企业，是指依法在中国境内成立，或者依照外国（地区）法律成立但实际管理机构在中国境内的企业。”；
- **实际管理机构的判定标准：** 依据《企业所得税法实施条例》第四条及《国家税务总局关于境外注册中资控股企业依据实际管理机构标准认定为居民企业有关问题的通知》（国税发〔2009〕82号），实际管理机构是指**对企业的生产经营、人员、账务、财产等实施实质性全面管理和控制的机构**；
- **法律后果与救济机制：** 一旦主管税务机关依据经济实质原则，判定该离岸公司的实际管理机构位于中国境内，该离岸公司将被认定为**中国税收居民企业**，其全球所得依法应在境内缴纳企业所得税；但必须指出，若企业在境外已依法纳税，可依照税法第二十三条申请**境外税收抵免**，并非无条件双重全额加征。

#### 2. 双重税收居民冲突与协定加税规则
- 当注册地（如新加坡）依设立地主义主张所得税管辖权，而中国依据实际管理地主义主张征税权时，构成**双重税收居民冲突**；
- 此时应依据双边税收协定（如中新税收协定第四条第三款）中的加税打破规则（Tie-Breaker Rules），首要考察其实际管理机构所在地；若存在争议，由两地主管税务当局通过相互协商程序（MAP）解决。

### 10.4.3 海外金融账户会怎样受到CRS信息交换规则影响？

随着经济合作与发展组织（OECD）推行的金融账户涉税信息自动交换标准（Common Reporting Standard, CRS）在全球落地，离岸账户的税务透明度已大幅提升。

#### 1. CRS 的运行机理与分类穿透规则
出海团队必须准确理解 CRS 的运行机制，既不心存侥幸，也不将其误读为“实时逐笔电汇监控”：
1. **多边自动交换机制：** 参与国（地区）的金融机构每年根据尽职调查程序识别非居民金融账户，汇总呈报给当地税局，每年 9 月前后完成**年度批次信息对调**；
2. **积极实体 vs 消极实体的法定分类标准（OECD CRS 规则 Section VIII(D)(8)）：**
   - **积极非金融机构（Active NFE）：** 实体在上一日历年度或相应报告期内，**被动收入（Passive Income，包括股息、利息、特许权使用费、财产转让收益）占比严格低于 50%，且产生被动收入的资产占比严格低于 50%！** （官方依据：[OECD CRS Standard 官方文本](https://legalinstruments.oecd.org/public/doc/307/body-text.en.html)）。正常订阅SaaS如其经审核的上一期被动收入占比及产生被动收入资产占比**均严格小于50%**，可以属于此项Active NFE；以被动软件版税及持有投资资产为主的SaaS控股公司可能属于Passive NFE。**另有上市公司及其关联公司、政府实体等其他法定Active NFE类别**，不能单凭业务名称分类。Active NFE在CRS报告规则下一般不按Passive NFE穿透报告控制人，但金融机构依反洗钱AML/KYC规则仍可能需要识别股东和实际控制人；
   - **消极非金融机构（Passive NFE）：** 若被动收入或被动资产占比达到或超过 50%，金融机构必须执行**穿透式尽职调查**；
3. **控制人识别阶梯规则（Controlling Persons）：**
   - 控制人的认定并非仅看持股 25%！依据 OECD CRS 释义及反洗钱规则，金融机构按以下三级阶梯依次识别：
     1. 首先识别直接或间接拥有公司 **25% 以上股权或表决权**的自然人；
     2. 若通过股权无法确定，识别**通过其他方式对公司行使实质控制**的自然人（如协议控制人、债务控制人）；
     3. 若仍无法确定，识别公司的**高级管理人员（Senior Managing Official）**作为控制人报送；
   - 仅在账户由参与司法辖区的应报告金融机构持有、满足可报告账户及控制人税收居民条件、适用的主管当局交换关系等前提下，账户年末余额和有关支付金额才**可能按年度交换至对应税收居民法域**。并非所有账户或每笔交易自动、实时回传；

#### 2. 美国对 CRS 的独立立场与跨国信息互助
- **客观事实：** 美国未签署 OECD 多边主管当局协定（MCAA），**不是 CRS 参与国**；
- **合规警示：** 美国未加入 CRS 绝不意味着美国银行账户具有绝对保密性！中美两国在《中美关于避免双重征税和防止偷漏税的协定》第二十五条中明确确立了**情报交换机制（Exchange of Information）**；在涉及跨国税务稽查、司法协助或涉嫌洗钱逃税时，两国税务主管当局可通过专案特定情报交换程序获取相关银行账户信息。

### 10.4.4 海外经营可能形成常设机构时，怎样判断协定与双重征税风险？

在跨国税收协定体系中，除了直接注册子公司外，出海企业在海外目的地从事某些深入的商业活动，可能被东道国税法判定为设立了**常设机构（Permanent Establishment, PE）**，从而丧失仅在母国纳税的协定保护。

#### 1. 常设机构判定的多元法源与服务型 PE 差异
1. **服务型常设机构（Service PE）并非全球统一 183 天规则：**
   - **关键核验：** 许多出海企业误以为“只要派人在境外工作超过 183 天就自动触发 PE”。事实上，**服务型 PE 条款取决于具体双边税收协定的约定！**
   - **中美协定具体反例：**[IRS公布的中美避免双重征税协定第5条第3款(c)](https://www.irs.gov/pub/irs-trty/china.pdf) **明确有服务型常设机构条款**：企业通过雇员或其他受聘人员，在另一国就**同一个或相关联项目**提供服务（含咨询），**在任意12个月内于该国累计持续超过6个月**，属于该条服务PE判定范围（仍须核对协定居民、人员活动、地点、项目关联与其他例外；不是通用183天或个人所得税停留天数测试）。**教学反例（MODEL_ASSUMPTION）：**仅5个月的同一项目服务通常未达到此项时长标准，仍可能因固定场所/代理人构成其他PE；7个月的同项目现场咨询可能满足服务PE的时长条件；两项真正独立且不相关的短项目不能未经核实就简单合并认定，但应检验“关联项目”实质，不允许人为拆分规避。
   - **中新协定另行判别：**新加坡与中国适用的协定版本、条号和累计时间口径须查两国正式协定及修订议定书；不得把它直接复制为中美规则。个人雇员工资及独立劳务应各查独立条款，不得混作企业PE判定。
2. **固定场所 PE 与海外仓反碎片化规则：**
   - 应先核对适用双边协定文本（例如中美协定第5条第4款列明特定仓储、陈列、交付用途例外）；是否需要证明活动的准备性/辅助性、是否被议定书或MLI改变以及具体代理/仓库经济实质须逐约分析，不能把OECD范本自动代入所有生效双边协定；
   - **反碎片化防线（Anti-Fragmentation Rule）：** 随着后 BEPS（税基侵蚀与利润移转）多边公约（MLI）的实施，如果企业将海外仓拆分为多个紧密关联的环节（如仓储、包装、分销、退换货加工），整体商业活动超越了准备性或辅助性范畴，东道国税局有权判定其构成固定营业场所常设机构。

#### 2. 触发常设机构的法律后果
- 一旦被判定构成常设机构，企业属于该常设机构经济贡献的营业利润，必须**按东道国的企业所得税法在当地申报缴纳企业所得税**；
- 企业可通过主张双边税收协定的常设机构条款，并在母国申请境外所得税额抵免来避免双重征税。

## 10.5 海外客户要税务表格或直接扣税，怎么办？

当中国开发者将应用上架苹果 App Store、Google Play，或向境外企业客户提供企业级 SaaS 授权，抑或为美国平台提供远程技术劳务时，常常在结算打款前被要求填写美国国税局（IRS）预提税务表格。

### 10.5.1 海外客户要求W-8等税务表格，我该怎样确认应填哪种？

美国客户要求填写W-8表格时，**先确认真正的收款人/美国税务上的收入实际受益所有人、所得来源和性质**，再判断是否属于美国来源且适用Chapter 3/4预扣，最后选表。**美国付款方在美国**不等于开发服务必为美国来源，**软件订阅/应用商店分成**不自动等于知识产权版税。对美国来源、属于适用范围的非有效关联FDAP收入，国内法预扣可能以30%为起点，协定优惠仍须依据具体税目和资格另审。[IRS个人服务收入来源规则](https://www.irs.gov/individuals/international-taxpayers/source-of-income-personal-service-income)、[IRS中美协定](https://www.irs.gov/pub/irs-trty/china.pdf)。

#### 1. 先按交易性质判断，再选表

| 典型案例（均须按合同实质核对） | 美国来源/预提判断 | 表格起点 |
|---|---|---|
| 中国居民个人在深圳全程远程为美国客户定制软件并交付服务成果 | **服务通常按实际履行地点确定来源**，不因美国付款就自动成为美国来源版税或需30% FDAP扣缴；若授予可独立利用的版权，还须重新定性 | 外国个人通常以W-8BEN证明非美国身份；是否需提供由付款方的合规程序决定，不能在Part II虚报版税优惠 |
| 中国公司真正授予美国客户在美国使用软件著作权/复制发行等法定权利，取得美国来源版税 | 符合所得性质、实际受益所有人与中美协定税收居民资格时，方可根据**第11条版税**审查10%协定上限及美国付款人扣缴程序；平台销售分成不自动属于此例 | 实际受益所有人属外国实体的通常W-8BEN-E，按收入及协定资格正确填写相关部分 |
| 平台作为法律转售方收取终端买家款，再向中国开发者支付商品价款或服务费 | 先看真实买方、知识产权授予内容、代销/经销合同及实际履行地点，不能仅凭后台“royalty”字段认定 | 视真正受益所有人/所得类型/实体分类决定，有时不涉及该类美国来源预扣 |
| 企业在美国有有效关联所得（ECI） | 合格收入通常走美国申报课税与对应W-8ECI等手续；不应与所有普通FDAP混用 | 核实是否真实有效关联并按[IRS W-8ECI说明](https://www.irs.gov/forms-pubs/about-form-w-8-eci)选择 |

#### 2. W-9、W-8BEN、W-8BEN-E与“美国注册LLC”的实际所有人

- **W-9**用于美国税务意义上的U.S. person（例如美国税务居民个人、符合条件的美国公司/被选择按公司课税的美国实体），而不是凭**LLC注册地**一律填写。外国所有人持有的美国单一成员LLC若为联邦所得税**disregarded entity**，某些款项通常应由**外国实际所有人**按其个人/实体身份填写W-8BEN或W-8BEN-E，而非LLC自动使用W-9。按章4/FATCA、付款账户、收入和申报目的可能有例外；若LLC选择按公司课税则另判。见[IRS W-8BEN-E说明：Disregarded Entity](https://www.irs.gov/instructions/iw8bene)。
- **W-8BEN**通常对应非美国税务居民自然人作为实际受益所有人；**W-8BEN-E**对应合格外国实体实际受益所有人；**W-8ECI**仅在确属适用的有效关联所得等条件下选用。**不能把所有中国个人身份证号、所有中国有限公司的Corporation/Active NFFE或Part III协定优惠当成默认勾选**，先按自身实体税务分类和章节定义核查。

#### 3. FTIN（6a/6b）、税收居民与协定条件怎么核验

1. **身份与税号：**核查个人/公司真实税收居民身份，实际受益所有人、外国税号及是否需要美国TIN。W-8BEN第6a栏FTIN在特定美国金融账户、需1042-S报告以及其他适用情形有填写要求和例外；中国个人居民身份证号码可构成个人税务识别号码的一种，仍须核实**其确为实际适用FTIN**，而非机械填身份证号。第6b栏“FTIN not legally required”不得在实际有应填FTIN但不想披露时随意勾选；按[IRS W-8BEN Line 6a/6b说明](https://www.irs.gov/instructions/iw8ben)逐项判断。
2. **例子A：**中国税务居民个人取得有1042-S报告的美国来源特许权使用费，填写W-8BEN时先核对有效FTIN/美国TIN、具体Part II条约及税种，不能仅因有银行账户就自动享协定；**例子B：**在中国完成全程远程服务且经核验不属应扣美国来源收入，W-8可能仅用于收款方身份确认，不应勾选并不存在的版税优惠；**例子C：**中国税务居民公司因真正美国来源版权许可主张协定，须提供企业适用税号、证明属于协定居民和实际受益所有人、满足具体协定限制并按实际税目填写W-8BEN-E。
3. **协定条款/LOB：**中美1984年协定没有现代通用的综合LOB条款时，符合资格的中国实体在相应W-8BEN-E Line14b可依据当期有效说明考虑`No LOB article in treaty`选项；**只在真实主张中美协定待遇且该选项确实适用时**选择，不能所有中国企业一律勾选、也不能从No LOB直接推出免除税收居民和反滥用资格审查。Form W-8是身份/待遇声明，不是IRS自动核准的税率证明。[IRS W-8BEN-E Instructions](https://www.irs.gov/instructions/iw8bene)。
4. **提交与留存：**通常将正确表格提供给付款方/扣缴代理而非自行直接交IRS，按有效期、信息变更后的更新要求管理，保存付款结算单、合同、1042-S及税收居民证明。如税务身份和公司结构复杂，取得美中合规专业人员书面结论后再选择。

### 10.5.2 海外扣缴的所得税，国内是否可以申请税收抵免？

当海外客户或苹果、谷歌等分销平台依照税法扣缴了预提所得税后，扣除税款后的外币净额汇入中国境内。我国税法为避免跨国双重征税，提供了严密的**境外所得税额抵免（Foreign Tax Credit, FTC）**机制。

#### 1. 境外所得税抵免的法定前提条件
根据《中华人民共和国企业所得税法》第二十三条、《个人所得税法》第七条及《国家税务总局关于发布〈企业境外所得税收抵免操作指南〉的公告》（国家税务总局公告2010年第1号）规定，申请境外税额抵免必须同时满足以下硬性条件：
1. **税种性质对应限制：** **须是依法允许抵免的境外所得税性质税款，并与中国税法认定的可抵免境外所得、纳税人和计算期间相匹配！**
   - **可能正例：**经合同/美国来源规则/中美协定核验，真正属于美国来源版权许可且确由中国企业依法负担的可抵免预提所得税、符合条件的境外股息预扣所得税；不是所有软件分成或报表扣款都能列为可抵税额。
   - **反例警告：** 境外缴纳的**销售税（Sales Tax）、增值税（VAT）或进口关税，绝对不属于所得税范畴，绝对不得在企业所得税汇算中申请税额抵免！** （流转税在会计上作为营业成本或税金直接冲减利润，但不能直接冲减中国应纳所得税额）；
2. **不得超过法定“抵免限额”：** 抵免税款不得超过按中国税法测算的境外所得应纳税额上限；
3. **境外完税凭证要求（不强制单一原件）：** 根据税局规定，纳税人应提供境外税务机关出具的完税证明、缴税凭证，或者**扣缴义务人出具的扣缴凭据（如美国国税局 Form 1042-S）配合银行资金收款流水等合法凭单**，经主管税务机关审核确认后予以抵免。

#### 2. 企业所得税境外税额抵免限额复算模型（MODEL_ASSUMPTION）
依据我国企业所得税法，境外税额抵免法定限额公式如下：
$$\text{境外税额抵免限额} = \text{境内外所得按中国税法计算的应纳税总额} \times \frac{\text{来源于某国（地区）的应纳税所得额}}{\text{境内外应纳税所得总额}}$$

> **基准复算案例（MODEL_ASSUMPTION）：**
> - 境内某科技企业 2026 年度实现境内应纳税所得额 4,000,000 元；
> - 当年通过软件出海从美国取得特许权使用费收入折合人民币 1,000,000 元（对应研发与分摊成本 200,000 元，境外净应税所得额为 800,000 元）；
> - 美国平台依据中美税收协定按 10% 扣缴预提所得税，实际在美纳税：$1,000,000 \times 10\% = \mathbf{100,000\text{ 元}}$；
> - 该企业适用中国法定企业所得税税率 25%。

##### 抵免限额计算与税负平衡测算过程：
1. **境内外应纳税所得总额：**
   $$\text{应纳税所得总额} = 4,000,000 + 800,000 = \mathbf{4,800,000\text{ 元}}$$
2. **境内外应纳税总额（按中国税法测算）：**
   $$\text{中国应纳税总额} = 4,800,000 \times 25\% = \mathbf{1,200,000\text{ 元}}$$
3. **美国所得的中国法定抵免限额：**
   $$\text{抵免限额} = 1,200,000 \times \frac{800,000}{4,800,000} = \mathbf{200,000\text{ 元}}$$
4. **实际抵免与应补税款：**
   - 境外实际纳税额（100,000 元）低于法定抵免限额（200,000 元）；
   - **只有在该100,000元确为中国居民企业对依法认定的美国来源所得实际负担、允许抵免的所得税，并已取得适用证明与满足分国（地区）或不分国（地区）抵免方式、汇率及期限等条件时**，该模型才允许在200,000元限额内抵免100,000元；若属于销售税、并非依法可抵外国税、受益人不符或缺合法凭证则不能据此抵免。
   - 境内最终实缴企业所得税为：$1,200,000 - 100,000 = \mathbf{1,100,000\text{ 元}}$；
   - 境外已纳所得税在限额内冲抵了境内应纳税额。需要客观指出，最终整体综合有效税负受是否存在不可抵扣调整项、研发加计扣除优惠等多种因素共同决定。如属于**依法可抵免**但因年度抵免限额不足的超出部分，才按中国现行抵免制度的相应期限和方式审查可否结转（例如企业所得税法实施条例第81条的五年限额内结转）。超缴的境外非合规税款、与该企业/该所得无关的税款，不能把它们当作统一可结转资产。

## 10.6 海外销售扩大后，怎样及时发现新的税务义务？

出海业务呈现非线性爆发增长特征。一个爆款产品的产生或一次成功的海外投放，往往在数月内将订单推向数十个新的州和国家。如果缺乏动态监控机制，企业极易在不知不觉中陷入严重的跨国税法违约。

### 10.6.1 业务扩大后，怎样发现目的国或州的新税务登记门槛？

为了避免遭遇突发性的海外税局稽查追缴函件，出海企业必须在运营底层建立一套前置性、常态化的**“税务联结雷达监控机制”**。

```
【海外税务联结动态监控四步法则】
1. 数据月度归集 ──> 2. 预警红线机制 ──> 3. 仓储变动监控 ──> 4. 法规动态追踪
```

#### 详细实操规则与行动指引
1. **以目的国/州为维度的月度收入台账归集：**
   - 财务与数据团队必须在每月月初，从 Shopify、ERP 或自建数据库中导出上一日历月及过去滚动 12 个月的销售报表；
   - 严格按照**收货人目的州（State/Province）与目的国（Country）**进行订单量、销售额汇总切片，而非单纯按收单币种汇总；
2. **设立 80% 临界预警红线机制（MODEL_ASSUMPTION）：**
   - 针对各目标法域设立预警安全缓冲区（如将 80% 设为企业内部管理预警线）：
     - 若某州门槛为 100,000 美元，当滚动 12 个月销售额达到 **80,000 美元**时，财务系统自动亮起黄色警示；
     - 当达到 500,000 美元门槛州的收入达到 **400,000 美元**时，触发法务与外部税务顾问介入评估；
   - **法定期限与生效时间窗口核对：** 必须对照各州具体法规所规定的办妥许可及起征时限（例如，得克萨斯州远程卖家在超过门槛后，税法赋予其在随后的**第四个月的第一天前**取得许可证并开始代征税款，Texas Tax Code § 151.0595）；
3. **仓储库存物理位置的动态穿透监控：**
   - 开启亚马逊 FBA“库存配置服务（Inventory Placement）”或与海外 3PL 合作时，海外仓服务商往往会为了物流时效将卖家的货物调拨至新的分拨中心；
   - 卖家必须每月下载《多渠道配送库存历史报告》，核对存货实际停留在哪些州，**一旦货物进入新州仓库，立即触发该州物理实质联结的合规排查**；
4. **全球税法动态的定期排查：**
   - 设立专门机制定期跟踪核心市场的规则变动（如欧盟关税改革新条例、美国特定州废除交易笔数门槛等）。

### 10.6.2 什么规模和情形下，值得使用自动算税或申报工具？

面对全球碎片化的税制规则，依靠人工手动在后台维护各个邮编的税率并手动填报数十个州的税表，在业务规模化后是完全不可持续的。但市面上的税务自动化 SaaS 工具收费不菲，盲目采购极易造成预算浪费。出海企业应根据业务阶段与渠道模型进行理性选型。

#### 1. 全球主流税务自动化工具的分层能力对比

| 工具类别与代表厂商 | 核心功能范围与交付形态 | 优势与核心价值 | 局限性与成本特征 | 最佳适用业务场景建议 |
|---|---|---|---|---|
| **第一层：嵌入式实时算税引擎**<br>代表：*TaxJar (Stripe旗下)*、*Avalara AvaTax*、*Stripe Tax* | 通过 API 接入电商后台，根据买家精确街道地址自动计算应征税额；自动监控各州经济联结进度条。部分工具（如 TaxJar）同时提供报税扩展插件。 | 算税精度高；无缝集成主流建站工具；提供直观的经济关联预警仪表盘。 | **以 API 计费为主**；申报功能通常需按州或按次增购附加订阅包。 | **起步与成长型独立站：** 业务覆盖 2-3 个州门槛的跨境电商团队。 |
| **第二层：全自动申报与汇缴系统**<br>代表：*TaxJar AutoFile*、*Avalara Returns*、*Sovos* | 在实时算税基础上，系统自动生成符合各州税局标准的电子报表，直接代卖家向各州税局批量提交报表并代划缴税款。 | 大幅释放财务人工；解决数十个州不同报表格式与申报截止日的错配痛点。 | **每州每期单独收取申报服务费**；遇到税局系统更新或退税争议仍需人工核验。 | **中大型独立站与多渠道品牌：** 已在多个州注册税号，每月需稳定处理多州申报的企业。 |
| **第三层：商户记录代理模式 (MoR)**<br>代表：*Paddle*、*FastSpring*、*Lemon Squeezy* | 作为法定转售方接管数字交易，替卖家承担该平台订单的全球算税、代收、报税与汇缴责任。 | **大幅简化数字服务间接税合规**；开发者无需在每个目的地国注册增值税号。 | **交易抽成费率较高**；开发者仍须自主处理自身直接所得税及非平台渠道税务。 | **中小出海 SaaS 团队与独立开发者：** 团队规模较小、主攻欧美市场、无力自建海外财税团队的软件团队。 |

#### 2. 工具采购与人工替代的成本效益决策模型（MODEL_ASSUMPTION）
出海企业可采用**“年度综合合规成本 = 软件订阅费 + 申报服务费 + 内部人工工时成本”**的模型进行理性评估：
- **模型案例 A（起步型：覆盖 1 至 2 个州，MODEL_ASSUMPTION）：**
  - 若仅在 1-2 个州产生代征义务，每季度人工在线填报耗时约 2 小时（折合内部财务工时成本约每年 1,000 - 2,000 元人民币），此时采用自主申报或仅采购基础算税插件（基础年费约几百美元）通常更具经济性；
- **模型案例 B（规模扩张型：覆盖 5 个州以上，MODEL_ASSUMPTION）：**
  - 当突破门槛的州达到 5 个以上时，手动申报面临极高的跨州规则错配风险与逾期罚款隐患。此时采用 AutoFile 自动化报税（`MODEL_ASSUMPTION`：若每州每季一次、每次35—60美元，**5州×4季×35—60美元=年700—1,200美元**，另有订阅/开户/复杂申报等其他费用另列，不能无依据凑成1,500—3,000美元），或委托专业跨国财税会计师事务所，能够显著降低综合法律风险。

- **人工与自动的订单阈值示范（MODEL_ASSUMPTION，金额均为美元）：**若人工年度总成本为`6,800+5N`，自动方案为`7,400+0.5N`，两者相等时`N=600/4.5≈133.33`，**整数从134笔起自动方案才更便宜**；在133笔时人工7,465美元、自动7,466.50美元（人工更便宜1.50美元），134笔时人工7,470美元、自动7,467美元（自动更便宜3美元）。这一示例中自动工具的固定成本更高、单笔增量成本更低，**仅为教学示例，不代表真实产品报价**；必须把各项真实报价代入并明确比较方向。低订单量且只有平台代征、未产生多州自行申报义务者，不应假设一定要购买多州AutoFile。

## 一、撰写口径

1. 按原《现代商业支付系统》正式格式区分一级短名称、唯一核心问题、二级问题与三级问题。
2. 三级只拆解二级问题里的必要判断，不以某个工具、服务商或 IP 指纹规避方案作为普遍答案。
3. 三级问题围绕**知识原理 / 实际选择 / 实施与验证 / 重要限制**组织；每个二级先提供 2 项三级候选，需要时继续增补，而不人为追求数量。
4. 法律、平台准入、计费、商业免费条款是**待研究的问题**，不能把提问当成已验证的事实；所有云服务、证书、备份与安全效果均不得作无限保证。
5. 与第三板块支付税务经营主体、第四板块产品研发、第五板块获客保持边界。

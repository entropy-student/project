# 第七部分 故障与恢复｜网站或程序出了问题，怎样及时发现并恢复？

## 1. 我不可能天天盯着网站，怎样让系统自动发现问题并提醒我？

### 1.2 怎样设置有用的告警、通知渠道和简单的故障处理责任安排？

## 2. 网站突然打不开了，应该从哪里开始排查？
### 2.1 网站打不开、响应变慢和程序报错，分别怎样按连接链路逐层排查？
### 2.2 哪些日志、监控记录和最近配置变更能帮助找出真正原因？

## 3. 哪些东西一定要备份？多久备份一次，放在哪里才安全？
### 3.1 哪些业务数据、配置和账号恢复材料一旦丢失就难以重建，应该分别怎样妥善保存？
### 3.2 怎样按可接受的数据损失确定备份频率、存放位置与保护方式？

## 4. 服务器坏了、资料丢了，怎样尽快恢复正常经营？
### 4.1 不同故障下，应该优先恢复哪些客户可用功能和重要数据？
### 4.2 如何结合可接受停机时间、现有备份与备用服务制定实际可执行的恢复步骤？
### 4.3 恢复服务后，怎样确认重要数据一致，并避免重复执行关键操作？

## 5. 怎样确认备份真的能用，并避免类似故障反复发生？
### 5.1 怎样在安全的独立环境中测试备份是否完整且能够恢复关键功能？
### 5.2 故障解决后该如何复盘、更新监控和修订恢复方案，减少再次发生？

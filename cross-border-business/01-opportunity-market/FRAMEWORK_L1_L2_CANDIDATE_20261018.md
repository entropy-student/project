| 一级模块及卖家问句（候选） | 编号 | 二级卖家问句（候选） | 后续正文应覆盖的知识边界（非问题标题） |
|---|---|---|---|
| **1. 发现机会**：我该去哪里找值得做的跨境生意？ | 1.1 | 从哪里能发现新的生意机会？ | 搜索行为、客户评论和抱怨、平台与社区、采购线索、行业和地区变化；区分线索与已证实需求 |
|  | 1.2 | 看到一个热门产品或客户抱怨，怎么判断有没有生意可做？ | 把线索转换成客户、问题、场景、可能付费价值和待证假设；不急于确定产品 |
|  | 1.3 | 点子一大堆，先调查哪几个？ | 线索来源可信度、具体程度、初步需求迹象、调查成本和明显障碍；只做初筛 |
| **2. 识别需求**：谁会买，我怎么知道他们真的需要？ | 2.1 | 我应该先卖给哪一群人？ | 按角色、用途、行业、地区及购买条件细分客户；避免把所有人当客户 |
|  | 2.2 | 他们在什么情况下会需要这个东西？ | 客户当时要完成的事、痛点触发、真实使用场景、已有流程和期望结果 |
|  | 2.3 | 这件事对客户有多重要，不解决会怎样？ | 需求频率、紧急性、时间/金钱损失、现有解决成本；区分刚需、可选项和表面兴趣 |
|  | 2.4 | 想用的人和真正掏钱的人是同一个吗？ | 使用者、付款者、决策者、预算来源、购买流程与障碍 |
|  | 2.5 | 客户说自己需要，有什么证据能证明？ | 访谈、评价、购买记录线索和行为观察；需求调查的样本偏差；不把此处的需求证据当作第⑥章实际成交验证 |
| **3. 分析竞争**：别人已经在卖了，我还有机会吗？ | 3.1 | 客户不买我的东西时，会怎么解决同一个问题？ | 直接竞品、替代品、免费或人工解决方案、自建与维持现状 |
|  | 3.2 | 同行为什么能卖出去，客户又在嫌弃什么？ | 竞品价值、定位、价格、信任、服务和评论反馈；不直接把抱怨当商机 |
|  | 3.3 | 同行很多或者几乎没有同行，各意味着什么？ | 竞争强度、集中度、市场进入门槛、切换成本，以及市场可能根本不存在的风险 |
|  | 3.4 | 客户凭什么换成我的产品或服务？ | 有价值的差异化、未被满足的要求、转换阻力、可被相信的承诺 |
| **4. 判断市场**：这个市场有多大，还能做多久？ | 4.1 | 别人说的“市场很大”，到底有多少跟我有关？ | 区分行业总体、目标细分市场及现实可触达范围，明确客户/用途/地域边界 |
|  | 4.2 | 怎么估算真正可能向我买单的人有多少？ | 从客群数量、购买频率、可触达范围与单价推算，使用上下界并检验来源 |
|  | 4.3 | 现在很火，是长期有需求还是一阵风？ | 成交与搜索历史、季节性、周期、数据口径及交叉验证，避免只盯近期热度 |
|  | 4.4 | 同一门生意，哪个国家或地区更值得尝试？ | 市场需求与竞争、消费习惯、支付能力、语言差异、渠道可达性 |
|  | 4.5 | 有哪些变化可能让这个市场突然变难做？ | 技术替代、平台政策、供应链和经济变化、单一市场/平台依赖；资格细则属其他板块 |
| **5. 评估生意**：卖这个能赚钱吗，我做得来吗？ | 5.1 | 这种生意通常怎么收费，哪种方式更适合？ | 一次性销售、按次、订阅、佣金、项目与服务收费；按业务形态比较收入模式 |
|  | 5.2 | 卖多少钱比较合适？ | 客户感知价值、竞品与替代价格、目标价格带、折扣和不同地区差异；属于待验证定价假设 |
|  | 5.3 | 每卖一单能剩多少钱，卖多少单才回本？ | 单位成本、变动费用、获客成本假设、贡献利润、固定费用和盈亏平衡 |
|  | 5.4 | 开始做得花多少钱，钱什么时候能回来？ | 启动预算、库存/开发支出、现金流、回款周期与资金周转风险 |
|  | 5.5 | 真的接到单了，我能稳定交货或提供服务吗？ | 时间、技能、供应商、物流、售后、交付与扩张瓶颈；不进入④的具体产品实现 |
|  | 5.6 | 哪些门槛可能让我根本卖不了，或者代价很高？ | 平台准入、禁限售、知识产权和商业授权、关键法律经营约束；具体②③流程不在本板块 |
| **6. 验证机会**：不先投入很多钱，怎么试出有人真买？ | 6.1 | 现在最该先弄清楚的，是哪一个不确定的问题？ | 识别需求、愿付价格、触达、成本、交付等关键假设；按风险与验证代价排序 |
|  | 6.2 | 东西还没正式做出来，怎么低成本试卖？ | 报价、样品、演示、试点、预订、付费试用与少量交付；真实说明交付能力，不做误导性承诺 |
|  | 6.3 | 点赞、询价和实际付款，分别能证明什么？ | 区分兴趣、意向、询盘、预付款和真实交易的证据强弱；关注退款或撤销 |
|  | 6.4 | 试到什么程度，才值得继续花钱？ | 代表性样本、成交与成本指标、可重复性、时间和预算门槛；不以一个好评判断成功 |
|  | 6.5 | 没人下单，是生意不行，还是测试方式有问题？ | 检查客群、场景、价格、信任、样本、展示和购买阻力；返回前面章节修正 |
| **7. 选择与决策**：好几个方向都想做，我该先选哪个？ | 7.1 | 怎样比较几个方向，不被热度和预估利润带偏？ | 统一比较需求证据、市场范围、竞争、利润、可行性、风险和机会成本 |
|  | 7.2 | 证据还不够时，应该开始做、再试一轮，还是先放下？ | 未知项、继续验证价值、可逆性与投入边界；不重写第⑥章实验方法 |
|  | 7.3 | 决定试一试之后，先投多少钱和多少时间合适？ | 分阶段投入、预算与时间上限、放大投入条件，避免一次押注 |
|  | 7.4 | 做到什么地步，就该换方向或及时停下？ | 止损信号、持续低于预期、需求变化、机会成本、调整与退出判断 |

## 设计与去重说明

- ①仅收集、转化与初筛线索；⑦负责面对多个选项时最终取舍。
- ②研究客户真实问题及需求迹象；⑥才是用小规模真实行为检验购买承诺。
- ③研究竞争和切换原因；⑤研究自己如何收费、成本和经营条件。
- ④判断市场整体空间、地区和变化；②判断具体客户是谁、遇到什么问题。
- ⑤只判断交付与资格**可行性**；④板块负责产品、订单与履约实际建设，③负责支付/主体/财税细则，②负责网络环境。
- ⑥只研究入场前最小化验证；⑤板块负责经营阶段持续获客、转化和复购。②—⑤可交叉并行，⑥的结果可以迫使重新选择。

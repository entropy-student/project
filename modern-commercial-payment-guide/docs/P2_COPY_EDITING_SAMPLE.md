# 卖了174美元，扣完已知费用为什么只剩129.52美元？

六笔29美元的订单，顾客一共付了174美元。按一条特定的PayPal中国大陆企业账户路线演算，扣完收款手续费剩164.52美元；再发起一笔美元电汇，扣掉35美元，剩129.52美元。

从174到129.52，少了44.48美元。钱还没有真正进入银行，可能发生的银行收费和换汇损耗也没算进去。对需要用这批订单收入支付下一笔经营开支的商家，这个差额很值得先看清楚。

先限定例子的范围。假设一家中国大陆企业卖29美元的数字商品，买家在海外，以美元支付，商品与收款权限均已获批准。企业持有的PayPal账户须按《PayPal中国跨境支付服务用户协议》和《PayPal全球服务条款》开立，也获准通过美元电汇提现至中国大陆银行。只有在这组条件下，才采用下面的公开价格。其他协议或账户产品不能直接照搬。

先看六笔订单里的任意一笔。PayPal这类国际商业美元收款的标准交易费为4.40%，另外每笔收0.30美元。29 × 4.40% + 0.30 = 1.576美元。为了让批次金额好算，假设逐单先四舍五入到美分，也就是每单手续费1.58美元，留下约27.42美元。

六单共留下164.52美元。到这里扣掉的是收款手续费，商家在PayPal一侧有了这笔模拟余额，仍需要把钱提到能合法使用的银行账户。支付账户显示金额与银行实际收到金额之间，隔着提现规则。

为什么偏偏算六单？PayPal中国区提现帮助说明，美元电汇到中国大陆银行，最低提现金额是150美元。五单的交易后余额只有137.10美元，按本例条件还差12.90美元；第六单加进来，余额来到164.52美元，才越过最低金额要求。订单从五单变成六单，改变的是这批钱能否达到申请这一路线提现的金额门槛。

达到150美元，商家接着要看每次提取多少钱。PayPal的对应**企业账户**费率表列出，中国大陆银行电汇每笔提现收费35美元。六单放在一起只提一次，164.52减35，就有了开头的129.52美元。六笔订单一共扣了约9.48美元交易费，再扣35美元固定电汇费；两笔费用在收款和提现两个环节发生，很容易在只看单笔订单时漏掉后者。

129.52美元只是扣除这两层已知费用后的**银行入账前估值**，不是已到银行的实收金额。此例还假定六笔交易成功，没有退款、拒付、风险预留或其他余额调整；实际逐笔舍入方式也未核实。银行汇入或中转费用、可能的换汇差额、税款及经营成本尚未确定。PayPal帮助页面列出的美元电汇通常需要3至7个工作日，并提示所有提现要审核，到账时间也不能按日历机械倒推。

固定的35美元，把低单量和高单量的选择拉开了。仍按每单约剩27.42美元、每批只提一次来算，十单交易费后为274.20美元，再扣电汇费约剩239.20美元，每单摊3.50美元电汇费。一百单顾客合计付2900美元，交易费后约2742美元，扣35美元后约2707美元，每单分摊只有0.35美元。这几个数字同样停在银行额外费用和汇兑之前。

同样一笔35美元，为什么要考虑订单数？一家每月仅有五单、下周就要用钱采购的商家，按本例连150美元门槛都达不到，只能等更多订单，或先核实另一条对自身真正开放、可合法提现的路线。订单接近百单、可以攒一批再提的企业，35美元摊得少了，反而可能愿意考虑这条路线。两家商家即使卖同样的商品，想要的到账时间和能接受的成本也不一样。

尤其要分清企业和个人。本例35美元的电汇费来自特定企业PayPal账户的价目表。大陆自然人能否按真实身份使用对应的商户服务、出售这一类数字商品，能否把经营款项合法提到本人银行账户，都需要分别核验。仅有一张境外银行账户或一个支付按钮，无法替代商户资格及资金用途的审核。

收款路线选得合不合适，最终要落到一笔能支配的钱上。可以先按自己预计的月订单量，问清所选账户是否准入、需要攒到多少才能提、一次提款的固定费有多大、通常多久才能拿到钱。确认了这些，再比较其他确实符合资格的选项。

六单时的129.52美元和百单时的2707美元，反映的是同一套公开费率在不同订单规模下的结果。单量、每批的固定费，以及这笔钱必须在哪一天以前用上，会让同一条收款路线在不同阶段出现不同的答案。

## 来源与演算前提

这是使用公开费用规则的**假设演算**，没有真实收款或提现测试。对照来源为 [已审P2正文 §4.1（第130—172行）和 §5.1 演练A（第228—245行）](https://github.com/entropy-student/project/blob/17ea75adec7448a8bbe6387788b5bfe321ff68f6/modern-commercial-payment-guide/docs/P2_REWRITE_CANDIDATE.md)、[PayPal中国大陆商家费用（S02）](https://www.paypal.com/c2/business/paypal-business-fees?locale.x=zh_C2) 和 [PayPal中国区提现帮助（S05）](https://www.paypal.com/c2/cshelp/article/how-do-i-withdraw-funds-from-my-paypal-account-help394)。S02只适用于指定中国跨境支付服务协议及全球服务条款下的账户，不适用于依据《PayPal支付服务用户协议》开户的账户。上述35美元取自S02**企业PayPal账户**中国大陆电汇费用；150美元门槛及3至7个工作日取自S05。费用、账户资格和最终入账以真实合同、审批结果、银行及汇率为准。

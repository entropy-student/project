## APPLICABLE_CRITICAL_CONSTRAINTS

1. **双目标分别评估：** A“愿意读”与B“解决疑惑”各自独立评分、举证和结论。A 的专家/Agent 冷读只是**代理指标**，不是真人意愿或完读率。B 的场景推演也只是文本可用性诊断，不能冒充真实账户可开通或资金到账。
2. **不能预先给读者标准答案。** 测试包分“读前意愿→读中关键节点→读后独立输出”三个阶段；读后先记录读者自己的判断，再展示对照/核验答案。问法应为普通商家用语，不用“你是否已经学会6项决策输出”这种诱导式提问。
3. **读者最小输入（8项）：** ①真实经营主体/地区及已有资格；②商品/服务和一次性或订阅；③客户市场和顾客类型；④销售渠道/谁对消费者销售；⑤典型客单价+月订单量；⑥最终合法受款账户地区/币种（只需类别，不要卡号/账号）；⑦资金何时必须可用；⑧已获批准/尚待审核的商户和结算服务。可将①与⑧分开问，不能要求读者先懂支付术语。
4. **六类输出逐项核验：** ①适合的商业收款模式；②不合格路线/条件候选/已获证据资格的状态；③明确值得优先核验的具体路线或服务类别；④有条件的已知费用与预计现金时间、UNKNOWN项；⑤主用与真实独立备用的选择或尚不可确定的理由；⑥后续最少2–3项准确核验动作、责任对象、合格/放弃条件。
5. **至少3个不同商家场景，不得只验证稿中已写好的两个案例：**
   - **A 大陆自然人**卖原创设计模板，海外顾客，美国市场、自有网站，US$29/单、月5单，14天内需要人民币经营现金；无境外公司、无商户资格确认。重点：不得把企业PayPal US$35计入个人，区分会收付款与合法提款，不能声称香港银行账户等于香港商户。
   - **B 大陆个人开发者**卖真正的软件SaaS订阅，US$19/月、约80个持续付费用户、海外个人买家，自有网站；初步可能属于软件MoR品类，但**没有 Paddle 或其他商户/受款路径审批**，需要30天内合法拿到经营资金。重点：是否能明确比较软件MoR与真实合格的自收单及销售责任/税务/提现，费用只能按已知规则示范，不承诺实际可用。
   - **C 大陆企业**卖跨境实物，Shopify 自营店，美国买家，US$29/单、月100单，14天内需人民币采购资金；企业有普通国内银行账户，但**没有已证实的中国 Shopify Payments 邀请，也没有已获批的第三方跨境收单**。重点：哪个是 `NO/UNKNOWN`，Shopify第三方费可能叠加，WorldFirst不是独立收单网关，验证现金期限和备用路线。
   如需要只增加一个对抗性场景，可加入“大陆自然人境内销售网络教程，仅有个人二维码”，不能修改前述必做三项。
6. **内容锚定：** 每个测试答案都标注候选稿小节与**具体行号/短摘录**以便 Reviewer 独立对照；任何候选不能充分支持的答案记 `GAP`，不得用常识/网页补写成文章已给出的内容；必要的官方规则只用于澄清事实，不代替文章自己的教学效果。

# Storyboard Reviewer Checklist v1.0 (Candidate)
适用于实操/测评/观点；全镜头核对源文与证据状态，不以漂亮截图替代审查。

HARD_CHECKS (每项必须PASS，不能以总分补偿)：
[ ] 原文source_revision固定；非口播内容标明；每个原文段有Scene/Beat映射或经Owner批准忽略原因。
[ ] 每个Scene有且仅有一个**主要**视觉表达目标（可多个连续内部Beat）。
[ ] 区分实测/待核/示意/模拟/主观判断；不得虚构网页截图、操作完成、技术参数或交易价格。
[ ] 真实操作和敏感命令未实测就BLOCKED；素材是否已有、来源/版权/许可明确。
[ ] 独立制作与验收边界明确；有起始、中间动作和结束状态；支持与V6外壳无重复合成。
[ ] 全局镜头切换为硬切；Scene内动作按解说逐步展开；无字数/秒数/镜头数硬阈值。
[ ] Chapter/Beat/Scene数与索引一致；禁止假定52是固定值。

OPTIONAL_RUBRIC (人工盲审，需每项给证据例子，5维总分100)：
- 内容/叙事覆盖25
- 准确性与证据纪律25
- 视觉解释力20
- 可制作性与缺口可见20
- 变化节奏与观看负担10
建议80以上且硬检查全通过可标PASS_FOR_PLANNING；该阈值是项目实验建议值，待验证。
Reviewer输出四段：总评、逐镜RETURN点、源文缺漏与实证阻塞、下一Gate建议；只出PASS_FOR_PLANNING/RETURN_STORYBOARD/BLOCKED_EVIDENCE，不自行宣告PRODUCTION_PASS。

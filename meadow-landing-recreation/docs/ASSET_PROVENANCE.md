# 素材来源与重建

素材来源于 Owner 在本次任务提供的 `动效.mp4`（H.264/AAC，1922×1080，约 16.566 秒，36,782,130 bytes）。原片 SHA-256：`959073ef90a2b6fe425cfa60aa3d0c8b57c8658aaf7a1b66e0590a6a964cff35`。音量探测的平均值及峰值均为 -91 dB；该测量只说明检测结果，不代表素材权利已确认。

原文件按 5 MiB 顺序分片存放于 `reference/video-parts/`；执行 `python scripts/restore-reference-video.py` 后在 `reference/动效.mp4` 得到逐字节还原的原片，脚本会核对大小和 SHA-256，避免覆盖已有文件。

`reference/` 的五张 PNG 是重建脚本使用的原视频帧，分别对应 8 秒、9 秒、5.9 秒、12.2 秒和 7 秒。`scripts/build-scenes.py` 分析轮廓和颜色，输出嵌有原帧 WebP 的场景 SVG，以及独立矢量字样。顶部与底部文字使用遮罩分离并由 HTML 重新排版；窄屏天空使用无文字的入场帧。可运行页面不依赖访问第三方图片服务器。

此前版本曾采用 AI 补绘；最终归档页面的场景以录屏帧为准。前端绘制的花朵、光点和切换动画是近似效果。原片中所见产品名称、图像和设计的权利归属及商用许可 **UNKNOWN**，在明确授权前不得对外声称拥有相关权利。

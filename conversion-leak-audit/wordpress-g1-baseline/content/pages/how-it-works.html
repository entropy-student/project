How it works

The audit starts with public facts, not a free-form AI critique.

  1. Validate that the target URL is safe and publicly reachable.
  2. Inspect a bounded set of relevant pages.
  3. Extract normalized facts from static pages and, only when needed, limited browser states.
  4. Apply store-type and context gates.
  5. Evaluate a frozen set of high-confidence rules.
  6. Return evidence-linked findings or explicitly say when evidence is incomplete.

What a public scan cannot know

Traffic quality, actual funnel drop-off, payment decline rates, contribution margin, repeat purchase behavior and causal lift require your own store data or controlled experiments.

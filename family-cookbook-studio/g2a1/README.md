# Family Cookbook Studio — G2A1 local PoC artifacts

This folder contains the bounded OCR-routing/schema and browser-local preview probes for the Gate. The G2A1 delivery state is `RETURN_G2A1_OCR_ENVIRONMENT_BLOCKED`; the OCR runner is provided for replay, but it did not execute in this environment.

## Reproduce the synthetic inputs

Requirements: Node.js and local Chrome/Chromium. Set `CHROME_PATH` if Chrome is not at the default Windows path.

```powershell
node ocr/render-fixtures.mjs ocr/fixtures
```

This emits 20 synthetic page PNGs and metadata. It makes no network calls. Every source line is generated by the script; the handwritten-looking samples use installed system fonts and are not genuine handwriting.

## Deterministic routing and schema checks

```powershell
python -m unittest -v ocr/test_poc.py
python -m py_compile ocr/routing.py ocr/schema.py ocr/run_benchmark.py
```

The routing checks never rewrite OCR text. Two-engine disagreement and residual critical-value anomalies require user confirmation. The test suite does not stand in for OCR engine results.

## OCR benchmark replay

Use an isolated Python 3.10+ environment with CPU PaddlePaddle/PaddleOCR, OpenCV, Pillow, psutil, and a Torch-enabled Transformers environment for TrOCR. Install the exact versions in `ocr/requirements-ocr.txt` and `ocr/requirements-trocr.txt`, render fixtures, then run:

```powershell
python ocr/run_benchmark.py
```

PaddleOCR is invoked on each full page. TrOCR is loaded only after a deterministic rule selects a suspicious line crop. Model downloads use the local runtime cache; no cache should be copied into this repository. There is no cloud OCR/VLM code in this PoC.

The current structured output is `ocr/benchmark-output.json`. OCR accuracy, fallback resolution, confirmation burden, and inference resource metrics remain `null` because no OCR model ran in this Gate execution.

## Browser-local preview

```powershell
node preview/verify-preview.mjs preview/index.html preview/sample-local-image.svg preview/preview-observation.json
```

The preview runs from `file://`, reads a selected synthetic SVG through a local object URL, and blocks fetch/XHR/beacon/WebSocket attempts. It contains no form, upload action, OCR, model call, or downloadable cookbook. This proves the static browser-local boundary only. A WordPress/Kadence integration was not exercised.

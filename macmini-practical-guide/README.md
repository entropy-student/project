## 交付边界
- **需要**：情境、问题、解决/研究过程、证据、结论的自然叙事；画面用途和素材缺口；试验 Human Writing Skill + 精简语料对个人风格的帮助。
- **不需要**：把原 HTML 六个章节锁定成视频格式、制作移动端网站、打磨页面样式、上架部署、立刻生成最终图片和视频。
- **HTML 用途**：一个可本地打开的审稿文件，能同时看封面概念、解说原文、配画面提议和图片或占位提示。

# 自媒体文案创作系统（实操 / 测评 / 观点）

> Mac mini 是第一期验证题材，不是固定栏目或 HTML 网站开发项目。
> 当前状态：写作规范 v0.1 + 统一 Prompt v0.1 **CANDIDATE，待审议，尚未用 Codex 生成文章**。

## 最终产物
```text
类型 + 选题 + 可选资料/想法
           ↓
    AI 内部研究、组织、成文
           ↓
完整可朗读的中文自媒体文案
           ↓
       一个独立 HTML
```

范围只限「实操、测评、观点」三类，允许自然融合但每篇明确主类型。HTML 为审稿载体，不要求移动端、视频渲染、分镜、配图计划或网页设计。写作 Skill 是候选辅助，不能替代事实和作者判断。
